Lägga till bilder i meddelanden

Du kan skicka en bild som syns i chattfönstret. Till skillnad från när du skickar en fil visas bilden direkt bredvid din text, och behöver inte accepteras först för att sedan visas separat.
Dra bildfiler till textfältet där du skriver meddelandet. En liten symbol syns, för att visa att bilden kommer att skickas när du trycker på returtangenten. Du kan lägga till text före och efter bilden.

Du får bäst resultat om du skickar bilder i JPEG- eller GIF-format, så att folk som använder andra program än iChat AV kan se filerna.
