Ändra ditt statusmeddelande

Du kan ställa in ett statusmeddelande som visas bredvid ditt namn i kontaktlistan. De som har dig i sin kontaktlista kan se det meddelandet, så du kan låta dina vänner veta att du är på lunch, har möte, eller skriva något annat som du vill att de ska veta.
Klicka på statusvisaren under ditt namn i kontaktlistan.

Om du vill ställa in anpassade meddelanden när du är borta eller tillgänglig, välj Anpassa från popupmenyn Status och skriv in ett kort meddelande. Tryck på returtangenten för att spara ditt meddelande.

Du kan också välja Redigera statusmenyn från statuspopupmenyn. Om du vill skriva ett nytt statusmeddelande klickar du på knappen Lägg till (+) och skriver ditt meddelande. Tryck sedan på returtangenten. Om du vill redigera ett befintligt statusmeddelande dubbelklickar du på det.

Du sparar anpassade statusmeddelanden genom att välja "Kom ihåg anpassade meddelanden". När du skapar ett anpassat statusmeddelande läggs det till i statuspopupmenyn så att du enkelt kan använda det igen.

Om du vill ändra ordningsföljden för statusmeddelanden i menyn kan du dra dem uppåt eller nedåt i listan.

Ditt meddelande är synligt för andra iChat AV-användare som har dig i sina kontaktlistor. Om dina vänner använder ett annat program än iChat AV kan det hända att ditt meddelande inte syns, eller bara syns om de skickar dig ett snabbmeddelande.
