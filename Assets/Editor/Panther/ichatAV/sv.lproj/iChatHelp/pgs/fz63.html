Växla mellan olika konton för snabbmeddelanden

Om andra använder din dator kan du skapa skilda Mac OS X-användarkonton för var och en. När användare loggar in på Mac OS X kommer de att använda sina egna iChat-användarnamn. Välj Hjälp > Mac Hjälp i Finder om du vill ha hjälp med att skapa användarkonton i Mac OS X.

Har du olika användarnamn som du vill använda i iChat växlar du mellan dem i iChat-inställningarna.
1.Välj iChat > Inställningar och klicka på Konton.
2.Välj ett användarnamn från popupmenyn AIM-användarnamn.

Du kan även använda popupmenyn AIM-användarnamn för att skapa ett nytt .Mac-konto eller rensa menyn. När du rensar menyn försvinner alla användarkonton utom det du för närvarande använder.
