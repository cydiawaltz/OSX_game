Vad är ett användarnamn?

Ett användarnamn är din adress för snabbmeddelanden. Du ger användarnamnet till andra så att de kan chatta med dig. Ditt användarnamn kan vara din e-postadress hos Mac.com (till exempel poberg@mac.com) eller ett användarnamn för AOL Instant Messenger (AIM), som t ex "poberg3001".

Om du behöver ett användarnamn för iChat AV kan du skaffa ett .Mac-medlemskap på Apples webbplats. Du kan också gå till webbplatsen för AOL Instant Messenger på adressen www.aim.com.
