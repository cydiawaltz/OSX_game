Hindra andra från att skicka meddelanden till dig

Om du vill hindra någon från att skicka meddelanden till dig, ändrar du din status till Nedkopplad, eller kopplar ner från AIM- eller Rendezvous-tjänsten.

Du kan också ställa in integritetsalternativ som kontrollerar vilka du kommunicerar med.
Välj iChat > Inställningar. Klicka sedan på Integritetsskydd och välj ett alternativ.

Du kan också klicka på den översta knappen i Redigera Lista så kan folk chatta med dig. Klicka på knappen Lägg till (+) och skriv in personens AIM- eller .Mac-adress. Klicka på den nedersta knappen i Redigera lista så blockeras särskilda personer.

Du kan till exempel välja att acceptera meddelanden från endast ett fåtal utvalda personer, och blockera alla andra.

Om du stoppar personer från att skicka meddelanden till dig, kan de inte se om du är uppkopplad. Du kan inte heller se när de är uppkopplade eller skicka meddelanden till dem.

För att snabbt blockera en person klickar du på knappen Blockera som syns i meddelandefönstret när du får ett meddelande från någon.
