切換多個不同的即時通訊帳號

如果有其他人使用您的電腦，您可以替每一個使用者設定不同的 Mac OS X 使用者帳號。當使用者登入 Mac OS X 時，他們便會自動使用自己的 iChat 用戶名稱。如需設定 Mac OS X 帳號的相關協助，請從 Finder 裡選擇“輔助說明”>“Mac 輔助說明”。

如果您想在 iChat 裡使用多個用戶名稱，您可以使用“iChat 偏好設定”來切換不同的用戶名稱。
1.選擇 iChat >“偏好設定…”，再按“帳號”一下。
2.從“AIM 用戶名稱”彈出式選單裡選擇一個用戶名稱。

您也可以透過“AIM 用戶名稱”彈出式選單來製作新的 .Mac 帳號或清除選單。清除選單將會移除所有帳號，不過您正在使用的帳號會保留下來。
