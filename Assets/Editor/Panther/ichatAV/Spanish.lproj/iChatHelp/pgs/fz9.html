Cómo iniciar un chat con otro usuario

Para chatear con una persona, debe saber el nombre de usuario que dicha persona utiliza con iChat AV. Este nombre puede ser una clave AIM o una cuenta Mac.com. iChat AV no permite utilizar otros sistemas de chat, como por ejemplo: Yahoo o MSN.
1.Seleccione Archivo > "Nuevo chat con".
2.Escriba el nombre de usuario de la persona con la que desea chatear.

Si desea chatear con alguien con frecuencia, añada el nombre de usuario de la persona a la lista de contactos y visualizará en pantalla cuándo dicha persona está conectada y disponible.
