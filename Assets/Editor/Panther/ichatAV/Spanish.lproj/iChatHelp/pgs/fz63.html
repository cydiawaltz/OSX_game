Cómo pasar de una cuenta de mensajes instantáneos a otra

Si otras personas utilizan su ordenador, puede crear cuentas de usuario individuales en Mac OS X para cada una de ellas. Cuando un usuario inicia su sesión en Mac OS X, utilizará automáticamente su propia cuenta de iChat. Para obtener instrucciones sobre la creación de cuentas de usuario en el Mac OS X, seleccione Ayuda > Ayuda Mac en el Finder.

Si dispone de varios nombres de usuario y desea utilizarlos con iChat, puede cambiar de uno a otro mediante las preferencias de iChat.
1.Elija iChat > Preferencias y, a continuación, haga clic en Cuentas.
2.Seleccione un nombre de usuario en el menú local "Nombre de usuario AIM".

También puede usar el menú local "Nombre de usuario AIM" para crear una nueva cuenta .Mac o vaciar el menú. Cuando vacíe el menú, se borrarán todas las cuentas excepto la que esté utilizando en ese momento.
