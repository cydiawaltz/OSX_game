在多个即时信息帐户间切换

如果有其他人使用您的电脑，您可以为每个人创建单独的 Mac OS X 用户帐户。当用户登录 Mac OS X 时，他们会自动地使用自己的 iChat 用户名。有关设置 Mac OS X 帐户的帮助，请在 Finder 中选取“帮助”>“Mac 帮助”。

如果您想在 iChat 中使用多个用户名，您可以使用 iChat“预置”来切换。
1.选取 iChat >“预置…”，然后点按“帐户”。
2.从“AIM 用户名”弹出式菜单中选取一个用户名。

您也可以使用“AIM 用户名”弹出式菜单来创建新的 .Mac 帐户或清除菜单。清除菜单将会移去除当前使用的帐户以外的所有帐户。
