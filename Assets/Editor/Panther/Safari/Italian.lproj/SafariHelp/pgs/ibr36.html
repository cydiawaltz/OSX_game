Una pagina web non si apre

Ci sono diversi motivi per cui una pagina web potrebbe non aprirsi in Safari. Ecco alcuni suggerimenti da verificare, se una pagina non si apre.

Verifica il messaggio che compare quando una pagina non si apre. Potrebbe fornire importanti informazioni per risolvere il problema.

Assicurati di avere l'indirizzo corretto della pagina web e di averlo inserito correttamente.

Il sito web potrebbe essere temporaneamente non disponibile.

Se la pagina si trova su una rete o su Internet, verifica di essere collegato.

Se stai cercando di aprire una pagina utilizzando un indirizzo Rendezvous, assicurati che il sito si trovi sulla stessa sottorete del computer.

Alcuni siti web non consentono di utilizzare browser che non riconoscono. Contatta l'amministratore del sito web per capire se il problema è questo.

Se una pagina web non si apre, puoi comunicare questo problema scegliendo Safari > Comunica Problemi ad Apple.
