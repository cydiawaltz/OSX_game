Bloccare le finestre a comparsa

Alcune pagine web visualizzano delle finestre a comparsa quando le apri o le chiudi. Ad esempio, una pagina web potrebbe utilizzare una finestra a comparsa per richiedere le informazioni di accesso o per visualizzare delle pubblicità. Puoi bloccare queste finestre a comparsa.

Questo tipo di blocco ha effetto unicamente sulle finestre a comparsa che vengono visualizzate quando apri o chiudi una pagina. Ciò significa che non blocca le finestre a comparsa che si aprono quando fai clic su un collegamento.

Per bloccare le finestre a comparsa, scegli "Blocca Finestre a Comparsa" dal menu "Safari". Verrà visualizzato un segno di spunta accanto alla voce di menu.

Puoi anche scegliere "Preferenze" dal menu "Safari", fare clic su "Sicurezza" e selezionare l'opzione "Blocca le finestre a comparsa".

Se blocchi le finestre a comparsa, corri il rischio di perdere informazioni importanti per una pagina web.
