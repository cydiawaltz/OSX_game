Impostare la visualizzazione delle pagine

Puoi specificare l'aspetto delle pagine aperte con Safari (compresi i font utilizzati), se visualizzare le immagini e utilizzare i tuoi fogli di stile CSS.

Poiché molte pagine web specificano i propri font, le tue impostazioni avranno effetto solo sulle pagine in cui i font non sono definiti. In alcuni casi, le pagine web specificano dei fogli di stile che non consentono di utilizzare quello che hai impostato.

Scegli "Preferenze" dal menu "Safari", quindi fai clic su "Aspetto".

Per modificare il font standard o quello fisso utilizzati nelle pagine, fai clic sul pulsante di selezione appropriato, quindi scegli il font che vuoi utilizzare nella relativa finestra.

Se non vuoi che le immagini vengano visualizzate all'apertura della pagina, deseleziona l'opzione "Visualizza le immagini quando si apre la pagina". Disattivando questa opzione puoi aprire le pagine più rapidamente, anche se potresti perdere informazioni importanti.

Se il testo in una pagina web non viene visualizzato correttamente, potrebbe essere necessario scegliere una codifica differente nel menu a comparsa "Codifica Standard". Scegli una codifica adatta alla lingua delle pagine web che visualizzi più spesso.

Se vuoi utilizzare i tuoi fogli di stile CSS, fai clic su "Avanzate", quindi scegli "Altro" dal menu a comparsa "Foglio di Stile". Individua il foglio di stile e selezionalo.

Puoi controllare il contenuto visualizzato in alcune pagine anche dal pannello "Sicurezza" delle preferenze di Safari.

Alcuni siti web sono disponibili in più lingue e Safari è in grado di aprire automaticamente le pagine nella lingua che preferisci. Selezionando la codifica del testo non si imposta anche la lingua preferita. Per impostare la lingua, utilizza il pannello "Lingua" delle preferenze di "Internazionale".
