Controllare i contenuti caricati da una pagina web

Safari ti consente di controllare il contenuto che viene caricato all'apertura di una pagina web. Questa funzione è utile se non vuoi che le pagine carichino determinati tipi di contenuto per motivi di sicurezza o perché trovi che il contenuto sia privo di interesse.

Per evitare che il contenuto venga caricato, scegli "Preferenze" dal menu "Safari", quindi fai clic su "Sicurezza". A questo punto, deseleziona il contenuto che non vuoi che venga caricato.

Se vuoi bloccare le finestre a comparsa, seleziona la relativa opzione. Puoi anche scegliere "Blocca Finestre a Comparsa" dal menu "Safari".

Safari ti consente, inoltre, di scegliere se accettare i cookie e, nell'eventualità, quali accettare.

Le pagine web utilizzano plug-in, Java e JavaScript per visualizzare le informazioni. Disattivando queste funzioni, potrebbe essere impossibile visualizzare alcuni dei contenuti della pagina.
