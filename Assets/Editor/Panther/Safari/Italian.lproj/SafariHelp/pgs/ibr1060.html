Stampare le pagine web

Puoi utilizzare il comando standard "Stampa" dal menu "Archivio" per stampare una pagina web. Se la pagina web è formata da diversi frame puoi stamparne uno specifico.

Per stampare una pagina web, apri la pagina in Safari e scegli "Stampa" dal menu "Archivio".

Per stampare un frame di una pagina web, tieni premuto il tasto "Ctrl" e fai clic sul frame da stampare. Quindi scegli "Stampa" dal menu.

Inoltre, puoi creare un PDF della pagina web o inviare un fax utilizzando la finestra di dialogo Stampa.
