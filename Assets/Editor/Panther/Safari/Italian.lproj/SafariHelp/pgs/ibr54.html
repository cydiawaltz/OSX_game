Definire i server proxy

Se il tuo computer accede a Internet collegandosi a una rete protetta da un firewall, devi specificare i server proxy per accedere alle pagine web o ad altre risorse Internet. Il browser invia le richieste per le pagine web al server proxy, che le fornisce.

Se devi specificare un server proxy, l'amministratore di rete deve fornirti le informazioni necessarie. Le informazioni devono includere il tipo di server proxy, per definire (ad esempio, un server proxy web) l'indirizzo IP o il nome DNS per il server e il numero della porta.

Puoi specificare le informazioni del server proxy utilizzando le preferenze di rete. Puoi aprire le preferenze appropriate di rete utilizzando le preferenze di Safari.

Scegli "Preferenze" dal menu "Safari" e fai clic su "Avanzate", quindi su "Modifica Impostazioni".

Si apre il pannello "Network" delle Preferenze di Sistema che visualizza le impostazioni proxy per il tipo di connessione che stai utilizzando. Seleziona l'opzione di scelta per il tipo di server proxy (ad esempio, Proxy Web). Inserisci l'indirizzo IP o il nome DNS, fornito dall'amministratore di rete, nel primo riquadro di testo e il numero della porta nel secondo. Quando hai finito, fai clic su "Applica".
