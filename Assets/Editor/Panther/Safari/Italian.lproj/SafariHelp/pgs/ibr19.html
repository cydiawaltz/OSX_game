Monitorare le attività del browser

Mentre Safari carica una pagina web, puoi monitorare come procede per ogni elemento. Questa funzione può essere utile se vuoi esaminare la struttura di una pagina web.

Scegli "Attività" dal menu "Finestra", quindi apri la pagina web. Safari visualizza ogni elemento caricato dalla pagina.

Per aprire un elemento della finestra Attività nella sua finestra effettiva, fai doppio clic sull'elemento stesso.

Se apri un'altra pagina web, questa sostituisce il contenuto della finestra Attività.
