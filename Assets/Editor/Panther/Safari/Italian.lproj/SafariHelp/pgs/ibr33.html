Le pagine web non funzionano

Se le funzionalità delle pagine web sembrano non funzionare, potresti aver disattivato l'utilizzo dei plug-in, di Java o JavaScript, o potresti aver configurato Safari in modo da bloccare le finestre a comparsa.

Scegli "Preferenze" dal menu "Safari", quindi fai clic su "Sicurezza". Assicurati che le opzioni per utilizzare plug-in, Java e JavaScript siano selezionate e che l'opzione "Blocca le finestre a comparsa" non sia selezionata.

Se questi elementi non sono selezionati e la pagina non funziona, scegli "Comunica Problemi ad Apple" dal menu "Safari", per comunicare il problema.

Se apri delle pagine web di cui ti fidi, non metti a rischio la sicurezza del tuo computer se consenti di utilizzare plug-in, Java e JavaScript.
