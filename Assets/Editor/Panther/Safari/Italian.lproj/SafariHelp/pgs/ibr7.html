Aprire i siti web di Rendezvous

Safari utilizza Rendezvous per individuare i siti web che sono disponibili nella rete locale o nella sottorete.

Per visualizzare i siti web di Rendezvous disponibili, fai clic sull'icona della libreria dei preferiti nella barra dei preferiti quindi seleziona "Rendezvous" nella colonna "Raccolte".

Se, utilizzando Rendezvous, hai una stampante disponibile, potresti vederla inclusa tra i siti web di Rendezvous. Puoi aprire il sito web per configurare la stampante.

Puoi aggiungere siti web di Rendezvous alla barra dei preferiti e al menu "Preferiti" utilizzando il pannello "Preferiti" delle preferenze di Safari. Inoltre, puoi scegliere di visualizzare i siti web di Rendezvous nella Libreria dei Preferiti.
