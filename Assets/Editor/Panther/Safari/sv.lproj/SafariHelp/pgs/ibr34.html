Bilder visas inte

Om webbsidans bilder inte visas, kan det hända att alternativet som visar bilder är avaktiverat eller att det har uppstått nätverksproblem.

Välj Inställningar från Safari-menyn och klicka på Utseende. Klicka på "Visa bilder när sidan visas" så att alternativet markeras.

Om alternativet redan är markerat, kan du försöka att uppdatera sidan. Välj Uppdatera sida från menyn Innehåll.
