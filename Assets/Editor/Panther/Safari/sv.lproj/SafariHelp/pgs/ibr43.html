Se vilka insticksfiler som är tillgängliga för Safari

Safari fungerar med de insticksfiler som installeras med Mac OS X och som stöder Java-, QuickTime- och Shockwave Flash-material. Programmet fungerar också med insticksfiler som följer Netscape-standarden för insticksfiler, som t.ex. insticksfilen Macromedia Shockwave Player (kallas Shockwave for Director).

Om du vill se vilka insticksfiler som är tillgängliga för Safari väljer du Installerade insticksfiler från Hjälp-menyn.
