Webbsidor fungerar inte

Om vissa funktioner på webbsidor inte verkar funkgera kan du ha stängt av användningen av insticksfiler, Java eller JavaScript, eller så kan du ha angett att Safari ska blockera popupfönster.

Välj Inställningar från Safari-menyn och klicka på Säkerhet. Kontrollera att kryssrutorna för att använda insticksfiler, Java och JavaScript är markerade och att kryssrutan "Blockera popupfönster" inte är markerad.

Om dessa objekt inte är markerade och sidan inte fungerar, väljer du Rapportera buggar till Apple från Safari-menyn och berättar om problemet.

Om du öppnar webbsidor som du litar på innebär det ingen fara för datorn att låta sidorna använda insticksfiler, Java eller JavaScript.
