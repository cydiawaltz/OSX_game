Spécification de serveurs proxy

Si votre ordinateur accède à Internet en se connectant à un réseau protégé par un coupe-feu, vous devrez sans doute spécifier des serveurs proxy pour pouvoir accéder à des pages Web ou à d'autres ressources Internet. Votre navigateur envoie aux serveurs proxy des requêtes à propos de pages Web et ces derniers les récupèrent pour vous.

Si vous devez spécifier un serveur proxy, votre administrateur réseau devrait vous fournir les informations dont vous avez besoin. Parmi ces informations doivent figurer le type de serveur proxy à spécifier (un serveur proxy Web par exemple), l'adresse IP ou le nom DNS de ce serveur et un numéro de port.

Les informations de serveur proxy se définissent dans les préférences Réseau. Vous pouvez ouvrir le panneau de préférences Réseau approprié via les préférences Safari.

Choisissez Préférences dans le menu Safari et cliquez sur Avancé puis sur Modifier les réglages.

La fenêtre Réseau des Préférences Système s'ouvre et affiche les réglages proxy du type de connexion que vous utilisez. Cochez la case du type de serveur proxy (Web Proxy par exemple) utilisé. Dans le premier champ de texte, saisissez l'adresse IP ou le nom DNS fourni par votre administrateur réseau et dans la seconde le numéro de port. Une fois que vous avez terminé, cliquez sur Appliquer.
