Utilisation de votre feuille de style

Les feuilles de style en cascade (CSS) vous permettent de spécifier le mode d'affichage des éléments d'une page Web. Hormis l'ensemble des feuilles de style définies par la page, Safari vous permet d'utiliser votre propre feuille de style.

Choisissez Préférences dans le menu Safari, puis cliquez sur Avancé. Choisissez Autre dans le menu local Feuille de style. Recherchez la feuille de style que vous souhaitez utiliser, sélectionnez-la, puis cliquez sur Choisir.

Pour plus d'informations sur les feuilles de style en cascade, consultez le site du World Wide Web Consortium (en anglais). Recherchez "CSS" dans la liste des sujets "W3C A to Z".
