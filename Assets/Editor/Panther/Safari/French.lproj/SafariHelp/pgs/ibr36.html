Une page Web ne s'ouvre pas

Plusieurs raisons peuvent expliquer l'échec de l'ouverture d'une page dans Safari. Si tel est le cas, voici quelques points à vérifier.

Consultez le message qui s'affiche en cas de problème à l'ouverture d'une page. Il vous fournira peut-être des informations importantes pour résoudre le problème.

Assurez-vous que l'adresse de la page Web dont vous disposez est exacte et que vous l'avez saisie correctement.

Le site Web peut ne pas être disponible temporairement.

Si la page réside sur le réseau ou sur l'Internet, assurez-vous que vous n'êtes pas déconnecté.

Si vous tentez d'ouvrir une page à l'aide d'une adresse Rendezvous, assurez-vous que le site est hébergé sur le même sous-réseau que votre ordinateur.

Certains sites Web empêchent l'utilisation de navigateurs qu'ils ne reconnaissent pas. Contactez l'administrateur du site Web pour déterminer si c'est la raison pour laquelle la page ne s'ouvre pas.

En cas d'échec de l'ouverture d'une page Web, vous pouvez signaler le problème en choisissant Safari > Signaler un bogue à Apple.
