Un message indique qu'un module externe n'est pas disponible

Safari utilise tous les modules externes standard. Si vous rencontrez un problème avec un module externe, veuillez en informer Apple en cliquant sur l'icône bogue dans la barre d'adresses.

Safari utilise les modules externes installés sur Mac OS X qui gèrent Java, QuickTime et Shockwave Flash. Il utilise également les modules externes conformes à l'architecture standard des modules externes de Netscape, tels que Macromedia Shockwave Player (Shockwave pour Director).
