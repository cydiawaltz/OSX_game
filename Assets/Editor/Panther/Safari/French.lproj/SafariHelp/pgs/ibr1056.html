Synchronisation de vos signets

En utilisant iSync 1.1 et votre compte .Mac, vous pouvez synchroniser automatiquement vos signets entre plusieurs ordinateurs.

Par exemple, si vous utilisez un Mac à la fois chez vous et au bureau, vous avez la possibilité de synchroniser vos signets Safari sur vos deux ordinateurs pour les harmoniser.

Si iSync repère qu'un signet a été modifié à la fois sur votre ordinateur et sur le serveur .Mac, il vous demande lequel vous souhaitez conserver.

Pour démarrer la synchronisation de vos signets, choisissez Préférences dans le menu Safari et cliquez sur Signets. Cochez la case pour synchroniser vos signets utilisant .Mac.

Si cette case apparaît grisée, il est possible que vous deviez enregistrer votre ordinateur sur le serveur de synchronisation .Mac. Pour cela, cliquez sur Configurer pour ouvrir iSync et cliquez sur le bouton pour enregistrer votre ordinateur.

Après avoir enregistré votre ordinateur, vérifiez que l'option de synchronisation de vos signets est sélectionnée dans iSync puis cliquez sur Synchroniser maintenant. En cas de doutes sur l'utilisation d'iSync, choisissez Aide iSync dans le menu Aide.

Si vous souhaitez que vos signets restent synchronisés, sélectionnez la case correspondante pour les synchroniser automatiquement toutes les heures.

Pour synchroniser les signets Safari sur un autre ordinateur, enregistrez votre ordinateur et cliquez sur Synchroniser dans iSync.

Vous ne pouvez par synchroniser vos signets Safari si iSync version 1.1 ou ultérieure n'est pas installé sur votre ordinateur.

Pour obtenir la dernière version d'iSync et ouvrir un compte .Mac, visitez le site Web Apple.
