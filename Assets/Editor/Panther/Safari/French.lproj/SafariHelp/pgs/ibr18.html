Purge du cache

Lorsque vous ouvrez des pages Web, Safari en enregistre le contenu temporairement, à un emplacement appelé "cache", afin que ces pages soient plus rapidement accessibles à la prochaine ouverture.

Si le contenu de la page que vous ouvrez n'est pas à jour, vous souhaiterez peut-être vider le cache. Si vous créez une page Web, vous souhaitez peut-être également vider le cache afin d'afficher le nouveau contenu de la page.

Choisissez Vider le cache dans le menu Safari, puis cliquez sur Vider.
