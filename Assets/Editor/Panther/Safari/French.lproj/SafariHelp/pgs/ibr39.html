Il semble qu'une page Web n'utilise pas ma feuille de style

Hormis l'ensemble des feuilles de style définies par la page, Safari vous permet d'utiliser la feuille de style en cascade que vous avez spécifiée. Il peut arriver qu'une feuille de style spécifiée par la page écrase votre feuille de style.

Si vous pensez que votre feuille de style devrait être utilisée par la page, assurez-vous que vous avez spécifié la bonne feuille de style.

Pour le vérifier, choisissez Préférences dans le menu Safari, puis cliquez sur Avancé.
