Sélection d'un encodage de texte

La plupart des pages Web spécifient un encodage de texte qui détermine le mode d'affichage des caractères dans la page. C'est n'est toutefois pas le cas pour certaines pages Web. À l'ouverture de ce type de page Web, Safari utilise l'encodage de texte par défaut sélectionné dans la fenêtre Apparence des préférences Safari.

Pour éviter d'afficher un texte tronqué, sélectionnez comme encodage de texte par défaut celui qui correspond aux caractères de la langue utilisée dans les pages Web que vous ouvrez le plus souvent. Par exemple, si vous ouvrez principalement des pages utilisant des caractères japonais, il est alors recommandé de remplacer l'encodage de texte par défaut par l'un des encodages japonais.

Choisissez Préférences dans le menu Safari, puis cliquez sur Apparence. Choisissez l'encodage le plus approprié à vos pages Web dans le menu local Encodage par défaut.

Si le texte d'une page est tronqué, vous pouvez modifier l'encodage utilisé pour cette page. Choisissez Encodage de texte dans le menu Présentation et sélectionnez l'encodage approprié pour la page.

Certains sites Web sont disponibles en plusieurs langues et Safari est capable d'ouvrir automatiquement des pages dans votre langue préférée. Sélectionner un encodeur de texte ne définit pas votre langue préférée. Pour configurer la langue de votre choix, utilisez la fenêtre Langues des préférences International.
