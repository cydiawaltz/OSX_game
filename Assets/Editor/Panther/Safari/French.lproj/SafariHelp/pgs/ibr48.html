Suppression de noms et mots de passe d'utilisateur sauvegardés

Si vous sélectionnez l'option du panneau de préférences Remplissage automatique permettant que les noms et mots de passe d'utilisateur soient automatiquement complétés, Safari sauvegarde tous les noms et mots de passe que vous saisissez dans les formulaires Web. Vous pouvez supprimer ces informations si, par exemple, vous craignez que quelqu'un d'autre n'accède à vos données d'authentification.

Si vous aviez sélectionné l'option "Jamais pour ce site Web" lorsque vous avez saisi un nom et un mot de passe pour un site Web, vous pouvez effacer l'élément sauvegardé pour ce site Web afin de pouvoir enfin sauvegarder ces informations.

Choisissez Préférences dans le menu Safari, puis cliquez sur Remplissage automatique. Cliquez sur Modifier à côté de la case "Noms et mots de passe d'utilisateur". Sélectionnez l'élément que vous souhaitez effacer et cliquez sur Supprimer.

Si vous aviez sélectionné l'option "Jamais pour ce site Web" lorsque vous avez saisi un nom et un mot de passe pour un site Web et que vous souhaitez maintenant sauvegarder ces informations, sélectionnez l'élément "Ne jamais enregistrer les mots de passe" et cliquez sur Supprimer.

Si vous désirez effacer tous les éléments, cliquez sur Tout supprimer.

Il n'est pas nécessaire que vous effaciez les informations sauvegardées pour un site Web si vos nom et mot de passe changent. Dans le formulaire, remplacez le nom et le mot de passe actuels par les nouveaux à l'ouverture de la page Web. Safari demande alors si vous souhaitez sauvegarder ces nouvelles informations.
