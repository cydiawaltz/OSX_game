Configuration de l'ouverture des liens d'autres applications

Si Safari est votre navigateur Web par défaut, les pages Web s'y ouvrent lorsque vous cliquez sur des liens dans d'autres applications, sur les messages de Mail par exemple, ou quand vous double-cliquez sur les icônes de fichiers Web Internet Location. En fonction de vos préférences, les pages peuvent s'ouvrir dans une nouvelle fenêtre ou dans la fenêtre en cours.

Choisissez Préférences dans le menu Safari et sélectionnez l'option "Ouvrir les liens des applications" que vous souhaitez utiliser.

Si vous activez la navigation par onglets et que vous sélectionnez "dans la fenêtre actuelle", les pages s'ouvriront dans un nouvel onglet de la fenêtre en cours.
