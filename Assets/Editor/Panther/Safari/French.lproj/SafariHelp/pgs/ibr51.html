Visualisation du code source HTML d'une page Web

Avec Safari, vous pouvez visualiser le code source HTML des pages Web. Vous pouvez aussi sauvegarder une page Web de manière à la consulter plus tard ou à l'utiliser en tant que source de code HTML.

Pour visualiser la source HTML d'une page Web, ouvrez la page que vous désirez visualiser et choisissez Afficher source dans le menu Présentation.

Pour sauvegarder la source HTML d'une page Web, ouvrez la page que vous désirez sauvegarder et choisissez Enregistrer sous dans le menu Fichier. Attribuez un nom au fichier et choisissez l'emplacement où vous désirez le sauvegarder, puis cliquez sur Enregistrer.

Cette action enregistre uniquement le contenu du texte HTML de la page en cours. Les éléments de la page référencés dans son code HTML, les images par exemple, ne sont pas sauvegardés.
