Retour à vos résultats de recherche Google

Lorsque vous cliquez sur un lien contenu dans une page de résultats de recherche Google, un bouton SnapBack apparaît dans le champ de recherche de Google. Vous pouvez cliquer sur ce bouton pour revenir à vos résultats de recherche, quelle que soit la page sur laquelle vous vous trouvez.

Pour revenir à la dernière page des résultats de recherche affichée, cliquez sur le bouton SnapBack situé dans le champ de recherche de Google.

Si vous avez lancé des recherches Google dans plusieurs fenêtres, le bouton SnapBack de Google situé dans chaque fenêtre vous permet de revenir à ses propres résultats de recherche.

Si vous cliquez sur le bouton SnapBack situé dans le champ de recherche Google, Safari supprime ce bouton du champ d'adresse, le cas échéant.
