Affichage des modules externes disponibles pour Safari

Safari utilise les modules externes installés avec Mac OS X qui gère le contenu Java, QuickTime et Shockwave Flash. Il utilise également les modules externes conformes à l'architecture standard des modules externes de Netscape, tels que Macromedia Shockwave Player (Shockwave pour Director).

Pour afficher les modules externes disponibles pour Safari, choisissez Modules externes installés dans le menu Aide.
