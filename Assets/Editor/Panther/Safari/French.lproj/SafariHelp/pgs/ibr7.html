Ouverture des sites Web Rendezvous

Safari utilise Rendezvous pour découvrir des sites Web qui sont disponibles sur votre réseau local ou votre sous-réseau.

Pour afficher les sites Web Rendezvous disponibles, cliquez sur l'icône de la bibliothèque des signets dans la barre des signets, puis sélectionnez Rendezvous dans la colonne Collections.

Si vous disposez d'une imprimante en utilisant Rendezvous, celle-ci peut apparaître dans la liste comme un site Web Rendezvous. Vous pouvez ouvrir la page Web pour configurer l'imprimante.

Dans les préférences Safari, la fenêtre Signets permet d'ajouter des sites Web Rendezvous à la barre des signets et au menu des signets. Vous pouvez également choisir d'afficher les sites Web Rendezvous dans la Bibliothèque des signets.
