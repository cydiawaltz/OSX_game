Retour à la page SnapBack

La première page que vous ouvrez dans une fenêtre est considérée comme la page SnapBack. Safari la conserve en mémoire afin que vous puissiez y accéder de nouveau après avoir ouvert d'autres pages du site Web.

Pour revenir à la page SnapBack, cliquez sur le bouton SnapBack dans la zone d'adresse.

Une seule page SnapBack est associée à chaque fenêtre. Pour marquer une nouvelle page SnapBack pour une fenêtre, ouvrez cette page, puis sélectionnez Marquer la page pour un SnapBack dans le menu Historique.

Lorsque vous ouvrez un page en saisissant son adresse dans le champ d'adresse ou à l'aide d'un signet ou encore en la sélectionnant dans le menu Historique, cette page est également définie comme la page SnapBack.

Si vous effectuez une recherche Google ou cliquez sur le bouton SnapBack dans le champ de recherche Google, Safari supprime le bouton SnapBack du champ d'adresse, le cas échéant.
