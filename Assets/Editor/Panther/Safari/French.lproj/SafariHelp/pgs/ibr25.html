Organisation du menu Signets

Vous pouvez organiser les signets ajoutés dans le menu Signets.

Pour ajouter un signet dans ce menu, ouvrez la page Web souhaitée, puis cliquez sur le bouton Ajouter un signet dans la barre d'adresse. Saisissez un nom pour le signet, puis choisissez Menu Signets dans le menu local.

Pour organiser les signets du menu Signets, choisissez Afficher tous les signets dans ce menu, puis cliquez sur Menu Signets. Pour classer les signets, faites-les glisser vers le haut ou vers le bas. Sélectionnez un élément, puis appuyez sur la touche Supprimer pour le supprimer.

Si vous ajoutez un dossier de signets dans le menu, il apparaît comme un sous-menu de ce menu. Pour créer un dossier, cliquez sur le bouton Ajouter (+) situé en bas de la colonne Signet, puis faites glisser les signets dans le dossier.

Pour renommer un signet ou un dossier, sélectionnez l'élément souhaité, puis appuyez sur Retour.

En utilisant la fenêtre Signets des préférences Safari, vous pouvez ajouter des éléments du Carnet d'adresses ou de Rendezvous au menu Signets et à la Bibliothèque des signets. Des sites Web figurant sur des cartes de votre Carnet d'adresses ou des sites Web Rendezvous sur votre réseau local sont autant d'exemples d'éléments.
