Gestion des cookies

Un site Web stocke des "cookies" sur votre ordinateur afin de faciliter les transactions entre ce dernier et le site. Dans la plupart des cas, les cookies sont inoffensifs. Pour utiliser certains sites Web, il est nécessaire que les cookies soient acceptés.

Si vous vous souciez du mode de gestion des cookies, vous pouvez le définir dans Safari.

Choisissez Préférences dans le menu Safari, puis cliquez sur Sécurité. Sélectionnez Jamais si vous ne souhaitez pas conserver les cookies sur votre ordinateur. L'inconvénient est que vous risquez de ne pas pouvoir accéder à certains sites Web.

Cliquez sur Toujours pour accepter et conserver tous les cookies.

Cliquez sur "Seulement des sites sur lesquels vous naviguez" pour empêcher le stockage de cookies provenant d'autres sites que ceux que vous ouvrez. Sélectionnez cette option pour éviter que les publicitaires des sites Web que vous visitez ne stockent leurs cookies sur votre ordinateur.

Pour consulter les cookies stockés sur votre ordinateur, cliquez sur Afficher les cookies. Pour supprimer un cookie, sélectionnez-le dans la liste et cliquez sur Supprimer.

Si vous ne souhaitez plus accepter les cookies, vous devrez aussi effacer tous les cookies stockés sur votre ordinateur après avoir sélectionné Jamais dans le panneau Sécurité.

Pour ouvrir une page, il est parfois nécessaire d'accepter temporairement les cookies. Sélectionnez Toujours pour accepter les cookies et ouvrir la page. Vous pouvez ensuite les désactiver. Après avoir vu une page, vous pouvez effacer ses cookies.
