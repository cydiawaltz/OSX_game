Sélection de la page d'accueil

Votre "page d'accueil" est la page qui apparaît généralement lorsque vous lancez Safari, ouvrez une nouvelle fenêtre ou choisissez Accueil dans le menu Historique. N'importe quelle page peut être choisie comme page d'accueil.

Ouvrez une page Web dans Safari, choisissez Préférences dans le menu Safari, puis cliquez sur Général. Cliquez sur Paramétrer sur la page en cours.

Vous pouvez également saisir l'adresse de la page que vous souhaitez utiliser dans le champ "Page d'accueil".

Cela modifie également le réglage de votre page d'accueil dans les préférences Internet.

Si vous souhaitez que de nouvelles fenêtres s'ouvrent avec la page d'accueil, choisissez Page d'accueil dans le menu local "Nouvelles fenêtre ouvertes avec".
