Téléchargement et installation de logiciels

Si vous téléchargez un fichier d'image disque, Safari le décompresse automatiquement. De même, s'il contient un programme d'installation, Safari se charge de l'ouvrir. Contentez-vous de suivre les instructions à l'écran pour terminer l'installation.

Si vous téléchargez une image disque Internet permettant l'installation de logiciels, Safari décompresse le fichier et ouvre automatiquement le programme d'installation. Une fois l'installation terminée, Safari place le fichier d'image disque dans la Corbeille. Si vous souhaitez conserver l'image disque pour pouvoir réinstaller le logiciel, retirez-la de la Corbeille.
