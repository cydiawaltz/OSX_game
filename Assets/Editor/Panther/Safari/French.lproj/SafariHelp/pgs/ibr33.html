Les pages Web ne s'affichent pas correctement

Si certaines fonctions de pages Web semblent ne pas fonctionner, c'est peut-être que vous avez désactivé l'utilisation de modules externes, de Java ou de JavaScript, ou encore que vous avez configuré Safari de sorte qu'il bloque les fenêtres contextuelles.

Choisissez Préférences dans le menu Safari, puis cliquez sur Sécurité. Assurez-vous que les cases autorisant l'utilisation de modules externes, Java et JavaScript, sont cochées et que la case "Bloquer les fenêtres contextuelles" est décochée.

Si ces options ne sont pas sélectionnées et que la page ne s'affiche pas correctement, choisissez Signaler un bogue à Apple dans le menu Safari pour signaler le problème.

Si vous ouvrez des pages Web que vous estimez fiables, autoriser l'utilisation de modules externes, Java et JavaScript, ne présente aucun risque pour la sécurité de votre ordinateur.
