Sélection de l'emplacement d'enregistrement des fichiers téléchargés

Lorsque vous téléchargez un fichier, Safari l'enregistre automatiquement à l'emplacement indiqué dans la fenêtre Général des préférences Safari. Safari est configuré pour télécharger les fichiers sur votre Bureau, mais un autre emplacement peut être spécifié.

Pour modifier l'emplacement de téléchargement, choisissez Préférences dans le menu Safari, puis cliquez sur Général. Choisissez Bureau ou cliquez sur Choisir un autre emplacement pour sélectionner un autre emplacement.

Dans la mesure où cette modification concerne vos réglages des préférences Internet, elle affecte également d'autres programmes utilisant les préférences Internet.

Vous pouvez choisir d'ouvrir certains fichiers "sécurisés" après les avoir téléchargés. Parmi les fichiers de ce type figurent les films, les images, les fichiers son, les documents texte et PDF, les images disque et d'autres types d'archives.
