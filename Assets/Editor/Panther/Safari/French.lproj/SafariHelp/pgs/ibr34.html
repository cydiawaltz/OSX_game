Les images n'apparaissent pas

Si les images d'une page Web n'apparaissent pas, l'option permettant leur affichage est peut-être désactivée ou le réseau est peut-être en dérangement.

Choisissez Préférences dans le menu Safari, puis cliquez sur Apparence. Cochez "Afficher les images à l'ouverture des pages".

Si l'option est déjà sélectionnée, essayez de recharger la page. Choisissez Recharger la page dans le menu Présentation.
