Ouverture d'une page Web dans une fenêtre différente

Lorsque vous cliquez sur un lien de la page Web, Safari ouvre généralement la page dans la fenêtre que vous utilisez actuellement. Si vous le souhaitez, vous pouvez ouvrir la page dans une nouvelle fenêtre afin de pouvoir afficher plusieurs pages en même temps. Il existe plusieurs méthodes pour ouvrir une page dans une nouvelle fenêtre.

Maintenez la touche Contrôle enfoncée et cliquez sur un lien ou un signet. Puis choisissez l'option Ouvrir le lien dans une nouvelle fenêtre, dans le menu des raccourcis.

Choisissez l'option Nouvelle fenêtre dans le menu Fichier, puis saisissez l'adresse de la page.

Pour ouvrir une page dans une nouvelle fenêtre, devant la fenêtre en cours, maintenez la touche Commande enfoncée et cliquez sur le lien ou le signet. Pour ouvrir la fenêtre derrière la fenêtre en cours, maintenez enfoncées les touches Commande et Majuscule. Ces raccourcis changeront si vous sélectionnez Permettre la navigation par onglets dans la fenêtre Onglets des préférences Safari.

Certains liens s'ouvrent dans une nouvelle fenêtre sans qu'il soit nécessaire d'utiliser ces raccourcis. La barre de statut (située au bas de la fenêtre) vous indique ce qui se passe lorsque vous cliquez sur un lien. Pour afficher la barre de statut, choisissez l'option Barre de statut dans le menu Présentation.
