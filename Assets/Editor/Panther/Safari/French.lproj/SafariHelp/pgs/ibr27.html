Contrôle des éléments chargés par une page Web

Vous pouvez contrôler le type d'élément chargé à l'ouverture d'une page Web. Pour des raisons de sécurité ou de confort, il peut arriver que vous souhaitiez empêcher le chargement de certains types d'éléments.

Pour empêcher le téléchargement de certains éléments, choisissez Préférences dans le menu Safari, puis cliquez sur Sécurité. Désélectionnez ensuite les éléments que vous ne souhaitez pas télécharger.

Pour bloquer l'affichage de fenêtres pop-up, cochez la case correspondante. Vous pouvez également choisir Bloquer les fenêtres pop-up dans le menu Safari.

En outre, vous avez la possibilité de refuser ou d'accepter les cookies et dans ce dernier cas de choisir lesquels.

Les pages Web utilisent des modules externes, ainsi que les programmes Java et JavaScript pour afficher des informations. Si vous désactivez ces fonctionnalités, certains éléments de la page visitée risquent de ne pas apparaître.
