Définition de Safari comme navigateur Web par défaut

Il vous est possible de faire de Safari votre navigateur Web par défaut. Si tel est le cas, il apparaît lorsque vous cliquez sur un lien figurant dans un document, tel qu'un message Mail, ou lorsque vous double-cliquez sur un fichier Adresse Web Internet dans le Finder.

Safari est configuré de manière à ce que ces pages s'ouvrent dans une nouvelle fenêtre mais vous pouvez faire en sorte qu'elles s'ouvrent dans un onglet de la fenêtre en cours.

Choisissez Préférences dans le menu Safari, puis cliquez sur Général. Choisissez Safari dans le menu local Navigateur Web par défaut.

Sélectionnez l'option "Ouvrir les liens des applications" que vous souhaitez utiliser. Si vous choisissez que s'ouvrent les pages dans la fenêtre en cours et que vous sélectionnez Permettre la navigation par onglets dans la fenêtre Onglet des préférences Safari, les pages s'ouvriront dans un nouvel onglet de la fenêtre en cours.

Si vous cliquez sur un lien dans certains programmes, il se peut que la page Web s'ouvre dans un navigateur différent de celui par défaut.
