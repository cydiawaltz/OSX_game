Retour à des pages Web précédemment ouvertes

Safari enregistre l'adresse des pages Web que vous ouvrez. Safari conserve dans l'Historique les pages que vous avez ouvertes pendant environ une semaine.

Grâce à cet Historique, il vous est possible de revenir ultérieurement sur une page en un clin d'oeil.

Pour accéder de nouveau à une page Web que vous avez récemment ouverte, cliquez sur les boutons Précédent et Suivant situés dans la barre d'outils. Cela fait, vous avez également la possibilité de sélectionner une page dans le menu qui s'affiche.

Pour revenir à une page Web ouverte précédemment, sélectionnez-la dans le menu Historique. Vous pouvez également cliquer sur Signets dans la barre des signets, puis sélectionner Historique pour afficher les pages qui ont déjà été ouvertes.

Si la page que vous souhaitez ouvrir est indiquée comme page SnapBack de la fenêtre, cliquez sur le bouton SnapBack situé dans le champ d'adresse. La page SnapBack correspond généralement à la première page que vous ouvrez dans une fenêtre.
