Ouverture de pages Web

Lorsque vous ouvrez Safari pour la première fois, il ouvre la page d'accueil spécifiée dans les préférences Internet. Ensuite, pour ouvrir les pages Web, il existe plusieurs méthodes.

Pour ouvrir une page vers laquelle il existe un lien sur la page que vous êtes en train de consulter, cliquez sur ce lien.

Pour ouvrir une page vers laquelle il n'existe pas de lien, saisissez son adresse dans le champ de texte de la barre des adresses et appuyez sur Retour.

Pour ouvrir une page pour laquelle vous avez créé un signet, cliquez sur un élément de la barre des signets, choisissez un élément du menu Signet ou double-cliquez sur le signet, dans la Bibliothèque des signets.

Un triangle placé en regard d'un élément de la barre des signets ou du menu Signet indique qu'il s'agit d'une collection de signets. Lorsque vous sélectionnez cet élément, vous voyez apparaître tous les signets de la collection, et vous pouvez alors sélectionner la page voulue dans la liste.

Pour ouvrir une page que vous avez déjà ouverte, saisissez une partie de son adresse. Safari complète l'adresse ou affiche une liste d'adresses correspondantes. Si une liste apparaît, sélectionnez une adresse à l'aide des touches fléchées ou du pointeur et appuyez sur Retour pour ouvrir la page.

Pour ouvrir une page dans une nouvelle fenêtre, devant la fenêtre en cours, maintenez la touche Commande enfoncée et cliquez sur le lien ou le signet. Pour ouvrir la fenêtre derrière la fenêtre en cours, maintenez enfoncées les touches Commande et Majuscule. Ces raccourcis changeront si vous sélectionnez Permettre la navigation par onglets dans la fenêtre Onglets des préférences Safari.

Pour ouvrir une page sur votre disque dur ou un serveur de fichiers, choisissez Ouvrir le fichier dans le menu Fichier.

Si Safari est votre navigateur Web par défaut, les pages Web s'y ouvrent lorsque vous cliquez sur des liens dans d'autres applications, sur les messages de Mail par exemple, ou quand vous double-cliquez sur les icônes de fichiers d'adresses Web Internet. La fenêtre Général des préférences Safari vous permet de sélectionner si les pages s'ouvrent dans une nouvelle fenêtre ou dans la fenêtre en cours. Si vous activez la navigation par onglets et que vous choisissez d'ouvrir les liens dans les fenêtres en cours, ils s'ouvrent alors dans de nouveaux onglets.

Vous pouvez ouvrir une page Web à partir d'un document situé dans une autre application en sélectionnant l'URL puis en choisissant Services dans le menu de l'application et en choisissant Ouvrir l'URL dans Safari.
