Suivi de l'activité du navigateur

Lorsque Safari charge une page Web, vous pouvez suivre l'avancement du téléchargement de chaque élément de cette page. Ceci peut s'avérer utile pour étudier la structure d'une page Web.

Choisissez Activité dans le menu Fenêtres, puis ouvrez la page Web. Safari affiche chaque élément chargé par la page.

Pour ouvrir un élément de la fenêtre Activité dans sa propre fenêtre, double-cliquez sur cet élément.

Si vous ouvrez une autre page Web, celle-ci vient écraser la fenêtre Activité.
