Impression de pages Web

Vous pouvez utiliser la commande Imprimer standard du menu Fichier pour imprimer une page Web. Si la page Web est composée de plusieurs cadres, vous pouvez imprimer celui que vous voulez.

Pour imprimer une page Web, ouvrez la page dans Safari et choisissez Imprimer dans le menu Fichier.

Pour imprimer un cadre d'une page Web, maintenez la touche Contrôle enfoncée et cliquez sur le cadre que vous souhaitez imprimer. Choisissez ensuite Imprimer le cadre dans le menu des raccourcis.

Vous pouvez également créer un PDF de la page Web ou vous l'envoyer par fax à l'aide de la zone de dialogue Imprimer.
