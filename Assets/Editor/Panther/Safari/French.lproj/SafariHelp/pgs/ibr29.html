Envoi de formulaires à un site Web sécurisé

Dans certains cas, les formulaires renseignés dans Safari peuvent être envoyés sans sécurisation à un site Web. Safari est configuré pour afficher un message lorsque vous êtes sur le point d'effectuer cette opération. Vous pouvez donc empêcher l'envoi du formulaire si vous vous souciez de la sécurité de vos informations.

Pour que ce message n'apparaisse pas, choisissez Préférences dans le menu Safari, puis cliquez sur Sécurité. Désélectionnez la case "Demander avant l'envoi d'un formulaire non sécurisé à un site Web sécurisé".
