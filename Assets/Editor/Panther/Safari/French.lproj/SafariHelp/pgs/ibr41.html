Choix des éléments ˆ afficher dans une nouvelle fenêtre

Vous pouvez choisir les éléments que vous souhaitez voir apparaître dans une nouvelle fenêtre lorsque vous les ouvrez dans Safari.

Choisissez Préférences dans le menu Safari, puis cliquez sur Général. Puis, choisissez un réglage dans le menu local "Nouvelles fenêtres ouvertes avec".

Choisissez la page d'accueil pour ouvrir la page Web que vous avez spécifiée comme étant votre page d'accueil.

Choisissez Cette page-même pour ouvrir la page qui est ouverte dans la fenêtre active.

Si vous ne souhaitez pas ouvrir de page, choisissez Page Vide.

Choisissez Signets pour afficher la Bibliothèque des signets.

Safari identifie la page ouverte dans la nouvelle fenêtre comme étant la page SnapBack de la fenêtre.
