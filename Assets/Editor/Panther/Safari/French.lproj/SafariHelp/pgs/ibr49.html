Suppression de données sauvegardées dans des formulaires Web

Si vous sélectionnez l'option permettant que soient remplis automatiquement les formulaires Web utilisant des informations d'autres pages Web, Safari sauvegarde les informations que vous saisissez. Si vous le souhaitez, vous pouvez effacer ces informations.

Choisissez Préférences dans le menu Safari, puis cliquez sur Remplissage automatique. Cliquez sur Modifier à côté de la case "Autres formulaires". Sélectionnez l'élément que vous souhaitez effacer et cliquez sur Supprimer. Si vous désirez effacer tous les éléments, cliquez sur Tout supprimer.

Si vous ne souhaitez pas que des données issues d'autres formulaires Web soient utilisées, décochez la case "Autres formulaires" de la fenêtre Onglets des préférences Safari.
