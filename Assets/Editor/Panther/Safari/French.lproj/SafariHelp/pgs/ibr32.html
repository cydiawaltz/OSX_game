Le texte d'une page Web est tronqué

Le texte d'une page Web peut apparaître tronqué si la page utilise des caractères qui ne font pas partie de votre encodage de texte par défaut et que la page n'indique pas l'encodage adapté.

Pour modifier l'encodage d'une page, choisissez Encodage de texte dans le menu Présentation, puis sélectionnez un encodage approprié pour la langue employée dans cette page.

Si le texte des pages que vous consultez fréquemment présente des troncatures, vous devez modifier votre encodage de texte par défaut. Choisissez Préférences dans le menu Safari, puis cliquez sur Apparence. Choisissez un encodage approprié dans le menu local Encodage par défaut.
