Ouverture des pages d'accueil à partir de votre Carnet d'adresses

Safari permet d'ouvrir facilement des sites Web pour les sociétés ou les particuliers répertoriés dans votre Carnet d'adresses.

Dans le Carnet d'adresses, sélectionnez une carte et entrez l'adresse du site Web dans le champ "page d'accueil" de la carte.

Pour afficher les pages d'accueil dans Safari, choisissez Afficher tous les signets dans le menu Signets et sélectionnez Carnet d'adresses. Pour ouvrir une page, double-cliquez sur cette page.

Dans les préférences Safari, la fenêtre Signets permet d'ajouter les pages d'accueil du Carnet d'adresses à la barre des signets et au menu des signets. Vous pouvez également choisir d'afficher les pages d'accueil du Carnet d'adresses dans la Bibliothèque des signets.
