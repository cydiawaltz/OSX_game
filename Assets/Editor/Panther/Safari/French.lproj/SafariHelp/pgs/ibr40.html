Création d'un signet pour une page Web

Lorsque vous ouvrez des pages Web, vous pouvez créer des signets afin de revenir rapidement sur ces pages.

Pour mettre en signet une page Web, ouvrez la page puis choisissez Ajouter un signet dans le menu Signets. Vous pouvez également cliquer sur le bouton Ajouter un signet dans la barre d'adresses si elle apparaît.

Saisissez un nom pour le signet, puis choisissez l'emplacement où vous souhaitez le voir apparaître dans le menu local. Vous pouvez ajouter le signet dans la barre des signets, dans le menu Signets ou dans une collection de signets.

Vous pouvez en outre ajouter un signet à la barre des signets en glissant son icône de la case d'adresse vers la barre des signets.

Pour afficher un signet que vous avez ajouté à une collection, choisissez Afficher tous les signets dans le menu Signets.
