Recherche de fichiers téléchargés

Les fichiers que vous téléchargez sont copiés vers l'emplacement spécifié dans la fenêtre Général des préférences Safari.

Safari est configuré pour télécharger les fichiers vers le dossier Bureau, mais vous pouvez indiquer un autre emplacement. Pour voir où les fichiers sont téléchargés, ouvrez la fenêtre Général des préférences Safari.

Pour afficher un fichier téléchargé sur le Finder, cliquez sur la loupe située en regard de la fenêtre Téléchargements, qui apparaît lorsque vous téléchargez le fichier.

Si la fenêtre Téléchargements n'apparaît pas, choisissez Téléchargements dans le menu Fenêtre.

Si vous téléchargez un fichier image disque, Safari affiche le nom du volume de l'image disque dans la fenêtre Téléchargements. Si vous avez démonté le volume, Safari affiche le dossier image disque dans le Finder lorsque vous cliquez sur la loupe.

Si vous téléchargez une image disque Internet, Safari décompresse le fichier et copie son contenu à l'emplacement du téléchargement, puis place l'image disque dans la Corbeille. Si vous cliquez sur la loupe, vous verrez le contenu de l'emplacement de téléchargement. Pour enregistrer le fichier image disque, vous devez d'abord le sortir de la Corbeille.
