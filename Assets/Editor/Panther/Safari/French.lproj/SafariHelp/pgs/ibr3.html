Notification de problèmes avec Safari

Si vous rencontrez un problème en utilisant Safari, vous pouvez adresser une notification à Apple via Safari. Les problèmes peuvent inclure les pages Web dont le chargement ne s'effectue pas correctement ou des fonctionnalités qui ne réagissent pas comme vous l'attendez.

Pour adresser une notification concernant Safari, choisissez Signaler un bogue à Apple dans le menu Safari.

La boîte de dialogue qui apparaît contient l'adresse de la page Web ouverte dans la fenêtre active. Cette information peut être précieuse pour évaluer votre problème.

Saisissez un brève description du problème dans la zone de texte. Décrivez, si possible, ce que vous faisiez lorsque le problème est survenu.

Pour envoyer une capture d'écran ou la source de la page en cours, cliquez sur Autres options, puis sélectionnez les éléments que vous souhaitez envoyer. Vous pouvez également indiquer le type de problème rencontré.

Une fois votre rapport terminé, cliquez sur Soumettre.

Safari envoie un message électronique à Apple accompagné des informations spécifiées. Si vous avez opté pour l'envoi d'une capture d'écran, Safari procède à la capture de la fenêtre Safari active, puis joint cette capture au message. Aucune information personnelle, telle que votre adresse électronique, n'apparaît dans le message envoyé. Par ailleurs, aucune réponse ne vous sera adressée.

Si vous adressez fréquemment des rapports, vous pouvez choisir Bogue dans le menu Présentation et ajouter le bouton Bogue à la barre des adresses.
