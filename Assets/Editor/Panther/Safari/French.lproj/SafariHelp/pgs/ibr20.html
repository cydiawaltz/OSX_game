Téléchargement de fichiers

Safari vous permet de télécharger facilement des fichiers sur Internet.

Cliquez sur le lien pour télécharger un fichier. La fenêtre Téléchargement affiche la progression du téléchargement en cours.

Si la fenêtre Téléchargements n'apparaît pas, choisissez Téléchargements dans le menu Fenêtre.

Pour interrompre le téléchargement d'un fichier, cliquez sur l'icône située à droite du nom de fichier dans la fenêtre Téléchargements. Cliquez de nouveau sur cette icône pour commencer le téléchargement du fichier.

Pour consulter un fichier téléchargé dans le Finder, cliquez sur la loupe située en regard du nom du fichier dans la fenêtre Téléchargements.

Une fois le fichier téléchargé, vous pouvez le trouver à l'emplacement spécifié dans le panneau Général des préférences Safari.

Si vous téléchargez une image disque au format de fichier MacBinary, BinHex ou gzip, Safari le décompresse automatiquement. De même, s'il contient un programme d'installation, Safari se charge de l'ouvrir.

Si vous téléchargez un fichier image disque, Safari le décompresse et monte le volume de l'image disque. De même, s'il contient un programme d'installation, Safari se charge de l'ouvrir.

Si vous téléchargez un fichier d'image disque Internet, Safari le décompresse automatiquement. De même, s'il contient un programme d'installation, Safari se charge de l'ouvrir. Safari place ensuite l'image disque dans la Corbeille. Si vous souhaitez conserver l'image disque, retirez-la de la Corbeille.

Si vous sélectionnez l'option permettant d'ouvrir des fichiers "sécurisés" lors de leur téléchargement dans la fenêtre générale des préférences Safari, le fichier s'ouvre, s'il est sécurisé. Parmi les fichiers de ce type figurent les images, les vidéos, les fichiers son, les documents texte et PDF, les images disque et les autres archives.

Pour masquer la fenêtre Téléchargements, cliquez sur le bouton Masquer situé dans la fenêtre. Vous pouvez également définir à quel moment Safari doit supprimer les éléments de la fenêtre Téléchargements à l'aide de la fenêtre Générales des préférences de Safari.

Safari télécharge des fichiers vers l'emplacement spécifié dans la fenêtre Général des préférences Safari. Pour sélectionner un nouvel emplacement, choisissez Autre dans le menu local "Enregistrer les fichiers téléchargés dans".
