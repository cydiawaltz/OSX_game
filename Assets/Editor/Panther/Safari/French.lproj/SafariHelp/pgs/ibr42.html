Je n'arrive pas à afficher un signet dans la barre des signets

Si la fenêtre est trop étroite pour afficher tous les signets, elle risque d'être cachée. Si une icône de sous-menu apparaît à l'extrémité droite de la barre des signets, cliquez dessus pour afficher les signets cachés.

Il est possible que vous ayez supprimé le signet de la barre. Dans ce cas, vous devez le rajouter à la barre.

Ouvrez la page et choisissez Ajouter un signet dans la fenêtre Signets. Donnez un nom à ce signet, puis choisissez-lui un emplacement dans le menu local.
