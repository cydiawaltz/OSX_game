Retour à votre page d'accueil

Votre page d'accueil est la page Web qui s'affiche lorsque vous ouvrez Safari ou une nouvelle fenêtre dans Safari. Safari est configuré pour ouvrir la page d'accueil spécifiée dans les préférences Internet.

Pour retourner directement sur votre page d'accueil, choisissez Accueil dans le menu Historique.

Pour sélectionner une nouvelle page d'accueil ou modifier les éléments affichés dans les nouvelles fenêtres Safari, choisissez Préférences dans le menu Safari, puis cliquez sur Général.

Lorsque vous cliquez sur un lien de votre page d'accueil, le bouton SnapBack apparaît à droite du champ adresse. Après avoir cliqué sur les autres liens, vous pouvez cliquer sur le bouton SnapBack pour retourner sur votre page d'accueil.
