Websider virker ikke

Hvis nogle funktioner på websiderne ikke virker, har du måske slået brug af plugin-arkiver, Java og JavaScript fra eller indstillet Safari til at blokere ekstra vinduer.

Vælg Indstillinger på Safari-menuen, og klik på Sikkerhed. Sørg for, afkrydsningsfelterne for plugin-arkiver, Java og JavaScript er valgt, og at afkrydsningsfeltet "Bloker ekstra vinduer" ikke er valgt.

Hvis disse emner ikke er valgt, og siden stadig ikke virker, skal du vælge Rapporter fejl til Apple på Safari-menuen for at gøre Apple opmærksom på fejlen.

Hvis du åbner websider, som du betragter som sikre, er der ingen sikkerhedsproblemer med at lade siderne bruge plugin-arkiver, Java og JavaScript.
