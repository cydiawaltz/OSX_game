Cómo controlar el contenido cargado por una página web

Cuando accede a una página web, puede controlar el contenido que se cargará. Por ejemplo, puede impedir que se carguen determinados tipos de contenido por motivos de seguridad o porque simplemente no desea visualizar dichos contenidos.

Para que no se carguen determinados contenidos, seleccione Preferencias en el menú Safari y haga clic en Seguridad. A continuación, deje sin marcar los contenidos que no desea visualizar.

Para bloquear las ventanas de aparición automática, seleccione la opción correspondiente. También puede elegir el comando "Bloquear ventanas de aparición automática" en el menú Safari.

Asimismo, puede decidir si desea aceptar cookies y cuáles se aceptarán.

Las páginas web suelen utilizar módulos y programas de Java y JavaScript para visualizar información. Si desactiva estas características, es probable que no pueda ver el contenido de algunas páginas.
