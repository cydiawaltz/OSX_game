Cómo rellenar automáticamente los formularios de las páginas web

Safari puede usar la información de su tarjeta de la Agenda para cumplimentar los formularios que debe rellenar en algunas páginas web. Safari también emplea los datos introducidos en formularios anteriores para rellenar nuevos formularios.

Para acelerar el acceso a determinados sitios web, Safari puede guardar los nombres de usuario y las contraseñas que introduce en los formularios de Internet.

En el panel Autorrelleno de las preferencias del navegador podrá especificar la información que usará Safari para rellenar formularios.

Seleccione Preferencias en el menú Safari y haga clic en Autorrelleno. Elija los elementos que desea que utilice Safari.

Para cumplimentar un formulario web, abra la página web y haga clic en el botón Autorrelleno de la barra de direcciones. Si este botón no está en la barra de direcciones, seleccione Autorrelleno en el menú Visualización. Los elementos introducidos mediante la función Autorrelleno aparecen de color amarillo en la página web.

Para rellenar campos individuales de un formulario, seleccione un campo de texto y empiece a escribir. Si Safari encuentra datos coincidentes para dicho campo, acabará de escribir el texto por usted. Si encuentra varios datos posibles, se abrirá un menú. Use las teclas de flecha para seleccionar el elemento adecuado y, a continuación, pulse la tecla Retorno.

Cuando introduce un nombre de usuario y una contraseña, Safari le pregunta si desea guardar la información. Haga clic en Sí para guardar el nombre y la contraseña. Haga clic en Ahora No si desea guardar los datos más adelante. Haga clic en "Nunca para este sitio web" si no quiere que Safari le vuelva a preguntar si desea guardar el nombre de usuario y la contraseña de este sitio web.

Si desea cambiar o borrar los nombres de usuario y las contraseñas que ha guardado, así como otros datos, haga clic en el botón Editar situado junto a la opción correspondiente en el panel Autorrelleno de las preferencias de Safari.
