Cómo bloquear las ventanas de aparición automática

Al abrir o cerrar algunas páginas web, se abren automáticamente otras ventanas. Por ejemplo, una página web puede usar una de estas ventanas para solicitarle sus datos de acceso a la página o para mostrar publicidad. Si lo desea, puede bloquear la aparición de este tipo de ventanas.

El bloqueo de las ventanas de aparición automática sólo afecta a las que se abren al abrir o cerrar una página web. No se bloquean las que se abren al hacer clic en un enlace.

Para bloquear las ventanas de aparición automática, seleccione esta opción en el menú Safari de manera que quede marcada.

También puede seleccionar Preferencias en el menú Safari y hacer clic en Seguridad. A continuación, marque la opción "Bloquear ventanas de aparición automática".

Si bloquea este tipo de ventanas, es posible que no pueda visualizar información importante de las páginas web.
