Descarga e instalación de software

Si descarga un archivo de imagen de disco, Safari lo descomprimirá de forma automática. Si el archivo descargado contiene un instalador, Safari se encargará de abrirlo. Para efectuar la instalación sólo tendrá que seguir las instrucciones que aparecerán en pantalla.

En caso de que descargue una imagen de disco de Internet que sirve para instalar software, Safari descomprimirá el archivo y abrirá el instalador. Una vez finalizada la instalación, Safari trasladará el archivo de imagen de disco a la Papelera. Si desea conservarlo para poder instalar el software de nuevo, deberá arrastrarlo fuera de la Papelera.
