Visualización del código HTML de una página web

Safari permite ver el código HTML de las páginas web. También puede guardar una página web para visualizarla posteriormente o usar su código fuente HTML.

Para ver el código fuente HTML de una página web, abra la página que desee y seleccione "Ver código fuente" en el menú Visualización.

Para guardar el código HTML de una página web, abra la página y seleccione Guardar Como en el menú Archivo. Escriba un nombre para el archivo, elija dónde guardarlo y haga clic en Guardar.

Al guardar la página, sólo se guarda el contenido de texto HTML de la página actual. No se guardarán los elementos de la página, como las imágenes, que aparecen en ella mediante una referencia en código HTML.
