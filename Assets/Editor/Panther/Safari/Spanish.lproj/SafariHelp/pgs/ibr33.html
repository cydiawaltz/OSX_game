Las páginas web no funcionan correctamente

Si algunas características de las páginas web no funcionan, es posible que haya desactivado el uso de módulos, de Java o de JavaScript, o que haya configurado Safari para que bloquee las ventanas de aparición automática.

Seleccione Preferencias en el menú Safari y haga clic en Seguridad. Compruebe que las opciones correspondientes al uso de módulos, de Java y de JavaScript estén seleccionadas y que la opción "Bloquear ventanas de aparición automática" no lo esté.

Si estos elementos no están seleccionados y la página no se ve correctamente, seleccione "Comunicar los errores a Apple" en el menú Safari para informar a Apple del problema.

Si abre páginas web seguras, el uso de módulos, de Java y de JavaScript no pondrá en peligro la seguridad del ordenador.
