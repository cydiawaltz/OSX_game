Cómo abrir sitios web Rendezvous

Safari utiliza Rendezvous para acceder a sitios web disponibles en su red o subred local.

Para ver los sitios web Rendezvous disponibles, haga clic en el icono de la biblioteca de favoritos situado en la barra de favoritos y elija Rendezvous en la columna Colecciones.

Si a través de Rendezvous hay alguna impresora disponible, puede que ésta aparezca listada como un sitio web Rendezvous. Puede abrir dicho sitio web para configurar la impresora.

Puede añadir sitios web Rendezvous a la barra de favoritos y al menú Favoritos mediante el panel Favoritos de las preferencias de Safari. También puede elegir la opción de mostrar los sitios web Rendezvous en la biblioteca de favoritos.
