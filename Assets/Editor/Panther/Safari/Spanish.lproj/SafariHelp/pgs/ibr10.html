Cómo volver a las páginas web visitadas

A medida que va accediendo a páginas web, Safari registra sus direcciones. Safari recuerda las páginas web visitadas durante la última semana.

Mediante el historial, puede volver rápidamente a una página web que haya visitado anteriormente.

Para volver a una página web visitada recientemente, haga clic en los botones Atrás y Adelante de la barra de herramientas. También puede pulsar uno de estos botones y elegir una página en el menú que aparece.

Para volver a una página web abierta anteriormente, selecciónela en el menú Historial. También puede hacer clic en Favoritos en la barra de favoritos y seleccionar el Historial para ver las páginas visitadas.

Si la página que desea abrir está marcada como página SnapBack para la ventana, haga clic en el botón SnapBack situado en el campo de dirección. La página SnapBack suele ser la primera página abierta en una ventana.
