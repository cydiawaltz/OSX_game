Una página web no se abre

Hay varios motivos por los que una página web puede no abrirse en Safari. Si no consigue acceder a una página, realice las comprobaciones que le indicamos a continuación.

Cuando una página no pueda abrirse, consulte el mensaje de error que aparece, ya que puede contener información importante para solucionar el problema.

Compruebe que la dirección de la página es correcta y está bien escrita.

A veces, algunas páginas web no están disponibles temporalmente.

Si la página está situada en la red o en Internet, compruebe que está conectado.

Si intenta abrir una página utilizando una dirección Rendezvous, asegúrese de que la página está en la misma subred que su ordenador.

Algunos sitios web bloquean los navegadores que no reconocen. Póngase en contacto con el administrador del sitio web para saber si se trata de este caso.

Si una página web no se abre, puede comunicar el problema a Apple seleccionando Safari > "Comunicar errores a Apple".
