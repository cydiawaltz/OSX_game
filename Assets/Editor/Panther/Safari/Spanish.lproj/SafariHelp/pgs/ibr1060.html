Cómo imprimir páginas web

Puede utilizar el comando estándar Imprimir en el menú Archivo para imprimir una página web. Si la página web consta de varios marcos, puede imprimir el marco que desee.

Para imprimir una página web, abra la página en Safari y elija la opción Imprimir en el menú Archivo.

Para imprimir un marco de una página web, mantenga pulsada la tecla Control y haga clic en el marco que desee imprimir. A continuación, elija la opción Imprimir Marco en el menú de función rápida.

También puede crear un archivo PDF a partir de la página web o enviar un fax con la página utilizando el cuadro de diálogo Imprimir.
