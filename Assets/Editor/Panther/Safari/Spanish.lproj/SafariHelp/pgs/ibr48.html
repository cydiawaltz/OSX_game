Cómo borrar nombres de usuario y contraseñas guardados

Si selecciona la opción de rellenar automáticamente los nombres de usuario y las contraseñas en el panel Autorrelleno de las preferencias, Safari guardará todos los nombres y contraseñas que introduzca en los formularios web. Puede eliminar esta información si, por ejemplo, teme que alguien pueda acceder a sus datos de autenticación.

Si seleccionó la opción "Nunca para este sitio web" al escribir el nombre de usuario y la contraseña de un sitio web, puede borrar el elemento guardado para esta página web de manera que pueda guardar la información.

Seleccione Preferencias en el menú Safari y haga clic en Autorrelleno. Haga clic en Editar junto a la opción "Nombres de usuario y contraseñas". Elija el elemento que desea borrar y haga clic en Eliminar.

Si anteriormente había seleccionado la opción "Nunca para este sitio web" al escribir el nombre de usuario y la contraseña de un determinado sitio web y después cambia de opción y desea guardar esta información, elija "Las contraseñas nunca se guardan" y haga clic en Eliminar.

Si desea borrar todos los elementos, haga clic en Eliminar Todo.

No es necesario que borre la información guardada de un sitio web si su nombre de usuario o contraseña cambian. En el formulario, sustituya el nombre y la contraseña actuales por unos nuevos cuando abra la página web. Safari le preguntará si desea guardar los nuevos datos.
