Acerca de Safari

A continuación se destacan las principales características de Safari. Para aprender más sobre este navegador, consulte la Ayuda Safari y visite la página web de Safari.

Búsqueda en Google integrada

Safari incluye en la barra de direcciones una función de búsqueda con el motor de búsquedas Google. Sólo tiene que escribir su consulta en el campo de búsqueda y pulsar Retorno. Para volver a la página de resultados de la búsqueda después de visitar diversas páginas web, haga clic en el botón SnapBack del campo de búsqueda de Google. Para repetir una búsqueda reciente, pulse el icono de la lupa.

Uso de la función SnapBack durante la navegación

Safari incluye los habituales botones Atrás y Adelante en la barra de direcciones para navegar por Internet. Mientras está navegando a partir de una página web inicial, puede volver rápidamente a ella pulsando el botón SnapBack del campo de dirección.

Navegación mediante pestañas

Cuando hace clic en un enlace para abrir otra página web, puede abrirla en una pestaña de la ventana actual en vez de hacerlo en una nueva ventana. Incluso puede abrir una carpeta de favoritos en múltiples pestañas con un solo clic del ratón.

Gestión fácil de los favoritos

Cuando encuentra una página web de su interés, puede guardar la dirección de la página en la lista de favoritos. Safari ofrece nuevas formas de crear favoritos y ordenarlos.

Al crear un favorito de una página web, puede añadirlo fácilmente a la barra de favoritos o al menú Favoritos. La biblioteca de favoritos le facilita la tarea de ordenar los favoritos de la manera que desee.

La barra de favoritos (situada bajo la barra de direcciones) permite abrir los favoritos de manera rápida. Mediante la biblioteca de favoritos, puede añadir carpetas de favoritos a la barra, así como favoritos individuales.

Safari también emplea favoritos dinámicos, como el historial de las páginas web visitadas recientemente. Asimismo, incluye sitios web de la Agenda y de cualquier sitio Rendezvous disponible en la red local.

Si anteriormente utilizaba el navegador Microsoft Internet Explorer, Netscape o Mozilla, Safari importará los favoritos de estos navegadores la primera vez que lo abra. Encontrará las carpetas con estos favoritos en la biblioteca de favoritos.

Sincronización de favoritos

Si utiliza iSync 1.1 y su cuenta .Mac, puede sincronizar automáticamente los favoritos de Safari entre diversos ordenadores para que siempre pueda acceder a sus páginas web preferidas.

Cómo bloquear las ventanas de aparición automática

Safari puede bloquear las ventanas que aparecen de forma automática mientras navega para que vea sólo las páginas web que desee. Sólo tiene que seleccionar el comando "Bloquear ventanas de aparición automática" en el menú Safari.

Autorrelleno de formularios

Safari simplifica el uso de Internet para realizar compras y negocios. Si ajusta las opciones del panel Autorrelleno de las preferencias de Safari, el navegador le ayudará a rellenar los formularios de acceso a sitios web seguros.

Máxima seguridad

Safari emplea funciones de seguridad estándares en Internet para protegerle a usted y su información. Abra el panel Seguridad de las preferencias de Safari para definir las opciones de seguridad.

Mantenimiento de la privacidad

Si utiliza un ordenador con acceso público, puede borrar cualquier registro sobre usted que Safari haya guardado. Elija Restaurar Safari en el menú Safari para borrar el historial de las páginas web visitadas, vaciar la caché, eliminar los archivos descargados, borrar las búsquedas de Google y eliminar las cookies, los nombres guardados, las contraseñas y cualquier otro texto de Autorrelleno.

Internacionalización

Safari emplea la compatibilidad del Mac OS X con Unicode para poder visualizar sitios web en idiomas pertenecientes a diversos sistemas de escritura, como japonés, chino, hebreo y árabe, además de inglés y otros idiomas románicos.
