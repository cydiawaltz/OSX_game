Cómo navegar por Internet

Safari es un navegador web rápido y fácil de usar. Safari facilita la búsqueda de sitios web utilizando el motor de búsqueda de Google. Descubrirá métodos prácticos para gestionar y utilizar los favoritos, así como excelentes utilidades, como un sistema de bloqueo de ventanas de aparición automática.

Haga clic en un elemento de la izquierda para ver la ayuda acerca de este tema. Para encontrar las respuestas a sus preguntas, escriba una palabra o una frase en el campo situado en la parte superior de esta ventana y, a continuación, pulse la tecla Retorno.
