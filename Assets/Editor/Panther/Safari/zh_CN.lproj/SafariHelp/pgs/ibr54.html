指定代理服务器

如果您的电脑通过接入有防火墙保护的网络来访问 Internet，您可能需要指定代理服务器来访问网页和其它 Internet 资源。您的浏览器将浏览网页的请求发送到代理服务器，然后代理服务器为您取回请求的页面。

如果您要指定代理服务器，网络管理员应该为您提供所需信息。此信息应当包括要指定的代理服务器的类型（如网络代理服务器）、服务器的 IP 地址或 DNS 名称以及端口号。

您可以使用“网络”预置来指定代理服务器信息。您可以用 Safari 预置来打开相应的“网络”预置。

从 Safari 菜单中选取“预置…”并点按“高级”，然后点按“更改设置…”。

“系统预置”的“网络”面板会打开，其中显示了您所使用的连接类型的代理设置。选择代理服务器所属类型的注记格（例如 Web Proxy）。在第一个文本框中输入网络管理员提供的 IP 地址或 DNS 名称，在第二个文本框中输入端口号。一切就绪后，点按“现在应用”。
