打开网页

第一次打开 Safari 时，它会打开 Internet 预置中指定的首页。您可以通过多种方式来打开网页。

要从正在查看的页面中打开其链接到的页面，请点按此链接。

要打开没有链接的页面，请在地址栏的文本框中键入其地址，然后按下 Return 键。

要打开已设置了书签的页面，请点按书签栏中的项目，从“书签”菜单选择一个项目或者连按“书签库”中的书签。

如果书签栏或“书签”菜单中的项目旁边有三角形，那么它就是一个书签收藏夹。选择该项目后，您会看到收藏夹中的所有书签，然后就可以从列表中选择想要打开的页面。

要打开以前曾打开过的页面，请键入它的地址的一部分。Safari 则会自动显示完整地址，或显示一列匹配的地址。如果看到该列表，请用箭头键或鼠标指针选择一个地址，然后按下 Return 键以打开该页面。

要在当前窗口前面的新窗口中打开一个页面，请按住 Command 键并点按链接或书签。要在当前窗口后面打开新窗口，请按住 Command 和 Shift 键。如果您在 Safari 预置的“标签”面板中选择了“启用标签式浏览”，那么这些迅捷会改变。

要打开硬盘或文件服务器上的页面，请从“文件”菜单选取“打开文件…”。

如果 Safari 是预设网络浏览器，则当您点按其它应用程序中的链接（如 Mail 邮件）或者连按 Web Internet 位置类型文件时，网页在 Safari 中自动打开。您可以使用 Safari 预置中的“通用”面板来选择是否在新窗口或当前窗口中打开页面。如果您选用标签进行浏览，并选择打开当前窗口中的链接，那么它们会在新的标签中打开。

如果在其它应用程序的文稿中选中 URL，并从应用程序菜单中选择“服务”，然后选取“在 Safari 中打开 URL”，您就可以从其它应用程序的文稿中打开网页。
