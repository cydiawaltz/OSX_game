Safari 迅捷方式

您可以在菜单命令的旁边看到许多 Safari 的迅捷键。以下是一些额外的迅捷方式。

操作

迅捷

将书签添加到“书签”菜单

打开页面，然后按下 ⌘ + Shift + D

将书签添加到“书签”菜单

将页面图标从地址栏拖拽到书签栏

在书签栏上移动书签

左右拖移书签

从书签栏移去书签

将书签拖拽到书签栏外

在“书签库”中更改书签的名称或地址

点按书签选取它，然后按下 Return 键

选择要更改的下一个书签名或地址（如果已选中“书签库”中的书签文本）

按下 Tab 键

在“书签库”中完成书签文本的编辑

按下 Return 键

删除“书签库”中的书签

选取书签并按下 Delete 键

上下左右滚动选项

箭头键

大幅滚动选项

Option + 箭头键

向下滚动屏幕

Page Down 键
Space 键

向上滚动屏幕

Page Up 键
Shift + Space 键

在新窗口中打开页面（如果已关闭标签式浏览）

⌘ + 点按链接或书签

在当前窗口后面的新窗口中打开页面（如果已关闭标签式浏览）

⌘ + Shift + 点按链接或书签

在标签中打开书签栏的文件夹里包含的全部书签

⌘ + 点按书签栏中的文件夹

关闭全部标签，只保留其中一个

Option + 在您要保持打开的标签上点按关闭按钮

按名称查看近期页面的列表

按住后退或前进按钮

按地址查看近期页面的列表

按住 Option +“后退”或“前进”按钮

在 Finder 中查看已下载的文件

点按“下载”窗口中的文件旁的图标
