Deleting saved user names and passwords

If you select the option in the AutoFill preferences pane to automatically complete user names and passwords, Safari saves any names and passwords you enter in web forms. You can delete this information if, for example, you are concerned about someone else having access to your authentication information.

If you selected "Never for this Website" when you entered a name and password for a website, you can delete the item saved for the website so that you can save the information.

Choose Preferences from the Safari menu and click AutoFill. Click Edit next to the "User names and passwords" checkbox. Select the item you want to delete and click Remove.

If you selected "Never for this Website" when you entered a name and password for a website and you want to save the information now, select the "Never Save Passwords" item and click Remove.

If you want to delete all the items, click Remove All.

You do not need to delete the saved information for a website if your user name or password changes. In the form, replace the current name and password with the new one when you open the webpage. Safari asks if you want to save the new information.
