Printing webpages

You can use the standard Print command in the File menu to print a webpage. If the webpage consists of several frames you can print the specific frame you want to print.

To print a webpage, open the page in Safari and choose Print from the File menu.

To print a frame of a webpage, hold down the Control key and click the frame you want to print. Then choose Print Frame from the shortcut menu.

You can also create a PDF of the webpage or send a fax of it using the Print dialog.
