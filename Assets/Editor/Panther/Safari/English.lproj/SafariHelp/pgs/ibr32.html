Text in a webpage is garbled

Text in a webpage may appear garbled if the page uses characters that are not part of your default text encoding and the page does not specify the correct encoding.

To change the encoding for a page, choose Text Encoding from the View menu then choose an encoding appropriate for the language used in the page.

If pages you open frequently have garbled text, you may want to change your default text encoding. Choose Preferences from the Safari menu and click Appearance. Choose an appropriate encoding from the Default Encoding pop-up menu.
