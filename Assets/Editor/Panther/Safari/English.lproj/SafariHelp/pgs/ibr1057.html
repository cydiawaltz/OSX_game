Downloading and installing software

If you download a disk image file, Safari automatically decompresses it. If the file contains an installer, Safari opens the installer for you. Just follow the onscreen instructions to complete the installation.

If you download an Internet Disk Image that installs software, Safari decompresses the file and opens the installer for you. After the installation is completed, Safari moves the disk image file to the Trash. If you want to keep the disk image to install the software again, drag it out of the Trash.
