Returning to the SnapBack page

The first page you open in a window is the SnapBack page. Safari remembers this page so you can quickly return to it after opening other webpages.

To return to the SnapBack page, click the SnapBack button in the address box.

Each window has only one SnapBack page. To mark a new SnapBack page for a window, open the page then choose Mark Page for SnapBack from the History menu.

A page is also marked as the SnapBack page when you open it by typing its address in the address box, open it using a bookmark, or choose it from the History menu.

If you perform a Google search or click the SnapBack button in the Google search box, Safari removes the SnapBack button from the address box, if there is one.
