I can't see a bookmark on the bookmarks bar

If the window is too narrow to show all the bookmarks, it may be hidden. If you see a right-pointing icon at the right end of the bookmarks bar, press it to see any additional bookmarks.

You might have removed the bookmark from the bar. If so, you'll need to add it to the bar again.

Open the page and choose Add Bookmark from the Bookmarks window. Type a name for the bookmark and choose a location from the pop-up menu.
