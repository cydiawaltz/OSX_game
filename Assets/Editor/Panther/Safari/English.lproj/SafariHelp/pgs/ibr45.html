Setting how links open from other applications

If Safari is your default web browser, webpages open in Safari when you click links in other applications, such as Mail, or when you double-click the icons of Web Internet Location files. You can select whether pages open in a new window or the current window.

Choose Preferences from the Safari menu and select the "Open links from applications" option you want to use.

If you enable tabbed browsing and select "in the current window," the pages open in a new tab in the current window.
