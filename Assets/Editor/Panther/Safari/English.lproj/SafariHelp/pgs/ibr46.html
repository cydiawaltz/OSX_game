Setting the way tabbed browsing works

You can set how tabbed browsing works using the Tabs pane of Safari preferences.

Choose Preferences from the Safari menu and click Tabs.

To browse webpages using tabs, select the Enable Tabbed Browsing checkbox.

To open new tabs in front of the current tab, select the "Select new tabs as they are created" checkbox.

Select the "Always show tab bar" checkbox to see a tab even if you have only one webpage open.

Enabling tabbed browsing or selecting to open new tabs in front of the current tab changes the shortcuts you can use to open pages in new tabs and new windows. The list at the bottom of the Tab pane shows you what shortcuts to use depending on how you have set up tabbed browsing.
