Safari について

以下に、「Safari」が搭載する機能の概要を示します。「Safari」の詳細については、「Safari ヘルプ」や「Safari」の Web サイトを参照してください。

Safari に組み込まれた Google 検索

「Safari」の「アドレスバー」には、Google 検索の機能が組み込まれています。探したいものを「Google 検索」ボックスに入力し、return キーを押すだけです。ほかの Web ページを見た後で、一番最近の検索結果に戻るには、「Google 検索」ボックスの SnapBack ボタンをクリックします。最近の検索を繰り返して行うには、虫眼鏡を押します。

ブラウズの途中、SnapBack で戻る

「アドレスバー」にある「前へ戻る」／「次へ進む」ボタンをはじめ、「Safari」には Web ページをブラウズするための標準的な手段が備わっています。次々にブラウズした後でも、「アドレスボックス」の「SnapBack」ボタンをクリックすれば、最初に見ていた Web ページへ簡単に戻ることができます。

タブを使ってブラウズする

別の Web ページへのリンクを開く場合、新規ウインドウを開かず、現在のウインドウに新規タブを開いて表示することができます。クリック 1 つで、「ブックマークフォルダ」に入っているすべてのブックマークを、それぞれタブで開くことさえできます。

簡単なブックマーク

面白い Web ページを見つけたら、アドレスを保存、つまり「ブックマーク」しておきましょう。「Safari」には、ブックマークを追加／整理して機能的に使うための、画期的な方法が用意されています。

Web ページをブックマークする場合は、簡単にブックマークバーや「ブックマーク」メニューに追加することができます。ブックマークライブラリを使って、お好みの方法で簡単にブックマークを整理できます。

ブックマークバー（「アドレスバー」の下にあります）を使って、ブックマークをすばやく開くことができます。ブックマークライブラリを使えば、個々のブックマークはもちろん「ブックマークフォルダ」も、ブックマークバーに追加することができます。

「Safari」にはまた、最近開いた Web ページの履歴など、自動ブックマークの機能も備わっています。これには、「アドレスブック」に記載のある Web サイトや、Rendezvous 経由で使うことのできる、ローカルネットワーク上の Web サイトも含まれます。

Microsoft 社の「Internet Explorer」や、「Netscape」、「Mozilla」などをお使いの場合、「Safari」を最初に開いたときに、それらのブラウザの「お気に入り」やブックマークが読み込まれます。このようなブックマークの入ったフォルダは、ブックマークライブラリにあります。

ブックマークの同期

iSync 1.1 と「.Mac」のメンバーシップがあれば、別々のコンピュータの間で「Safari」のブックマークを自動的に同期し、指定した Web ページをいつでも見ることができます。

ポップアップウインドウの表示をブロックする方法

「Safari」では、ポップアップウインドウを表示しないようにできますので、見たい Web ページだけを見ることができます。これには、「Safari」メニューで「ポップアップウインドウを開かない」を選択するだけです。

フォームの記入をより簡単に

「Safari」を使えば、インターネットを利用した買い物や仕事がより簡単になります。「Safari」メニューの「環境設定」で「自動入力」を表示し、オプションを選択すると、フォームの記入や、セキュリティ保護された Web サイトへのログインが簡単になります。

必要な場面でのセキュリティ

「Safari」には、インターネットの標準的なセキュリティ機能が備わっており、あなたとあなたの大事な情報とを守ります。「Safari」メニューの「環境設定」で「セキュリティ」を選び、セキュリティに関するオプションを選択します。

プライバシーを守るリセット機能

共用のコンピュータをお使いの場合に、「Safari」に保存された個人情報の記録を、すばやく消去することができます。「Safari」メニューの「Safari をリセット」を選ぶだけで、ブラウズした Web ページの履歴を消去し、キャッシュを空にし、ダウンロードしたファイルや Google 検索での入力の記録を消し、Cookie を削除し、保存した名前、パスワードほかの自動入力用テキストを削除します。

多言語機能

「Safari」は Mac OS X のサポートする Unicode で動作しますので、英語などのヨーロッパ系言語はもちろん、日本語、中国語、ヘブライ語、アラビア語などのような、特殊な表記法によるサイトを表示することができます。
