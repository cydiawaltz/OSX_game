Safari ショートカット

メニューコマンドの横に、「Safari」で使用できるショートカットが表示されています。以下は、メニューに表示されないショートカットです。

操作

ショートカット

「ブックマーク」メニューにブックマークを追加する

ページを開いて、コマンド + shift + D キーを押す

ブックマークバーにブックマークを追加する

ページのアイコンをアドレスボックスからバーにドラッグする

ブックマークバーにブックマークを移動する

ブックマークを右や左にドラッグする

ブックマークバーからブックマークを削除する

ブックマークをバー上方にドラッグする

ブックマークライブラリで、ブックマークの名前やアドレスを変更する

ブックマークをクリックして選択し、return キーを押す

ブックマークライブラリで、ブックマークの名前またはアドレスが選択されているとき、次の名前／アドレスを選択する

tab キーを押す

ブックマークライブラリで、ブックマークの名前やアドレスの編集を終える

return キーを押す

ブックマークライブラリで、ブックマークを削除する

目的のブックマークを選択し、delete を押す

画面を上下左右にスクロールする

矢印キー

大きくスクロールする

option + 矢印キー

画面を下にスクロールする

page down キー
スペースバー

画面を上にスクロールする

page up キー
shift キー + スペースバー

タブブラウズがオフのとき、新規ウインドウでページを開く

コマンドキーを押しながらリンクまたはブックマークをクリック

タブブラウズがオフのとき、新規ウインドウでページを開いて現在のウインドウの背面に配置する

コマンド + shift キーを押しながらリンクまたはブックマークをクリック

ブックマークバーで、「ブックマークフォルダ」の中にあるブックマークを、すべてタブで開く

コマンドキーを押しながらブックマークバーにあるフォルダ名をクリック

1 つだけ残して、ほかすべてのタブを閉じる

開いたままにしておきたいタブの、閉じるボタンを、option キーを押しながらクリックする

最近開いたページを、名前のリストで表示する

「前へ戻る」／「次へ進む」ボタンを押し続ける

最近開いたページを、アドレスのリストで表示する

option キーを押しながら「前へ戻る」／「次へ進む」ボタンを押し続ける

ダウンロードしたファイルを Finder で見る

「ダウンローダー」ウインドウでファイル名の隣に表示される虫眼鏡アイコンをクリックする
