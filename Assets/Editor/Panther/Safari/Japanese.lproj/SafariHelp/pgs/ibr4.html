Web ページを開く方法

「Safari」を初めて開くと、インターネット環境設定で指定したホームページが表示されます。ここから Web ページを開くには、いくつかの方法があります。

現在表示しているページからリンクされているページを開くには、リンクをクリックします。

リンクを使わずにページを開くには、アドレスバー内のテキストボックスにアドレスを入力して return キーを押します。

ブックマークに追加したページを開くには、ブックマークバーの項目をクリックするか、ブックマークメニューから項目を選択します。ブックマークライブラリ内ののブックマークをダブルクリックしても、ページを開くことができます。

ブックマークバーまたは「ブックマーク」メニューの項目に三角形のマークが付いていたら、その項目はブックマークのコレクションです。項目を選ぶと、コレクションの中のすべてのブックマークが見え、開きたいページを一覧から選択できます。

以前に開いたページであれば、アドレスの一部を入力するだけで開くことができます。「Safari」は、アドレスの残りの部分を自動入力するか、またはアドレスに一致するリストを表示します。リストが表示されたら、矢印キーまたはポインタを使用してアドレスを選択し、return キーを押してページを開きます。

現在表示しているウインドウの前面で新規ウインドウにページを開くには、コマンドキーを押しながらリンクまたはブックマークをクリックします。現在表示しているウインドウの後ろにインドウを開くには、コマンドキーと shift キーを押しながらクリックします。「Safari」環境設定で開ける「タブ」パネルで「タブブラウズを利用する」を選択すると、これらのショートカットは変更されます。

ハードディスクやファイルサーバにあるページを開くには、「ファイル」メニューで「ファイルを開く」を選択します。

「Safari」がデフォルトの Web ブラウザに設定されている場合、Mail メッセージなど、ほかのアプリケーション内でリンクをクリックしたり、Web インターネットロケーションファイルのアイコンをダブルクリックしたりすると、Web ページが「Safari」で開きます。「Safari」環境設定の「一般」パネルを使用して、ページを新規ウインドウに開くか、現在表示しているウインドウに開くかを選択できます。タブブラウズを有効にし、現在表示しているウインドウにリンクを開くように選択している場合、ページは新規タブに開かれます。

ほかのアプリケーションの書類から Web ページを開くには、URL を選択してアプリケーションメニューから「サービス」を選択し、「「Safari」で URL を開く」を選択します。
