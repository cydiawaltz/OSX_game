タブを使用して Web ページをブラウズする方法

タブブラウズをオンにすると、現在開いているウインドウや新規ウインドウではなく、タブで Web ページを開くことができます。

タブを使って Web ページを表示すると、ウインドウをいくつも開く必要がないので、たくさんのページを一度に開くのに便利です。

ページをタブで開くと、ブックマークバーの下にタブバーが表示されます。タブバーのタブにページの名前が表示されます。

ブックマークのコレクションをタブで開くこともできます。あるページを閲覧している間に、ほかのページを読み込めます。

タブブラウズをオフにするには、「Safari」メニューから「環境設定」を選択し、「タブ」をクリックします。「タブブラウズを利用する」を選択します。

リンクやブックマークバーにあるブックマークを新規タブで開くには、コマンドキーを押しながらクリックするか、Control キーを押しながらクリックし、コンテクストメニューから「新規タブで開く」を選びます。

ブックマークバー内のブックマークコレクションや、ブックマークライブラリ内のブックマークフォルダをタブで開くには、Control キーを押しながら「ブックマークコレクション」または「ブックマークフォルダ」をクリックし、コンテクストメニューから「すべてをタブで開く」を選びます。

ブックマークバー内のフォルダに「自動タブ」チェックボックスを選択した場合は、ブックマークバーでフォルダの名前をクリックすると、フォルダの中のブックマークすべてをタブで開くことができます。

Web ページを新規タブで開くには、「ファイル」メニューから「新規タブ」を選択し、ページのアドレスを入力します。

タブを閉じるには、タブに表示されているクローズボタンをクリックします。

あるタブに表示されている Web ページを残し、それ以外のタブをすべて閉じるには、option キーを押しながら残したいタブのクローズボタンをクリックします。

タブで表示されているページに含まれるリンクをクリックすると、ページは現在表示されているタブに開かれます。タブに開いたことのあるページを移動するには、アドレスバーの「前へ戻る」／「次へ進む」ボタンをクリックします。

「履歴」メニューまたは「ブックマーク」メニューからページを選択すると、ページは現在表示されているタブに開かれます。

タブブラウズをオフにすると、ウインドウを開くためのショートカットが変更されます。たとえば、新規ウインドウでページを開くには、コマンド + option キーを押しながらリンクをクリックします。「タブ」パネルの下部に、タブブラウズの設定内容に応じたショートカットが示されます。

ほかのアプリケーションに含まれるリンクを現在表示しているウインドウで開くように選択し、タブブラウズを有効にすると、ページは現在表示しているウインドウの新規タブに開かれます。
