Cookie を管理する方法

サイトとの転送作業を容易にするため、Web サイトはお使いのコンピュータに Cookie という情報を保存します。多くの場合、Cookie は無害です。一部の Web サイトについては、Cookie を受け入れないとサイトを使用できない場合があります。

Cookie の受け入れに不安がある場合は、「Safari」での処理方法を設定することができます。

「Safari」メニューから「環境設定」を選択して、「セキュリティ」をクリックします。お使いのコンピュータに Cookie を保存したくない場合は、「受け入れない」を選択します。この操作により、一部の Web サイトが使用できなくなる場合があります。

すべての Cookie を受け入れて保存するには、「常に受け入れる」をクリックします。

開いているもの以外の Web サイトから来た Cookie を保存しないようにするには、「訪問したページのサーバからのみ受け入れる」をクリックします。このオプションを選択して、訪問した Web サイトにあった広告プログラムが、お使いのコンピュータに Cookie を保存しないようにします。

お使いのコンピュータに保存されている Cookie を見るには、「Cookie を表示する」をクリックします。Cookie を削除するには、リストから選択して「削除」をクリックします。

Cookie の受け入れを停止する場合は、「セキュリティ」パネルで「受け入れない」を選択した後に、Cookie をすべて削除する必要があります。

Cookie を一時的に受け入れないとページを開けない場合があります。Cookie を受け入れてページを開くには、「常に受け入れる」を選択します。ページを表示したら、Cookie の受け入れをオフにしてかまいません。ページを見終わったら Cookie を削除するのも一案です。
