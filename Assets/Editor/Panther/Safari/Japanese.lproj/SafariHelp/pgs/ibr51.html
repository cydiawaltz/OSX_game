Web ページの HTML ソースを表示する方法

「Safari」で Web ページの HTML ソースコードを表示することができます。後で表示したり、HTML コードの手本に使ったりできるように、Web ページを保存することができます。

Web ページの HTML ソースを表示するには、表示するページを開いて、「表示」メニューから「ソース表示」を選択します。

Web ページの HTML ソースを保存するには、保存するページを開いて、「ファイル」メニューから「別名で保存」を選択します。ファイル名を入力して保存場所を選択し、「保存」をクリックします。

ページの保存では、現在のページの、HTML テキストの内容だけが保存されます。写真など、ページの HTML コードで参照されているページの要素は保存されません。
