ブックマークメニューを整理する方法

「ブックマーク」メニューに追加したブックマークを整理できます。

「ブックマーク」メニューにブックマークを追加するには、対象となる Web ページを開き、アドレスバーにあるブックマーク追加用のボタンをクリックします。ブックマークの名前を入力し、ポップアップメニューから「ブックマークメニュー」を選択します。

メニュー内のブックマークを整理するには、「ブックマーク」メニューから「すべてのブックマークを表示」を選択し、「ブックマークメニュー」をクリックします。各項目を上下にドラッグして、順番を並び替えます。ブックマークを削除するには、項目を選択して delete キーを押します。

メニュー内にブックマークのフォルダを作成すると、メニューのサブメニューとして表示されます。フォルダを作成するには、「ブックマーク」欄の下にある追加（＋）ボタンをクリックし、作成したフォルダにブックマークをドラッグします。

ブックマークまたはフォルダの名前を変更するには、該当するものを選択して return キーを押します。

「Safari」の「環境設定」にある「ブックマーク」パネルを使うと、「アドレスブック」や Rendezvous の項目を「ブックマーク」メニューや「ブックマークライブラリ」に追加できます。これらの項目には、「アドレスブック」のカードに含まれる Web サイトや、ローカルネットワークの Rendezvous Web サイトが含まれます。
