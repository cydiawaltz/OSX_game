Web フォームから保存したデータを削除する方法

ほかの Web ページからの情報を使用して Web フォームを自動入力するオプションを選択すると、入力する情報が「Safari」に保存されます。この情報は、必要に応じて削除することができます。

「Safari」メニューから「環境設定」を選択して、「オートフィル」をクリックします。「他のフォーム」チェックボックスの隣にある「編集」をクリックします。削除する項目を選択して、「取り除く」をクリックします。項目をすべて削除する場合は、「すべてを取り除く」をクリックします。

ほかの Web フォームからのデータを使用しない場合は、「Safari」環境設定の「タブ」パネルで「他のフォーム」チェックボックスの選択を外します。
