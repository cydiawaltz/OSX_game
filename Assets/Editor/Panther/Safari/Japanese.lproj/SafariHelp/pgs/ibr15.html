ブックマークを整理する方法

ブックマークライブラリでは、ブックマークバーや「ブックマーク」メニューなどに入れられたブックマークを整理することができます。

「アドレスブック」、「Rendezvous」、あるいは「履歴」内の項目は整理できません。ただし、「履歴」内の項目を削除することはできます。

ブックマークライブラリを表示するには、ブックマークバーの左端にあるアイコンをクリックします。

ブックマークライブラリの左側の欄には、ブックマークバー、「ブックマークメニュー」、「アドレスブック」、「Rendezvous」、「履歴」など、ブックマークのコレクションが表示されます。

右側の欄には、ブックマークの名前とアドレスが表示されます。ブックマークを含むほかのフォルダも表示されます。

あるコレクションをクリックすると、そのコレクションの内容が表示されます。

ブックマークをコレクションに移動するには、移動したいブックマークのアイコンをコレクションの名前の部分にドラッグします。ブックマークをコレクションにコピーするには、option キーを押しながらそのブックマークのアイコンをドラッグします。ブックマークをコレクション内のフォルダに移動やコピーする方法も同じです。

新しいコレクションを作成するには、「コレクション」欄の下部にある追加（＋）ボタンをクリックします。コレクション内に新しいフォルダを追加するには、コレクションを選択して、「ブックマーク」欄の下部にある追加（＋）ボタンをクリックします。

コレクションを並べ替えるには、各コレクションを上下にドラッグします。コレクションを別のコレクションに追加するには、追加するコレクションのアイコンを追加先のコレクションにドラッグします。

コレクション内のフォルダやブックマークを並べ替えるには、コレクションを選択して、目的のフォルダやブックマークのアイコンを上下にドラッグします。

項目の名前を変更するには、名前を選択して return キーを押します。新しい名前を入力し、再び return キーを押してください。ブックマークのアドレスを変更することもできます。

コレクション、コレクション内のフォルダ、またはブックマークを削除するには、削除したい項目を選択して delete キーを押します。
