Safari をデフォルト Web ブラウザに設定する方法

「Safari」をデフォルト Web ブラウザに設定することができます。設定すると、Mail のメッセージなどの書類内のリンクをクリックしたり、Finder で Web インターネットロケーションファイルをダブルクリックしたりすると、自動的に「Safari」が開きます。

「Safari」はこれらのページを新規ウインドウに開くように設定されていますが、現在表示しているウインドウのタブページとして開くように選択することもできます。

「Safari」メニューから「環境設定」を選択して、「一般」をクリックします。「デフォルト Web ブラウザ」ポップアップメニューから「Safari」を選択してください。

「他のアプリでリンクを開く場合」から使用するオプションを選択します。現在表示しているウインドウにページを開くように選択し、「Safari」環境設定の「タブ」パネルで「タブブラウズを利用する」を選択すると、現在表示しているウインドウにページが新規タブとして開きます。

ほかのプログラムの中には、リンクをクリックすると、デフォルトのブラウザとは別のブラウザで Web ページを開くものもあります。
