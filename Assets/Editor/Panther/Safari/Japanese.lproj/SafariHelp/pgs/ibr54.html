プロキシサーバを指定する方法

ご使用のコンピュータからファイアウォールで保護されたネットワークに接続してインターネットにアクセスする場合、Web ページおよびほかのインターネットソースにアクセスするために、プロキシサーバの指定が必要になる場合があります。ブラウザは Web ページ要求をプロキシサーバに送信します。プロキシサーバが代わりにページを取得します。

プロキシサーバを指定する必要がある場合は、ネットワーク管理者から必要な情報を得る必要があります。情報として必要なものは、指定するプロキシサーバの種類（たとえば、Web プロキシサーバ）、サーバの IP アドレスまたは DNS 名、およびポート番号です。

ネットワーク環境設定を使用して、プロキシサーバの情報を指定します。「Safari」環境設定を使用して、適切なネットワーク環境設定パネルを開くことができます。

「Safari」メニューから「環境設定」を選択し、「アドバンス」パネルを開いて「設定の変更」をクリックします。

システム環境設定の「ネットワーク」パネルが開き、使用している接続タイプのプロキシ設定が表示されます。プロキシサーバのタイプに該当するチェックボックスを選択します（たとえば、「Web プロキシ（HTTP）」）。最初のテキストボックスにネットワーク管理者から入手した IP アドレスまたは DNS 名を入力し、2 つ目のボックスにポート番号を入力します。入力が完了したら、「今すぐ適用」をクリックします。
