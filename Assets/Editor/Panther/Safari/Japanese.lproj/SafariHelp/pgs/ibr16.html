ほかのブラウザからブックマークを読み込む方法

「Safari」を初めて開いたときに、Microsoft Internet Explorer、Netscape Navigator、および Mozilla からお気に入りが自動的に読み込まれます。

現時点では、「Safari」は Microsoft Internet Explorer 以外の Web ブラウザからブックマークを直接読み込むことはできません。Microsoft Internet Explorer 以外の Web ブラウザからブックマークを「Safari」に移動するには、お使いの Web ブラウザからブックマークを HTML 書類として書き出します。次に、書き出した HTML 書類を「Safari」で開き、別のウインドウでブックマークライブラリを開きます。そして、1 つ目のウインドウ内のリンクをブックマークライブラリ内のコレクションにドラッグします。
