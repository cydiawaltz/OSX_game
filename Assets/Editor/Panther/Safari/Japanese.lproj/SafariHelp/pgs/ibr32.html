Web ページの文字化け

Web ページに、デフォルトのテキストエンコーディングに入っていない文字が使われており、しかもページ側で正しいエンコーディングが指定されていない場合は、ページのテキストが乱れて見えることがあります。

特定のページのエンコーディングを変更するには、「表示」メニューから「テキストエンコード」を選択して、ページで使用される言語に適したエンコーディングを選択します。

頻繁に開くページでテキストが文字化けしている場合は、デフォルトのテキストエンコードの変更が必要です。「Safari」メニューから「環境設定」を選択して、「アピアランス」をクリックします。「デフォルトエンコード」ポップアップメニューから、適切なエンコーディングを選択します。
