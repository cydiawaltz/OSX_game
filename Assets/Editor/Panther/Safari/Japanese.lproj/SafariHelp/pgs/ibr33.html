Web ページが動作しない場合

Web ページの機能がはたらかない場合、プラグイン、Java、または JavaScript の使用をオフにしているか、ポップアップウインドウの表示をブロックするように「Safari」を設定している可能性があります。

「Safari」メニューから「環境設定」を選択して、「セキュリティ」をクリックします。プラグイン、Java、および JavaScript を使用するためのチェックボックスが選択され、「ポップアップウインドウを防ぐ」チェックボックスの選択が外されていることを確認します。

これらの項目が選択されていないのにページが動作しない場合には、「Safari」メニューで「Apple にバグレポートを送信」を選択して、問題をご報告ください。

安全であることが確実な Web ページを開く場合は、ページでプラグイン、Java、および JavaScript の使用を許可しても、コンピュータのセキュリティに問題は生じません。
