Rendezvous Web サイトを開く方法

「Safari」では、Rendezvous を使ってローカルネットワークやサブネットで利用できる Web サイトを検出します。

使用できる Rendezvous Web サイトを確認するには、ブックマークバーでブックマークライブラリのアイコンをクリックし、「コレクション」の欄で「Rendezvous」を選択します。

Rendezvous 経由で使用できるプリンタがある場合には、Rendezvous Web サイトとしてリスト表示されます。この Web サイトを開いて、プリンタの設定を変更することができます。

「Safari」環境設定の「ブックマーク」パネルを使用すると、ブックマークバーや「ブックマーク」メニューに Rendezvous Web サイトを追加できます。ブックマークライブラリに Rendezvous Web サイトを表示するかどうかを選択することもできます。
