Web ページをブックマークに追加する方法

さまざまな Web ページを開いていると、ブックマークを付けておいてすぐに戻れるようにしたいページが見つかることがあります。

Web ページをブックマークに追加するには、ページを開いて「ブックマーク」メニューから「追加」を選択します。アドレスバーにあるブックマーク追加用のボタンをクリックして追加することもできます（アドレスバーが表示されている場合）。

追加するブックマークの名前を入力し、どこに表示させるか、保存場所をポップアップメニューで選びます。ブックマークは、ブックマークバー、「ブックマーク」メニュー、またはブックマークコレクションに追加できます。

「アドレスボックス」にあるアイコンをブックマークバーへドラッグして、ブックマークバーにブックマークを追加することもできます。

コレクションに追加したブックマークを表示するには、「ブックマーク」メニューから「すべてのブックマークを表示」を選択します。
