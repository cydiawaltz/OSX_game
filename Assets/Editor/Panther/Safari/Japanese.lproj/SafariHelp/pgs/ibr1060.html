Web ページをプリントする

通常通り、「ファイル」メニューの「プリント」コマンドを使って、Web ページをプリントできます。Web ページがいくつかのフレームでできている場合は、プリントしたい特定のフレームだけをプリントできます。

Web ページをプリントするには、ページを「Safari」で開き、「ファイル」メニューで「プリント」を選択します。

Web ページ中のあるフレームをプリントするには、control キーを押しながらプリントしたいフレームをクリックします。その後、コンテクストメニューで「フレームをプリント」を選択します。

「プリント」ダイアログでは、Web ページを PDF にしたり、ファクスで送ったりもできます。
