Web ページが開かない場合

「Safari」で Web ページが開かない場合には、いくつかの理由が考えられます。ページが開かない場合、次の項目についてチェックしてください。

ページが開かないときに表示されるメッセージをチェックします。不具合を解決するための重要な情報が含まれている場合があります。

お手元の Web ページのアドレスが正確で、正しく入力されていることを確認します。

Web サイトが一時的に使用できなくなっている可能性もあります。

ページがネットワークやインターネット上にある場合には、お使いのコンピュータが正しく接続しているか確認します。

Rendezvous アドレスを使用してページを開こうとしている場合には、サイトがコンピュータと同じサブネット上にあることを確認します。

一部の Web サイトは、サイトにより認識されないブラウザからは見ることができません。この状況に該当するかどうかは、Web サイトの管理者にお問い合わせください。

Web ページを開くことができなかった場合、「Safari」＞「Report Bugs to Apple にバグレポートを送信」と選択して、その問題をご報告いただくことができます。
