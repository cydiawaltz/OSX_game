テキストエンコードを選択する方法

ほとんどの Web ページでは、ページに文字をどのように表示するかを決めるテキストエンコードが指定されています。ただし、Web ページによっては、テキストエンコードが指定されていないものもあります。エンコーディングが指定されていない Web ページを開くとき、「Safari」は環境設定の「アピアランス」パネルで選択したデフォルトのテキストエンコードを使用します。

テキストが乱れて読めない状態を避けるには、頻繁に開く Web ページの多くで使われている言語の文字に対応したものを、デフォルトのテキストエンコードとして、選択しておきます。例えば、日本語を使用したページを最も頻繁に開く場合は、デフォルトテキストエンコードを日本語エンコーディングのうちの 1 つに変更します。

「Safari」メニューから「環境設定」を選択して、「アピアランス」をクリックしてください。「デフォルトエンコーディング」ポップアップメニューで、Web ページに合った適切なエンコーディングを選択します。

開いたページのテキストが文字化けしていたら、そのページで使用するエンコーディングを変更してください。「表示」メニューで「テキストエンコーディング」を選び、そこでページに合った適切なエンコーディングを選択します。

Web サイトの中にはいくつかの言語で表示できるものもありますが、「Safari」では、自動的に指定した言語でページを開くことができます。「表示」メニューにある「テキストエンコーディング」での選択では、指定した言語を設定したことにはなりません。言語の指定は、「システム環境設定」の「言語環境」で行います。
