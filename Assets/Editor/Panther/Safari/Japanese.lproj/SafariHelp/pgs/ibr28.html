ポップアップウインドウの表示をブロックする方法

Web ページの中には、ページを開いたり閉じたりしたとき、自動でポップアップウインドウを表示するものがあります。例えば、ログイン情報を要求したり広告を表示したりするために Web ページがポップアップウインドウを使用することがあります。このようなポップアップウインドウの表示をブロックすることができます。

ポップアップウインドウのブロックでは、ページを開いたり閉じたりしたときに現れるポップアップウインドウのみをブロックします。リンクをクリックすると開かれるポップアップウインドウはブロックされません。

ポップアップウインドウの表示をブロックするには、「Safari」メニューから「ポップアップウインドウを防ぐ」チェックボックスをクリックして選択します。

または、「Safari」メニューから「環境設定」を選択して、「セキュリティ」をクリックします。「ポップアップウインドウを防ぐ」チェックボックスをクリックして選択します。

ポップアップウインドウの表示をブロックすると、Web ページ内の重要な情報を見落とす可能性があります。
