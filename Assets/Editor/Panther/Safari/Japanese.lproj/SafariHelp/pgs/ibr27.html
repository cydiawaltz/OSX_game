Web ページで読み込むコンテンツを制御する方法

Web ページを開いたときに読み込むコンテンツを制御できます。セキュリティのため、または目障りなコンテンツを避ける目的で、ある種のコンテンツをページに読み込まないように設定したい場合があります。

特定のコンテンツを読み込まないようにするには、「Safari」メニューから「環境設定」を選択して、「セキュリティ」をクリックします。読み込まないコンテンツの選択を外します。

ポップアップウインドウを表示しないようにするには、「ポップアップウインドウを表示しない」チェックボックスを選択します。「Safari」メニューから「ポップアップウインドウを防ぐ」を選択することもできます。

Cookie の受け入れの有無や、受け入れる Cookie の種類を選択することもできます。

Web ページは各種プラグイン、Java、JavaScript を使用して情報を表示しています。これらの機能をオフにすると、ページのコンテンツの一部が見えなくなる場合があります。
