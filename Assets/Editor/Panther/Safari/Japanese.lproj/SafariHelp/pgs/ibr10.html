過去に開いた Web ページに戻る方法

Web ページを開くと、そのページの場所が「Safari」に記憶されます。「Safari」は過去に開いた Web ページを約 1 週間分記憶します。

この履歴を使って、過去に開いたページに簡単に戻ることができます。

最近開いた Web ページに戻るには、ツールバーの「前へ戻る」／「次へ進む」ボタンをクリックします。「前へ戻る」／「次へ進む」ボタンを押した状態で表示されるページを選択することもできます。

過去に開いた Web ページに戻るには、そのページを「履歴」メニューから選択します。または、ブックマークバーのブックマークをクリックしてから、「履歴」を選択して前に開いたページを見ることもできます。

開きたいページがウインドウの SnapBack ページとしてマーク付けされている場合は、アドレスボックスの SnapBack ボタン（オレンジの丸い矢印）をクリックしてください。SnapBack ページは、通常はウインドウで一番はじめに開いたページです。
