Web ページのフォームを自動入力する方法

「Safari」では、ご使用のアドレスブックの情報を使って、Web ページ内の記入が必要なフォームに情報を入力することができます。また、「Safari」では Web ページのフォームに入力した情報を使用して、ほかのフォームに情報を入力することもできます。

Web サイトに簡単にログインできるように、Web フォームに入力するユーザ名とパスワードを「Safari」に保存することもできます。

「Safari」で使用する情報を選択するには、「Safari」環境設定の「オートフィル」パネルを使用します。

「Safari」メニューから「環境設定」を選択して、「オートフィル」をクリックします。「Safari」で使用する項目を選択します。

Web フォームに情報を入力するには、Web ページを開いてアドレスバーの「オートフィル」ボタンをクリックします。アドレスバーに「オートフィル」ボタンが表示されていない場合は、「表示」メニューから「オートフィル」を選択します。オートフィルを使用して入力された項目は、Web ページでは黄色で表示されます。

フォームの個々のフィールドに情報を入力するには、テキストボックスを選択して入力します。フィールドの情報に一致するものが「Safari」に保存されている場合、そのテキストが自動的に入力されます。入力内容に一致する項目が複数存在する場合は、メニューが表示されます。矢印キーを押して正しい項目を選択し、return キーを押します。

ユーザ名とパスワードを入力すると、「Safari」から情報を保存するかどうかを尋ねられます。ユーザ名とパスワードを保存するには「はい」をクリックします。後で情報を保存する場合は「後で行う」をクリックします。そのWeb サイトでユーザ名とパスワードを保存しない場合、「この Web サイトでは行わない」をクリックします。

保存したユーザ名とパスワード、またはその他の情報を変更、削除するには、環境設定の「オートフィル」パネルで、該当するチェックボックスの隣にある「編集」ボタンをクリックします。
