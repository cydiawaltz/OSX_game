ほかのアプリケーションに含まれるリンクの開き方を設定する方法

「Safari」をデフォルトの Web ブラウザに設定している場合、Mail など、ほかのアプリケーション内でリンクをクリックしたり、Web インターネットロケーションファイルのアイコンをダブルクリックしたりすると Web ページが「Safari」で開きます。ページを新規ウインドウに開くか、現在表示しているウインドウに開くかを選択できます。

「Safari」メニューから「環境設定」を選択し、「他のアプリでリンクを開く場合」から使用するオプションを選択します。

タブブラウズを有効にし、「現在のウインドウで開く」を選択すると、ページは現在表示しているウインドウの新規タブに開かれます。
