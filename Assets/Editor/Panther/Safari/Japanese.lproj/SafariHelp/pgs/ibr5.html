別のウインドウで Web ページを開く方法

Web ページ上でリンクをクリックすると、通常「Safari」は現在アクティブなウインドウでそのページを開きます。しかし「Safari」では、新しいページを別のウインドウで開いて同時に複数のページを参照することも可能です。新規ウインドウでページを開くには、以下のようにいくつかの方法があります。

control キーを押した状態でリンクまたはブックマークをクリックします。ショートカットメニューから「リンクを新規ウインドウで開く」を選択します。

「ファイル」メニューから「新規ウインドウ」を選択し、ページのアドレスを入力します。

現在表示しているウインドウの前に新規ウインドウでページを開くには、コマンドキーを押しながらリンクまたはブックマークをクリックします。現在表示しているウインドウの後ろでウインドウを開くには、コマンドキーと shift キーを押しながらクリックします。「Safari」環境設定で開ける「タブ」パネルで「タブブラウズを利用する」を選択すると、これらのショートカットは変更されます。

リンクによっては、これらのショートカットを使用しなくても新規ウインドウに開かれるものがあります。ステータスバー（ウインドウ下部）を見ると、リンクをクリックしたときの動作が確認できます。ステータスバーを表示するには、「表示」メニューから「ステータスバー」を選択してください。
