ページの表示方法を設定する方法

「Safari」で開かれたページがどのように表示されるかを設定できます。例えば、使用するフォント、画像を表示するかしないか、独自の Cascading Style Sheet（CSS）を使用するかしないかなどが設定できます。

Web ページの多くでは、それぞれ使用するフォントが設定されています。フォントが指定されていないページにのみ、以下で説明するフォントの設定が有効になります。また Web ページによっては、ユーザが使用しているスタイルシートが別のスタイルシートに上書きされることがあります。

「Safari」メニューから「環境設定」を選択して、「アピアランス」をクリックします。

ページで使用する標準フォントや等幅フォントを変更するには、変更したいフォントの「選択」ボタンをクリックしてください。次に「フォント」ウインドウで、使用するフォントを選択します。

ページを開いたときに画像を表示しないようにするには、「ページを開く時に画像を表示する」チェックボックスを外します。このオプションをオフにすると、ページが速く開くようになりますが、重要な情報を見逃してしまうかもしれません。

Web ページのテキストが正しく表示されない場合は、「デフォルトエンコーディング」ポップアップメニューで、別のエンコーディングを選ぶ必要があるかもしれません。最も頻繁に表示する Web ページの言語に適したエンコーディングを選択してください。

独自の Cascading Style Sheet を使用するには、「アドバンス」をクリックし、「スタイルシート」ポップアップメニューから「その他」を選択します。使用するスタイルシートを選択します。

「Safari」環境設定の「セキュリティ」パネルからも、ページに表示されるコンテンツをコントロールできます。

Web サイトの中にはいくつかの言語で表示できるものもありますが、「Safari」では、自動的に指定した言語でページを開くことができます。「表示」メニューにある「テキストエンコーディング」での選択では、指定した言語を設定したことにはなりません。言語の指定は、「システム環境設定」の「言語環境」で行います。
