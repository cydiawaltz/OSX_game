Webpagina's worden niet correct geladen

Als bepaalde onderdelen van een webpagina niet correct functioneren, hebt u mogelijk het gebruik van plugins, Java of JavaScript uitgeschakeld, of u hebt pop-upvensters geblokkeerd.

Kies 'Voorkeuren' uit het Safari-menu en klik vervolgens op 'Beveiliging'. Zorg ervoor dat de aankruisvakken voor het activeren van plugins, Java en JavaScript zijn ingeschakeld, en dat het aankruisvak 'Blokkeer pop-upvensters' is uitgeschakeld.

Als u dit hebt gedaan en de onderdelen nog steeds niet functioneren, kiest u 'Verzend bugrapport naar Apple' uit het Safari-menu om het probleem te rapporteren.

Het activeren van plugins, Java en JavaScript voor websites die u veilig acht, heeft geen schadelijke gevolgen voor de beveiliging van de computer.
