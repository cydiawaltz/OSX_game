Se hvilke pluginmoduler som er tilgjengelig for Safari

Safari kan bruke pluginmodulene som ble installert sammen med Mac OS X, som støtter Java-, QuickTime- og Shockwave Flash-innhold. Safari kan også bruke pluginmoduler som er kompatible med Netscape-standarden for pluginarkitektur, for eksempel Macromedia Shockwave Player- pluginmodulen «Shockwave for Director».

Hvis du vil se hvilke pluginmoduler som er tilgjengelig, velger du Installerte pluginmoduler fra Hjelp-menyen.
