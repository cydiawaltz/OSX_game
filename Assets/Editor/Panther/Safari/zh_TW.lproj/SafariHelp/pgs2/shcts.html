Safari 快速鍵

您可以在選單指令旁看到許多 Safari 的快速鍵。下面提供您一些額外的快速鍵。

動作

快速鍵

將書籤加到“書籤”選單中

打開網頁然後同時按下 ⌘ + Shift + D

將書籤加入“書籤列”中

將網頁圖像從網址欄拖到網址列中

在“書籤”列上移動書籤

將書籤向左或向右拖移

將書籤從“書籤”列中移除

將書籤從書籤列中拖移出去

在“書籤資料庫”中更改書籤的名稱或網址

按一下來選擇書籤並按 Return 鍵

在“書籤資料庫”中選取書籤的文字內容後，要更改下一個書籤的名稱或網址

按 Tab 鍵

完成“書籤資料庫”中的書籤文字編輯

按 Return 鍵

刪除“書籤資料庫”中的書籤

選擇書籤並按 Delete 鍵一下

上、下、左、右捲視

方向鍵

增加頁面的捲視幅度

Option + 方向鍵

向下捲頁

Page Down 鍵
空白鍵

向上捲頁

Page Up 鍵
Shift + 空白鍵

在新視窗中開啟網頁，若未啟用標籤頁瀏覽

⌘ + 點選連結或書籤

在新視窗中開啟網頁並讓其位於目前瀏覽視窗後方，若未啟用標籤頁瀏覽

⌘ + Shift + 點選連結或書籤

以標籤頁打開檔案夾（位於書籤列上）內的所有書籤

⌘ + 點選書籤列中的檔案夾

關閉指定標籤頁外的所有標籤頁

按住 Option 鍵並按一下您想保持開啟的標籤頁上的關閉按鈕

依照網頁名稱來查看最近瀏覽的網頁

按住“上一頁”或“下一頁”按鈕

依照網址來查看最近瀏覽的網頁

按住 Option 鍵 +“上一頁”或“下一頁”按鈕

在 Finder 中查看下載的檔案

在“下載項目”視窗中按檔案旁的圖像一下
