關於 Safari

以下是 Safari 的使用摘要。若要瞭解更多 Safari 相關內容，請搜尋“Safari 輔助說明”並參訪 Safari 網站。

內建 Google 搜尋

Safari 在網址列中包含 Google 搜尋。您只要在搜尋框中輸入想要尋找的相關內容，並按 Return 鍵一下。若您觀看完網頁後要回到搜尋結果，請按 Google 搜尋框內的“回溯”按鈕一下。若要查看最近的搜尋結果，請按住放大鏡。

回溯瀏覽過的頁面

Safari 包含標準的網頁瀏覽方式，例如網址列中的“上一頁”和“下一頁”按鈕。當您從開始的網頁瀏覽時，可以按網址欄中的“回溯”按鈕一下來回到開始的網頁。

使用標籤頁瀏覽

當您開啟另一個網頁的連結時，可以讓網頁在目前瀏覽視窗的標籤頁中開啟，而不需另開新視窗。您甚至只要按一下就能以標籤頁打開檔案夾中的所有書籤

簡便的書籤

當您找到令您感興趣的網站時，會想要儲存該網站的網址，或將網址加到“書籤”中。Safari 提供您新的方式來加入與管理書籤。

當您將網頁加入書籤後，便可以輕鬆地將網頁書籤加到書籤列或“書籤”選單中。“書籤資料庫”能讓您以自己喜好的方式來輕鬆整理您的書籤。

書籤列（在網址列下方）能讓您快速開啟書籤。您可以使用“書籤資料庫”來將書籤檔案夾或是個別的書籤加入書籤列中。

Safari 也提供靈活運用的書籤集，例如您最近的網頁瀏覽記錄。書籤集也包含您“通訊錄”中的個人網站，以及區域網路上所有可使用的 Rendezvous 網站。

若您之前使用過 Microsoft Internet Explorer、Netscape 或 Mozilla，第一次啟動 Safari 時，Safari 會從上述瀏覽器中輸入您的喜好項目。您會在“書籤資料庫”中發現這些書籤的檔案夾。

同步書籤內容

您可以使用 iSync 1.1 和 .Mac 帳號，在不同的電腦上自動同步 Safari 書籤內容，如此您在任何時候都可以連接到自己喜好的網頁。

阻擋彈出式視窗

Safari 可以阻擋彈出式視窗，這樣您便可以只觀看想要瀏覽的網頁。只要從 Safari 選單中選擇“阻擋彈出式視窗”即可。

幫助您填寫表單

Safari 能讓您輕鬆使用 Internet 來購物與從事商業活動。若您在 Safari 偏好設定的“自動填寫”面板中選取自動填寫的選項，Safari 將會幫助您完成表單的填寫並登入具安全機制的網站。

保障您的資料安全

Safari 支援 Internet 標準的安全性功能來防護您本身以及您的資訊。打開 Safari 偏好設定中的“安全性”面板來選擇您的安全性選項。

清除您的私密資料

若您所使用的是公用電腦，便可以快速清除 Safari 所儲存的所有個人資訊記錄。只要從 Safari 選單中選擇“重置 Safari…”，便能刪除您參訪過網頁的瀏覽記錄，並清除快取、清除下載項目與 Goodle 查詢項目，並移除名稱、密碼，或其他“自動填寫”內容。

國際公民

透過 Mac OS X 的 Unicode 支援功能，Safari 可以使用不同的文字系統，如日文、中文、希伯來文、阿伯文、英文，以及其他羅馬語系來瀏覽網頁。
