以標籤頁瀏覽網頁

如果您啟用了標籤頁瀏覽，便可以在標籤頁中打開網頁，而不需取代目前瀏覽的視窗或是打開另外的視窗。

使用標籤頁來瀏覽網頁能讓您更容易一次打開數個網頁，因為您不需開啟多個視窗。

當網頁在標籤頁中開啟時，標籤列會顯示在書籤列下方。網頁名稱會顯示在標籤列中的標籤頁內。

您也可以在標籤頁中打開書籤集。這樣您可以在觀看一個頁面的同時，載入其他的頁面。

若要開啟標籤頁瀏覽，請選擇 Safari 選單中的“偏好設定…”並按“標籤頁”一下。選擇“啟用標籤分頁瀏覽”。

若要以新的標籤頁來開啟連結或書籤列中的書籤，請按住 Command 鍵並按欲開啟的項目一下，或是按住 Control 鍵並按項目一下，然後從快捷選單中選擇“以新標籤頁開啟”。

若要以標籤頁開啟書籤列中的書籤集，或“書籤資料庫”中的書籤檔案夾，請按住 Control 鍵並按書籤集或檔案夾一下，然後從快捷選單中選擇“以新標籤頁開啟所有書籤”。

若您為書籤列中的檔案夾選取“標籤頁開啟”註記框，只要按書籤列中的檔案夾名稱一下，便能讓所有檔案夾中的書籤在標籤頁中開啟。

若要在新標籤頁中開啟網頁，請從“檔案”選單中選擇“新增標籤頁”然後輸入網頁的網址。

若要關閉標籤頁，請按標籤中的關閉按鈕一下。

若要顯示某個標籤頁中的網頁並關閉其他所有的標籤頁，請按住 Option 鍵，然後在您要保持開啟的標籤頁上按關閉選項格一下。

當您在標籤頁內瀏覽網頁時，若按網頁內的連結一下，連結頁面便會在目前的標籤頁中開啟。您可以按一下網址列中的“下一頁”或“上一頁”按鈕來瀏覽標籤頁中開啟的網頁。

若您選擇“瀏覽記錄”或“書籤”選單中的網頁，該網頁便會在目前的標籤頁中開啟。

當您啟用標籤頁瀏覽時，將會更改開啟視窗的快速鍵使用。例如，若要在新視窗內開啟網頁，請按住 Command 和 Option 鍵並點選連結。依照您所設定的標籤頁瀏覽方式，“標籤頁”面板底部的列表將會指示您快速鍵的使用方式。

若您選擇在目前視窗中開啟來自其他應用程式的連結，並且啟用標籤頁瀏覽，網頁會在目前視窗中以新標籤頁開啟。
