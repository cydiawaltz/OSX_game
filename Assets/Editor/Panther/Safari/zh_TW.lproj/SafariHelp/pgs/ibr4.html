打開網頁

當您第一次打開 Safari 時，Safari 會以“系統偏好設定”中，Internet 的設定作為預設開啟的首頁。您可以使用多種方式來開啟網頁。

若要打開目前瀏覽頁面所連結的其他網頁，請按該網頁的連結一下。

若沒有連結可以前往要打開的網頁，請在網址列的文字框中輸入網頁的網址，並按 Return 鍵一下。

若要打開已加入書籤的網頁，可以按書籤列中的項目一下、選擇“書籤”選單中的項目，或是按“書籤資料庫”中的書籤兩下。

若書籤列或是“書籤”選單中的項目旁有一個三角形，則此項目內便含有書籤集。當您選擇該項目時，會看見書籤集內的所有書籤，然後便可以從書籤列表中選擇想要開啟的網頁。

若要打開之前已開啟過的網頁，請輸入網頁的部分網址。Safari 會為您完成網址的輸入或是列出符合的網址。若您看見網址列表，請使用滑鼠指標或方向鍵來選擇網址，並按 Return 鍵來打開網頁。

若要在新視窗中打開網頁並從目前視窗切換至新視窗，請按住 Command 鍵並按連結或書籤一下。若要讓開啟的視窗位於目前瀏覽視窗的後方，請按住 Command 和 Shift 鍵。若您在 Safari 偏好設定的“標籤頁”面板中選擇“啟用標籤分頁瀏覽”，則這些快速鍵的功能也會隨之改變。

若要開啟硬碟或檔案伺服器上的網頁，請從“檔案”選單中選擇“打開檔案…”。

若 Safari 是您的預設網頁瀏覽器，當您在其他應用程式中點選連結（如在 Mail 的信件中）或是按兩下“網頁 Internet 位置”檔案圖像時，網頁便會在 Safari 中開啟。您可以使用 Safari 偏好設定的“一般”面板來選擇讓網頁在新視窗或是目前的視窗中開啟。若您啟用標籤頁瀏覽並選擇在目前視窗中開啟連結，這樣連結的網頁便會在新的標籤頁中開啟。

您可以從其他應用程式中的文件打開網頁，請選取文件中的 URL 並從應用程式選單中選擇“服務”，然後選擇“以 Safari 開啟 URL”。
