在不同視窗中開啟網頁

當您按網頁中的連結一下時，Safari 通常會以您目前正在使用的視窗開啟網頁。您也可以依自己喜好在新視窗內開啟網頁，這樣便可以同時觀看數個頁面。您可以使用數種方法在新視窗內開啟網頁。

請按住 Control 鍵並按連結或書籤一下。然後從快捷選單中選擇“以新視窗開啟連結”。

從“檔案”選單中選擇“打開新視窗”，然後輸入網頁的網址。

若要在新視窗中打開網頁並從目前視窗切換至新視窗，請按住 Command 鍵並按連結或書籤一下。若要讓開啟的視窗位於目前瀏覽視窗的後方，請按住 Command 和 Shift 鍵。若您在 Safari 偏好設定的“標籤頁”面板中選擇“啟用標籤分頁瀏覽”，則這些快速鍵的功能也會隨之改變。

某些連結不需使用這些快速鍵而會自動以新視窗開啟。請在狀態列（位於視窗底部）內查看關於點選連結的資訊。若要檢視狀態列，請從“顯示方式”選單中選擇“狀態列”。
