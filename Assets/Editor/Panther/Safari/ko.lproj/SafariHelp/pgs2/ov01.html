Safari에 관하여

다음은 Safari로 할 수 있는 내용의 요약입니다. Safari에 대해 더 많이 배우려면, Safari 도움말을 선택하고 Safari 웹 사이트를 방문하십시오.

내장 Google 검색

Safari는 주소 막대에서 Google 검색을 제공합니다. 검색 입력란에서 찾고자 하는 내용을 입력하고 Return을 누르십시오. Google 검색 입력란에서 SnapBack 단추를 클릭하여 가장 최근 검색 결과로 돌아갈 수 있습니다. 최근 검색을 반복하려면, 확대경을 누르십시오.

검색 시 SnapBack

Safari는 주소 막대의 뒤로/앞으로 단추와 같은 웹 페이지를 검색하는 표준 방법을 제공합니다. 시작 웹 페이지부터 검색하는 경우, 주소 막대의 SnapBack 단추를 클릭하여 해당 페이지로 빠르게 돌아갈 수 있습니다.

탭으로 브라우징하기

다른 웹 페이지로의 링크를 열면, 새로운 윈도우를 열지 않고 현재 윈도우의 탭에서 페이지를 열 수 있습니다. 한 번 클릭으로 탭의 책갈피 폴더를 열 수 있습니다.

쉬운 책갈피

관심있는 웹 페이지가 있는 경우, 저장하거나 주소를 "책갈피"하길 원할 수 있습니다. Safari는 책갈피를 추가하고 관리하는 새로운 방법을 제공합니다.

웹 페이지를 책갈피하는 경우, 책갈피 막대나 책갈피 메뉴로 쉽게 추가할 수 있습니다. 책갈피 보관함으로 원하는대로 책갈피를 관리하기가 더욱 쉬워졌습니다.

책갈피 막대(주소 막대 아래)에서 책갈피를 빠르게 열 수 있습니다. 책갈피 보관함에서, 개별 책갈피뿐만 아니라 책갈피 폴더를 막대에 추가할 수 있습니다.

Safari는 최근에 방문했던 웹 페이지의 히스토리와 같은 동적인 책갈피도 제공합니다. 주소록과 로컬 네트워크에 있는 Rendezvous 웹 사이트도 포함됩니다.

Microsoft Internet Explorer, Netscape 또는 Mozilla를 사용해 왔고 Safari를 처음 실행한 경우, Safari는 다른 브라우저의 즐겨찾기를 가져옵니다. 책갈피 보관함에서 해당 책갈피들을 모아놓은 폴더를 볼 수 있습니다.

책갈피 동기화하기

iSync 1.1과 .Mac 계정을 사용하여, 다른 컴퓨터의 Safari 책갈피와 자동으로 동기화하여, 즐겨찾기 웹 페이지에 항상 접근할 수 있습니다.

팝업 윈도우 방지

Safari는 팝업 윈도우를 차단하여 보고자 하는 웹 페이지만 나타낼 수 있습니다. Safari 메뉴에서 팝업 윈도우 방지를 선택하면 됩니다.

자동 완성

Safari는 쇼핑이나 비즈니스를 위해 인터넷을 사용하기 쉽도록 합니다. Safari 환경설정의 자동 완성 패널에서 선택사항을 선택하면, Safari는 양식을 완성시켜 보안 웹 사이트에 로그인할 수 있도록 돕습니다.

보안

Safari는 인터넷 표준 보안 기능을 지원하여 정보를 보호합니다. Safari 환경설정의 보안 패널을 열어 보안 선택사항을 선택하십시오.

개인 정보 재설정

공용 컴퓨터를 사용하는 경우, Safari가 저장한 개인 정보 기록을 빠르게 지울 수 있습니다. Safari 메뉴에서 Safari 재설정을 선택하여 방문한 웹 페이지의 히스토리를 지우고, 캐시를 비우고, Google 검색 목록과 다운로드 내용을 지우고, 쿠키를 제거하고, 이름, 암호나 다른 자동 완성 텍스트를 제거하기만 하면 됩니다.

전세계의 사용자

Safari는 Mac OS X의 Unicode 지원을 사용하여, English와 다른 Roman 언어뿐만 아니라 Japanese, Chinese, Hebrew 또는 Arabic으로 된 사이트를 볼 수 있습니다.
