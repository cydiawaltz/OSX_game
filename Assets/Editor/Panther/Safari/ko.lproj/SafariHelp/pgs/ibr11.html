SnapBack 페이지로 돌아가기

윈도우에서 처음 방문한 페이지가 SnapBack 페이지입니다. Safari는 이 페이지를 기억하여 다른 웹 페이지를 방문한 후에도 빨리 SnapBack 페이지로 돌아갈 수 있도록 합니다.

SnapBack 페이지로 돌아가려면, 주소 입력란에서 SnapBack 단추를 클릭하십시오.

각 윈도우는 하나의 SnapBack 페이지만 있습니다. 윈도우에 대해 새로운 SnapBack 페이지를 표시하려면, 히스토리 메뉴에서 SnapBack할 페이지로 표시를 선택하십시오.

주소 입력란에서 해당 주소를 입력하여 열거나, 책갈피 또는 히스토리 메뉴에서 선택하여 열면 해당 페이지는 SnapBack 페이지로 표시됩니다.

Google로 검색하거나 Google 검색 입력란에서 SnapBack 단추를 클릭하면, Safari는 주소 입력란에 SnapBack 단추가 있다면 이를 제거합니다.
