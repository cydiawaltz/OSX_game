Safari를 기본 웹 브라우저로 만들기

Safari를 기본 웹 브라우저로 만들 수 있습니다. 기본 웹 브라우저로 설정한 경우, Mail 메시지와 같은 도큐멘트에서 링크를 클릭하거나, Finder에서 웹 인터넷 위치 파일을 이중 클릭하면 Safari가 열립니다.

Safari는 새로운 윈도우로 이들 페이지를 열도록 설정되어 있지만, 현재 윈도우의 탭에서 열도록 선택할 수 있습니다.

Safari 메뉴에서 환경설정을 선택한 다음, 일반을 클릭하십시오. 기본 웹 브라우저 팝업 메뉴에서 Safari를 선택하십시오.

"응용 프로그램에서 링크 열기" 선택사항을 선택하십시오. 현재 윈도우에서 페이지를 열고 Safari 환경설정의 탭 브라우징 사용을 선택한 경우, 현재 윈도우에 새로운 탭으로 페이지가 열립니다.

일부 프로그램에서 링크를 클릭하면, 프로그램이 기본 브라우저가 아닌 브라우저에서 웹 사이트를 열 수 있습니다.
