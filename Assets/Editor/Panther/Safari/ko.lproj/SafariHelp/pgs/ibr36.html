웹 페이지가 열리지 않습니다

Safari에서 웹 페이지가 열리지 않는 이유는 여러 가지가 있을 수 있습니다. 다음은 페이지가 열리지 않을때 확인해야 할 몇 가지 사항입니다.

페이지가 열리지 않을 경우 나타나는 메시지를 확인하십시오. 문제를 해결할 중요 정보가 있을 수 있습니다.

웹 페이지의 정확한 주소와 정확하게 입력했는지를 확인하십시오.

웹 사이트가 잠시 사용 불가능한 것일 수 있습니다.

페이지가 네트워크나 인터넷에 있다면, 네트워크나 인터넷에 연결되어 있는지 확인하십시오.

Rendezvous 주소를 사용하여 페이지를 열려고 하면, 컴퓨터와 동일한 서브넷에 사이트가 있는지 확인하십시오.

일부 웹 사이트는 해당 사이트가 인식할 수 없는 브라우저를 사용하지 못하도록 합니다. 인식할 수 없는 브라우저를 사용한 경우인지 웹 사이트의 관리자에게 문의하십시오.

웹 페이지를 열 수 없다면, Safari > Apple에 버그 리포트를 선택하여 문제를 보고할 수 있습니다.
