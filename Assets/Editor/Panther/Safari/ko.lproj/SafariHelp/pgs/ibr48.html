저장된 사용자 이름과 암호 삭제하기

자동 완성 환경설정 패널에서 사용자 이름과 암호를 자동으로 완성하도록 선택했다면, Safari는 웹 양식에 입력한 모든 이름과 암호를 저장합니다. 예를 들어, 다른 사람이 인증 정보에 접근하는 것을 막으려면, 이 정보를 지울 수 있습니다.

웹 사이트에 대해 이름과 암호를 입력할 때 "이 웹 사이트에서는 다시 사용 안함"을 선택했다면, 해당 웹 사이트에서 저장한 항목을 삭제해서 정보를 저장할 수 있습니다.

Safari 메뉴에서 환경설정을 선택한 다음, 자동 완성을 클릭하십시오. "사용자 이름 및 암호" 체크상자 옆의 편집을 클릭하십시오. 삭제하려는 항목을 선택하고 삭제를 클릭하십시오.

웹 사이트에서 이름과 암호를 입력할 때 "이 웹 사이트에서는 다시 사용 안함"을 선택했고 지금 그 정보를 저장하기를 원한다면, "암호를 다시 저장하지 않음" 항목을 선택하고 삭제를 클릭하십시오.

모든 항목을 지우려면, 모두 삭제를 클릭하십시오.

사용자 이름이나 암호를 변경한 경우, 해당 웹 사이트에 대해 저장된 정보를 삭제할 필요는 없습니다. 양식에서, 웹 페이지를 열 때 현재 이름과 암호를 새로운 이름과 암호로 대치하십시오. Safari는 새로운 정보를 저장할 것인지를 묻습니다.
