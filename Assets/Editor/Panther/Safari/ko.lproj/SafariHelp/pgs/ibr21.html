홈 페이지 선택하기

Safari를 열 때 보통 "홈 페이지"를 연다면, 새로운 윈도우를 열거나 히스토리 메뉴에서 홈을 선택하십시오. 어떤 페이지든 홈 페이지로 선택할 수 있습니다.

Safari에서 웹 페이지를 연다음, Safari 메뉴에서 환경설정을 선택하고 일반을 클릭하십시오. 현재 페이지를 설정을 클릭하십시오.

"홈 페이지" 입력란에서 홈으로 사용할 페이지의 주소를 입력해도 됩니다.

인터넷 환경설정의 홈 페이지 설정도 변경됩니다.

홈 페이지로 새로운 윈도우를 열려면, "새로운 윈도우 열기" 팝업 메뉴에서 홈 페이지를 선택하십시오.
