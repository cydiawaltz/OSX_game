페이지 표시 방법 설정하기

Safari를 실행할 때, 사용할 서체, 이미지 표시 및 CSS 사용 여부를 포함한 페이지 표시 방법을 지정할 수 있습니다.

많은 웹 페이지가 자신의 서체를 지정합니다. 서체 설정은 서체를 지정하지 않은 페이지에만 영향을 줍니다. 웹 페이지는 사용자가 지정한 스타일 시트를 무시하는 스타일 시트를 지정할 수 있습니다.

Safari 메뉴에서 환경설정을 선택한 다음, 모양새를 클릭하십시오.

페이지에 사용된 기본 서체나 고정폭 서체를 변경하려면, 적절한 선택 단추를 클릭하십시오. 그런 다음, 서체 윈도우에서 사용할 서체를 선택하십시오.

페이지를 열 때 이미지가 표시되지 않도록 하려면, "페이지를 열 때, 이미지 표시" 체크상자를 선택 해제하십시오. 이 선택사항을 끄면 페이지가 좀 더 빠르게 열립니다. 그러나, 중요 정보를 유실할 수도 있습니다.

웹 페이지의 텍스트가 제대로 나타나지 않는다면, 기본 인코딩 팝업 메뉴에서 다른 인코딩을 선택해야 할 수도 있습니다. 자주 보는 웹 페이지에 대해 적절한 언어 인코딩을 선택하십시오.

자신의 CSS를 사용하려면, 고급의 스타일 시트 팝업 메뉴에서 다른 스타일을 선택하십시오. 자신의 스타일 시트를 찾아 선택하십시오.

Safari 환경설정의 보안 패널에서 일부 페이지에 표시된 내용을 제어할 수도 있습니다.

일부 웹 사이트는 여러 언어로 제공됩니다. Safari는 선호하는 언어를 사용하여 페이지를 자동으로 엽니다. 텍스트 인코딩 선택으로 선호하는 언어가 설정되지는 않습니다. 언어를 설정하려면, 다국어 환경설정의 언어 패널에서 설정하십시오.
