방문한 웹 페이지로 돌아가기

웹 페이지를 방문할 때마다, Safari는 해당 웹페이지의 위치를 기록합니다. Safari는 1주일동안 방문했던 웹페이지를 기억합니다.

이 히스토리를 사용하여, 나중에 다시 해당 페이지로 빨리 돌아갈 수 있습니다.

최근에 방문했던 웹 페이지로 돌아가려면, 도구 막대에서 뒤로/앞으로 단추를 클릭하십시오. 뒤로/앞으로 단추를 누른 다음, 나타나는 메뉴에서 페이지를 선택할 수도 있습니다.

이전에 방문했던 웹 페이지로 돌아가려면, 히스토리 메뉴에서 해당 페이지를 선택하십시오. 책갈피 막대에서 책갈피를 클릭한 다음, 히스토리를 선택하여 방문했던 페이지를 볼 수도 있습니다.

열고자 하는 페이지가 SnapBack 페이지로 윈도우에 표시되어 있다면, 주소 입력란에서 SnapBack 단추를 클릭하십시오. SnapBack 페이지는 보통 윈도우에서 처음 방문한 페이지입니다.
