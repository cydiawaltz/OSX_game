웹 양식에서 저장한 데이터 삭제하기

다른 웹 페이지의 정보를 사용하여 웹 양식을 자동으로 완성하도록 하는 선택사항을 선택한 경우, Safari는 입력한 정보를 저장합니다. 이 선택사항을 선택했다면, 이 정보를 지울 수 있습니다.

Safari 메뉴에서 환경설정을 선택한 다음, 자동 완성을 클릭하십시오. "다른 양식" 체크 상자 옆의 편집을 클릭하십시오. 삭제하려는 항목을 선택하고 삭제를 클릭하십시오. 모든 항목을 지우려면, 모두 삭제를 클릭하십시오.

다른 웹 양식의 데이터를 사용하지 않으려면, Safari 환경설정의 탭 패널에서 "다른 양식" 체크 상자를 선택 해제하십시오.
