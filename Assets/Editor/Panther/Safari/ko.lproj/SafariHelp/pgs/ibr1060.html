웹 페이지 프린트하기

파일 메뉴의 프린트 명령을 사용하여 웹 페이지를 프린트할 수 있습니다. 웹 페이지가 여러 프레임으로 구성되어 있다면, 프린트하길 원하는 특정 프레임만 프린트할 수 있습니다.

웹 페이지를 프린트하려면, Safari에서 페이지를 열고 파일 메뉴에서 프린트를 선택하십시오.

웹 페이지의 프레임을 프린트하려면, Control 키를 누른 상태에서 프린트할 프레임을 클릭하십시오. 그런 다음, 단축키 메뉴에서 프레임 프린트를 선택하십시오.

웹 페이지를 PDF로 생성하거나 프린트 대화상자에서 웹 페이지를 팩스로 전송할 수 있습니다.
