웹 페이지의 양식을 자동 완성하기

Safari는 주소록의 정보를 사용하여 웹 페이지에서 입력해야 할 양식을 완성시킵니다. Safari는 또한 웹 페이지에서 입력한 정보를 사용하여 양식을 완성시킵니다.

웹 사이트에 쉽게 로그인하기 위해, Safari는 웹 양식에 입력한 사용자 이름과 암호를 저장할 수 있습니다.

Safari 환경설정의 자동 완성 패널에서 Safari가 사용할 정보를 선택하십시오.

Safari 메뉴에서 환경설정을 선택한 다음, 자동 완성을 클릭하십시오. Safari가 사용할 항목을 선택하십시오.

웹 양식을 완성하려면, 웹 페이지를 열고 주소 막대에서 자동 완성 단추를 클릭하십시오. 주소 막대에 자동 완성 단추가 없다면, 보기 메뉴에서 자동 완성을 선택하십시오. 자동 완성을 사용하여 완성한 항목은 웹 페이지에서 노란색으로 나타납니다.

양식에서 개별 필드 단위로 완성하려면, 텍스트 입력란을 선택하고 입력을 시작하십시오. Safari는 해당 필드에 맞는 저장된 정보를 찾아, 텍스트 입력을 완성합니다. 입력한 내용과 일치하는 항목이 여러 개가 있다면, 메뉴가 나타납니다. 화살표 키를 눌러 올바른 항목을 선택하고 Return을 누르십시오.

사용자 이름과 암호를 입력하면, Safari는 정보를 저장할 지를 묻습니다. 승인을 클릭하여, 이름과 암호를 저장하십시오. 나중에 정보를 저장하기를 원한다면 지금 사용 안함을 클릭하십시오. 해당 웹 사이트에 대해 이름과 암호를 저장할 것인지를 묻지 않기를 원한다면, "이 웹 사이트에서는 다시 사용 안함"을 클릭하십시오.

저장한 사용자 이름과 암호 또는 다른 정보를 변경하거나 삭제하려면, 자동 완성 환경설정 패널에서 해당 체크상자 옆의 편집 단추를 클릭하십시오.
