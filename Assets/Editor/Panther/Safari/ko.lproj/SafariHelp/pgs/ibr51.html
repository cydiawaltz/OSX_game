웹 페이지의 HTML 소스 보기

Safari에서 웹 페이지의 HTML 소스 코드를 볼 수 있습니다. 웹 페이지를 저장하여 나중에 보거나 HTML 코드의 소스로 사용할 수 있습니다.

웹 페이지의 HTML 소스를 보려면, 보려는 페이지를 열고 보기 메뉴에서 소스 보기를 선택하십시오.

웹 페이지의 HTML 소스를 저장하려면, 저장할 페이지를 열고 파일 메뉴에서 별도 저장을 선택하십시오. 파일의 이름을 지정하고 저장할 위치를 선택한 다음, 저장을 클릭하십시오.

페이지를 저장하면 현재 페이지의 HTML 텍스트 내용만 저장됩니다. 페이지의 HTML 코드에서 참조하는 그림과 같은 페이지의 요소는 저장하지 않습니다.
