웹 페이지로 로드된 컨텐츠 조정하기

웹 페이지를 열 때 어떤 컨텐츠를 로드할 것인지 제어할 수 있습니다. 보안상의 이유나 귀찮은 켄텐츠가 나타나지 않도록 특정 컨텐츠가 로드되지 않기를 원할 수 있습니다.

컨텐츠가 로드되지 않도록 하려면, Safari 메뉴에서 환경설정을 선택하고 보안을 클릭하십시오. 그런 다음, 로드하지 않을 컨텐츠를 선택 해제하십시오.

팝업 윈도우가 나타나지 않도록 하려면, 이 체크 상자를 선택하십시오. 또는 Safari 메뉴에서 팝업 윈도우 방지를 선택할 수도 있습니다.

쿠키를 수용할 지 여부와 어떤 쿠키를 수용할 것인지도 선택할 수 있습니다.

웹 페이지는 플러그인, Java 및 JavaScript를 사용하여 정보를 나타냅니다. 이들 기능을 끄면, 해당 페이지의 일부 컨텐츠를 볼 수 없을 것입니다.
