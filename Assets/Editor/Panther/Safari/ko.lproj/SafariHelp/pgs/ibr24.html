텍스트 인코딩 선택하기

대부분의 웹 페이지는 페이지의 문자 표시 방법을 결정하는 텍스트 인코딩을 지정합니다. 하지만, 텍스트 인코딩을 지정하지 않은 일부 페이지도 있습니다. 이들 웹 페이지 중 하나를 여는 경우, Safari는 Safari 환경설정의 모양새 패널에서 선택한 기본 텍스트 인코딩을 사용합니다.

텍스트가 깨지지 않도록 하려면, 자주 방문하는 웹 페이지에서 사용된 언어에 해당하는 기본 텍스트 인코딩을 선택해야 합니다. 예를 들어, 한글로 된 페이지를 주로 방문하다면, Korean 인코딩 중 하나를 기본 텍스트 인코딩으로 선택해야 합니다.

Safari 메뉴에서 환경설정을 선택한 다음, 모양새를 클릭하십시오. 기본 인코딩 팝업 메뉴에서 웹 페이지에 맞는 인코딩을 선택하십시오.

방문한 페이지의 텍스트가 깨져 있다면, 해당 페이지의 인코딩을 변경해야 합니다. 보기 메뉴의 텍스트 인코딩을 선택하고 페이지에 맞는 인코딩을 선택하십시오.

일부 웹 사이트는 여러 언어로 제공됩니다. Safari는 선호하는 언어를 사용하여 페이지를 자동으로 엽니다. 텍스트 인코딩 선택으로 선호하는 언어가 설정되지는 않습니다. 언어를 설정하려면, 다국어 환경설정의 언어 패널에서 설정하십시오.
