다른 윈도우로 웹 페이지 열기

웹 페이지에서 링크를 클릭하면, Safari는 보통 현재 사용하고 있는 동일 윈도우로 해당 페이지를 엽니다. 원한다면, 새로운 윈도우로 페이지를 열어 한 번에 여러 페이지를 볼 수 있습니다. 새로운 윈도우로 페이지를 열 수 있는 다양한 방법이 있습니다.

Control키를 누르고 링크나 책갈피를 클릭하십시오. 그런 다음, 단축키 메뉴에서 새로운 윈도우로 링크 열기를 선택하십시오.

파일 메뉴에서 새로운 윈도우를 선택한 다음, 해당 페이지의 주소를 입력하십시오.

현재 윈도우 앞에 새로운 윈도우로 페이지를 열려면, Command키를 누르고 링크나 책갈피를 클릭하십시오. 현재 윈도우 뒤로 윈도우를 열려면, Command와 Shift키를 누르십시오. Safari 환경설정의 탭 패널에서 탭 브라우징 사용을 선택하면 단축키 메뉴가 달라집니다.

일부 링크는 이들 단축키를 사용하지 않고도 새로운 윈도우로 열립니다. 링크를 클릭하면 나타날 정보에 대해 보려면, 상태 막대(윈도우 하단)를 확인하십시오. 상태 막데를 보려면, 보기 메뉴에서 상태 막대를 선택하십시오.
