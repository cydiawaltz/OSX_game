Rendezvous 웹 사이트 열기

Safari는 Rendezvous를 사용하여 로컬 네트워크나 서브네트의 웹 사이트를 검색할 수 있습니다.

사용 가능한 Rendezvous 웹 사이트를 보려면, 주소 막대에 있는 책갈피 보관함 아이콘을 클릭한 다음, 모음 행에서 Rendezvous를 선택하십시오.

Rendezvous를 사용하는 프린터가 있다면, Rendezvous 웹 사이트로 나타납니다. 웹 사이트를 열어 프린터를 구성할 수 있습니다.

Safari 환경설정의 책갈피 패널에서 Rendezvous 웹 사이트를 주소 막대와 책갈피 메뉴에 추가할 수 있습니다. 책갈피 보관함에 Rendezvous 웹 사이트가 나타나도록 선택할 수도 있습니다.
