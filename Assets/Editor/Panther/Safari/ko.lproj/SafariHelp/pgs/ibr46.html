탭 브라우징 동작 방법 설정하기

Safari 환경설정의 탭 패널에서 탭 브라우징 동작 방법을 설정할 수 있습니다.

Safari 메뉴에서 환경설정을 선택한 다음, 탭을 클릭하십시오.

탭을 사용하여 웹 페이지를 브라우즈하려면, 탭 브라우징 사용 체크상자를 선택하십시오.

현재 탭의 앞에서 새로운 탭으로 열려면, "새롭게 생성된 탭 선택" 체크 상자를 선택하십시오.

한 개의 웹 페이지가 열려있더라도 탭을 볼 수 있도록하려면 "항상 탭 막대로 보기" 선택상자를 선택하십시오.

탭 브라우징을 사용가능하게 하거나, 현재 탭의 전면에서 새로운 탭을 열도록 선택하면 새로운 탭과 새로운 윈도우로 열기 위해 사용할 수 있는 단축키가 변경됩니다. 탭 패널의 하단에 있는 목록에는 탭 브라우징을 어떻게 설정하는지에 따라 어떤 단축키를 사용해야 하는지 나타냅니다.
