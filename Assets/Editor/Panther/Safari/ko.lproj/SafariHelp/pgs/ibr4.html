웹 페이지 열기

Safari를 처음 실행하면, 인터넷 환경설정에서 지정한 홈 페이지를 엽니다. 웹 페이지를 여는 데는 몇 가지 방법이 있습니다.

현재 보고 있는 페이지에서 링크된 페이지를 열려면, 링크를 클릭하십시오.

링크 없이 페이지를 열려면, 주소 막대의 텍스트 입력란에 주소를 입력하고 Return키를 누르십시오.

책갈피 한 페이지를 열려면, 책갈피 막대에서 항목을 클릭하고, 책갈피 메뉴에서 항목을 선택하거나 책갈피 보관함에서 책갈피를 이중 클릭하십시오.

책갈피 막대나 책갈피 메뉴 항목 이름 옆에 삼각형이 있으면, 책갈피 모음을 나타냅니다. 항목을 선택하면, 모음에 있는 모든 책갈피를 볼 수 있으며, 목록에서 원하는 페이지를 선택할 수 있습니다.

이전에 방문한 페이지를 열려면, 해당 주소의 일부를 입력하십시오. Safari는 주소를 자동 완성시키며 일치되는 주소 목록을 보여줍니다. 목록이 나타나면, 화살표 키나 마우스 포인터로 주소를 선택하고 Return키를 눌러 페이지를 여십시오.

현재 윈도우 앞에 새로운 윈도우로 페이지를 열려면, Command키를 누르고 링크나 책갈피를 클릭하십시오. 현재 윈도우 뒤로 윈도우를 열려면, Command와 Shift키를 누르십시오. Safari 환경설정의 탭 패널에서 탭 브라우징 사용을 선택하면 단축키가 변경됩니다.

하드 디스크나 파일 서버의 페이지를 열려면, 파일 메뉴에서 파일 열기를 선택하십시오.

Safari가 기본 웹 브라우저라면, Mail 메시지와 같은 다른 응용 프로그램에서 링크를 클릭하거나 웹 인터넷 위치 파일의 아이콘을 이중 클릭하면 웹 페이지가 Safari로 열립니다. Safari 환경설정의 일반 패널에서 페이지를 새로운 윈도우로 열지, 또는 현재 윈도우로 열지를 선택할 수 있습니다. 탭 브라우징를 사용하고 있고 현재 윈도우에서 링크를 열도록 선택하면, 새로운 탭으로 열립니다.

다른 응용 프로그램의 도큐멘트에서 URL을 선택하고 응용 프로그램 메뉴에서 서비스를 선택한 다음, Safari에서 URL 열기를 선택하여 웹 페이지를 열 수 있습니다.
