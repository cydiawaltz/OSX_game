파일 다운로드하기

Safari로 인터넷에서 파일을 쉽게 다운로드할 수 있습니다.

링크를 클릭하여 파일을 다운로드하십시오. 다운로드 윈도우가 다운로드 과정을 나타냅니다.

다운로드 윈도우가 나타나지 않는다면, 윈도우 메뉴에서 다운로드를 선택하십시오.

파일 다운로드를 중단하려면, 다운로드 윈도우에서 파일 이름 오른쪽의 아이콘을 클릭하십시오. 아이콘을 다시 클릭하여 파일을 처음부터 다운로드하십시오.

Finder에서 다운로드된 파일을 보려면, 다운로드 윈도우의 파일 이름 옆의 돋보기를 클릭하십시오.

Safari 환경설정의 일반 패널에서 지정한 위치에 파일이 다운로드됩니다.

디스크 이미지, MacBinary, BinHex 또는 gzip 포맷 파일을 다운로드한 경우, Safari는 파일을 자동으로 압축 해제합니다. 파일에 설치 프로그램이 있는 경우, Safari는 설치 프로그램을 실행합니다.

디스크 이미지 파일을 다운로드한 경우, Safari는 파일을 압축 해제하고 디스크 이미지 볼륨을 마운트합니다. 파일에 설치 프로그램이 있는 경우, Safari는 설치 프로그램을 실행합니다.

인터넷 디스크 이미지 파일을 다운로드하면, Safari는 이미지 파일을 압축 해제 합니다. 파일에 설치 프로그램이 있는 경우, Safari는 설치 프로그램을 실행합니다. 그런 다음, Safari는 디스크 이미지를 휴지통으로 이동합니다. 디스크 이미지를 유지하려면, 휴지통 밖으로 드래그하십시오.

Safari 환경설정의 일반 패널에서 다운로드 시 "안전한" 파일을 열도록 하는 선택사항을 선택한 경우, 해당 파일이 안전하다면 열립니다. 안전한 파일에는 그림, 동영상 및 사운드, PDF와 텍스트 도큐멘트, 그리고 디스크 이미지와 다른 압축된 파일들이 포함됩니다.

다운로드 윈도우를 지우려면, 윈도우에서 삭제를 클릭하십시오. Safari 환경설정의 일반 패널에서 다운로드 윈도우의 항목을 제거하는 경우를 설정할 수도 있습니다.

Safari는 Safari 환경설정의 일반 패널에서 지정한 위치로 파일을 다운로드합니다. 새로운 위치를 선택하려면, "다운로드한 파일 저장" 팝업 메뉴에서 다른 위치를 선택하십시오.
