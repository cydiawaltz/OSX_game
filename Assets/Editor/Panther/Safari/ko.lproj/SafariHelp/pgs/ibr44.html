탭에서 웹 페이지 브라우징하기

탭 브라우징이 커져 있다면, 현재 윈도우의 내용을 대치하거나 별도의 윈도우를 열지 않고도 탭에서 웹 페이지를 열 수 있습니다.

탭을 사용한 웹 페이지 브라우징의 경우 여러 윈도우를 열 필요가 없기 때문에 여러 페이지를 한번에 쉽게 열 수 있습니다.

탭으로 페이지를 열면, 책갈피 막대 아래에 탭 막대가 나타납니다. 페이지의 이름은 탭 막대의 탭에 나타납니다.

탭에서 책갈피 모음을 열 수도 있습니다. 한 페이지를 보면서도, 다른 페이지를 로드할 수 있습니다.

탭 브라우징을 켜려면, Safari 메뉴에서 환경설정을 선택한 다음, 탭을 클릭하십시오. 탭 브라우징 사용을 선택하십시오.

새로운 탭으로 책갈피 막대에서 링크나 책갈피를 열려면, Command키를 누르고 항목을 클릭하거나, Control키를 누르고 항목을 클릭한 다음 단축키 메뉴에서 새로운 탭에서 열기를 선택하십시오.

책갈피 막대에서 책갈피 모음이나 탭의 책갈피 보관함에서 책갈피 폴더를 열려면, Control키를 누르고, 모음이나 폴더를 클릭하고, 단축키 메뉴에서 탭에서 열기를 선택하십시오.

책갈피 막대에서 폴더의 자동 탭 체크상자를 선택하면, 책갈피 막대에서 폴더 이름을 클릭하여 탭에서 폴더의 모든 책갈피를 열 수 있습니다.

새로운 탭에서 웹 페이지를 열려면, 파일 메뉴에서 새로운 탭을 선택하고 페이지 주소를 입력하십시오.

탭을 닫으려면, 탭에서 닫기 단추를 클릭하십시오.

탭에 있는 웹 페이지를 나타내고 다른 모든 탭을 닫으려면, Option키를 누르고 그대로 열어 둘 탭에서 닫기 상자를 클릭하십시오.

탭에서 보고 있는 페이지의 링크를 클릭하면, 현재 탭에서 페이지가 열립니다. 주소 막대의 뒤로/앞으로 단추를 클릭하여 탭에서 연 페이지를 열람할 수 있습니다.

히스토리나 책갈피 메뉴에서 페이지를 선택하면, 페이지가 현재 탭에서 열립니다.

탭 브라우징이 켜 있다면, 윈도우 열기 단축키가 변경됩니다. 예를 들어, 새로운 윈도우에서 페이지를 열려면, Command와 Option키를 누르고 링크를 클릭하십시오. 탭 패널의 하단에 있는 목록에는 탭 브라우징을 어떻게 설정하는지에 따라 어떤 단축키를 사용해야 하는지 나타냅니다.

탭 브라우징을 활성화 하고 다른 응용 프로그램의 링크를 현재 윈도우로 열도록 선택한 경우, 페이지는 현재 윈도우의 새로운 탭에서 열립니다.
