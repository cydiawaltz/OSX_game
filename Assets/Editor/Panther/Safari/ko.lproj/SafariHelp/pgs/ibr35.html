다운로드한 파일 찾기

다운로드한 파일은 Safari 환경설정의 일반 패널에서 지정한 다운로드 위치로 복사됩니다.

Safari는 파일을 데스크탑에 다운로드하도록 설정하지만, 다른 위치를 선택할 수 있습니다. 다운로드한 파일의 위치를 보려면, Safari 환경설정의 일반 패널을 여십시오.

다운로드한 파일을 Finder에서 보려면, 파일을 다운로드할 때 나타나는 다운로드 윈도우의 파일 이름 옆에 돋보기를 클릭하십시오.

다운로드 윈도우가 나타나지 않는다면, 윈도우 메뉴에서 다운로드를 선택하십시오.

디스크 이미지 파일을 다운로드하는 경우, Safari는 다운로드 윈도우에 디스크 이미지 볼륨의 이름을 나타냅니다. 마운트되지 않은 볼륨이 있다면 돋보기를 클릭할 때, Safari는 Finder에 디스크 이미지 파일을 나타냅니다.

인터넷 디스크 이미지를 다운로드하는 경우, Safari는 파일을 압축 해제하고 컨텐츠를 다운로드 위치에 복사한 다음, 디스크 이미지를 휴지통으로 이동합니다. 돋보기를 클릭하면, 다운로드 위치의 내용을 볼 수 있습니다. 디스크 이미지 파일을 저장하려면, 휴지통 밖으로 드래그하십시오.
