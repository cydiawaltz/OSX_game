웹 페이지가 동작하지 않습니다

웹 페이지의 기능이 제대로 동작하지 않는다면, 플러그인, Java 또는 JavaScript를 끄거나, Safari에서 팝업 윈도우를 차단하도록 설정할 수 있습니다.

Safari 메뉴에서 환경설정을 선택한 다음, 보안을 클릭하십시오. 플러그인, Java 및 JavaScript를 사용하도록 체크 상자가 선택되어 있는지와, "팝업 윈도우 방지" 체크 상자가 선택되어 있지 않은지 확인하십시오.

이들 항목이 선택되어 있지 않은데도 페이지가 동작하지 않는다면, Safari 메뉴에서 Apple로 버그 리포트를 선택하여 문제를 보고하십시오.

신뢰하는 웹 페이지를 연 다음, 페이지가 플러그인, Java 및 JavaScript를 사용하도록 허용하면 컴퓨터의 보안을 위협하지는 않습니다.
