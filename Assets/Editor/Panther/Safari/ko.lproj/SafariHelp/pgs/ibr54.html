프록시 서버 지정하기

방화벽으로 보호된 네트워크에 연결하여 인터넷에 접속하려면, 웹 페이지와 다른 인터넷 자료에 접근하도록 프록시 서버를 지정해야 합니다. 브라우저가 프록시 서버에 웹 페이지를 요청하면, 해당 페이지를 검색합니다.

프록시 서버를 지정해야 할 경우, 네트워크 관리자가 필요한 정보를 제공해야 합니다. 정보에는 지정할 프록시 서버 유형(예를 들어, 웹 프록시 서버), 서버의 IP 주소나 DNS 이름 및 포트 번호가 포함되어야 합니다.

네트워크 환경설정에서 프록시 서버 정보를 지정하십시오. Safari 환경설정에서 적절한 네트워크 환경설정을 열 수 있습니다.

Safari 메뉴에서 환경설정을 선택하고 고급을 클릭한 다음, 설정 변경을 클릭하십시오.

시스템 환경설정의 네트워크 패널은 사용하고 있는 연결 유형에 대한 프록시 설정값을 나타냅니다. 예를 들어 웹 프록시와 같이 프록시 서버 유형 체크상자를 선택하십시오. 네트워크 관리자가 제공한 IP 주소나 DNS 이름을 첫 번째 텍스트 입력란에 입력하고 포트 번호를 두 번째 입력란에 입력하십시오. 준비가 되었다면, 지금 적용을 클릭하십시오.
