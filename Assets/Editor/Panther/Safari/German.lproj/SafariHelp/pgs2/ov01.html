Über Safari

Hier finden Sie eine Zusammenfassung der Funktionen von Safari. Ausführliche Informationen über Safari erhalten Sie in der Safari Hilfe und auf der Safari Web-Site.

Integrierte Google Suche

Safari enthält in der Adressleiste eine integrierte Google Suchfunktion. Geben Sie einfach ein Stichwort in das Suchfeld ein und drücken Sie anschließend den Zeilenschalter. Klicken Sie in die Taste "SnapBack" im Google Suchfeld, um zu Ihren letzten Suchergebnissen zurückzukehren. Wenn Sie eine kürzlich ausgeführte Suche wiederholen möchten, klicken Sie in das Lupensymbol.

"SnapBack" Funktion beim Surfen

Safari bietet Ihnen die Standardmöglichkeiten zum Durchsuchen von Web-Seiten, wie zum Beispiel die Tasten "Vorwärts" und "Zurück" in der Adressleiste. Wenn Sie von einer Ausgangs-Web-Seite ausgehen, können Sie schnell und einfach zu dieser Seite zurückkehren, indem Sie in die "SnapBack" Taste im Adressfeld klicken.

Surfen mit Tabs

Wenn Sie einen Link zu einer anderen Web-Seite öffnen, können Sie diese Seite als Tab im aktuellen Fenster öffnen, anstatt ein neues Fenster zu öffnen. Sie können sogar einen Lesezeichenordner einfach per Mausklick in Tabs öffnen.

Einfache Lesezeichenverwaltung

Wenn Sie eine interessante Web-Seite finden, möchten Sie diese möglicherweise sichern bzw. ein "Lesezeichen" der Adresse erstellen. Safari bietet Ihnen neue Möglichkeiten zum Hinzufügen und Verwalten von Lesezeichen.

Wenn Sie eine Web-Seite mit einem Lesezeichen versehen, können Sie dieses ganz einfach in der Lesezeichenleiste oder im Menü "Lesezeichen" hinzufügen. Mit der Lesezeichen-Sammlung steht Ihnen eine einfache Möglichkeit für die gewünschte Verwaltung Ihrer Lesezeichen zur Verfügung.

Die Lesezeichenleiste (unter dem Adressfeld) erlaubt ein schnelles Öffnen Ihrer Lesezeichen. Mithilfe der Lesezeichen-Sammlung können Sie Ordner mit Lesezeichen und auch einzelne Lesezeichen zur Leiste hinzufügen.

Safari bietet Ihnen zudem dynamische Lesezeichen, etwa eine Statistik der kürzlich von Ihnen besuchten Web-Seiten. Zudem verwendet Safari auch die Web-Sites in Ihrem Adressbuch und alle Rendezvous Web-Sites, die in Ihrem lokalen Netzwerk zur Verfügung stehen.

Wenn Sie bisher Microsoft Internet Explorer, Netscape oder Mozilla verwendet haben, importiert Safari automatisch Ihre Favoriten aus diesen Browsern, wenn Sie Safari zum ersten Mal öffnen. Sie finden die Ordner für diese Sammlungen im Fenster "Lesezeichen-Sammlung".

Synchronisieren von Lesezeichen

Mithilfe von iSync 1.1 und Ihrem .Mac Benutzer-Account können Sie Ihre Safari Lesezeichen automatisch auf unterschiedlichen Computern synchronisieren, damit Sie immer Zugriff auf Ihre bevorzugten Web-Seiten haben.

Unterdrücken von Pop-Up-Fenstern

Safari kann Pop-Up-Fenster unterdrücken, sodass nur die Web-Seiten angezeigt werden, die Sie wirklich sehen möchten. Wählen Sie dazu einfach den Befehl "Pop-Ups unterdrücken" aus dem Menü "Safari".

Hilfe beim Ausfüllen von Formularen

Safari erleichtert es Ihnen, das Internet zum Einkaufen und für geschäftliche Zwecke zu nutzen. Wenn Sie die Optionen im Bereich "Automatisch ausfüllen" der Safari Einstellungen auswählen, trägt Safari verschiedene Informationen auf Formularen automatisch ein und unterstützt Sie beim Anmelden bei sicheren Web-Sites.

Sicherheit - dort, wo Sie sie brauchen

Safari unterstützt die standardmäßigen Internet-Sicherheitsfunktionen, um Ihre Privatsphäre und Ihre Informationen zu schützen. Öffnen Sie einfach den Bereich "Sicherheit" der Safari Einstellungen, um die gewünschten Sicherheitsoptionen auszuwählen.

Zurücksetzen für Datenschutz und Privatsphäre

Wenn Sie einen öffentlich zugänglichen Computer nutzen, können Sie schnell alle persönlichen Informationen löschen, die von Safari gespeichert werden. Wählen Sie "Safari zurücksetzen" aus dem Menü "Safari" aus, um die Statistik der von Ihnen besuchten Web-Seiten zu löschen, den Cache zu entleeren, Einträge im Fenster "Geladene Objekte" und Google Suchwörter zu löschen, Cookies sowie gesicherte Namen, Kennwörter und andere automatisch ausgefüllte Textelemente zu entfernen.

Internationalität

Safari verwendet die Mac OS X Unterstützung für das Unicode-Format, sodass Sie Web-Sites in verschiedenen Schriftsystemen anzeigen können, z. B. in Japanisch, Chinesisch, Hebräisch, Arabisch, sowie Englisch und romanischen Sprachen.
