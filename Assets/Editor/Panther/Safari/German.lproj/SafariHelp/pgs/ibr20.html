Laden von Dateien

Mit Safari können Sie einfach Dateien aus dem Internet laden.

Klicken Sie in den Link, um eine Datei zu laden. Der Vorgang des Ladens wird im Fenster "Geladene Objekte" angezeigt.

Wenn Sie das Fenster "Geladene Objekte" nicht sehen, wählen Sie den entsprechenden Befehl aus dem Menü "Fenster".

Wenn Sie das Laden einer Datei stoppen möchten, klicken Sie in das Symbol rechts neben dem entsprechenden Dateinamen im Fenster "Geladene Objekte". Klicken Sie erneut in dieses Symbol , um den Ladevorgang für die Datei von vorn zu beginnen.

Klicken Sie im Fenster zum Laden in das Lupensymbol neben dem Dateinamen, um eine geladene Datei im Finder anzuzeigen.

Sobald die Datei geladen ist, finden Sie diese unter dem im Bereich "Allgemein" der Safari Einstellungen angegebenen Speicherort.

Wenn Sie eine Image-Datei oder Dateien im MacBinary, BinHex oder gzip Format laden, dekomprimiert Safari diese Datei automatisch. Enthält die Datei ein Installationsprogramm, öffnet Safari das Installationsprogramm für Sie.

Wenn Sie eine Image-Datei laden, dekomprimiert Safari die Datei und aktivert das Volume der Image-Datei. Enthält die Datei ein Installationsprogramm, öffnet Safari das Installationsprogramm für Sie.

Wenn Sie eine Image-Datei aus dem Internet geladen haben, dekomprimiert Safari diese Datei ebenfalls automatisch. Enthält die Datei ein Installationsprogramm, öffnet Safari das Installationsprogramm für Sie. Safari bewegt die Image-Datei dann in den Papierkorb. Wenn Sie die Image-Datei aufbewahren möchten, bewegen Sie sie wieder aus dem Papierkorb heraus.

Wenn Sie im Bereich "Allgemein" der Safari Einstellungen die Option zum Öffnen "sicherer" Dateien während des Ladens auswählen, wird die Datei geöffnet, wenn sie sicher ist. Sichere Dateien sind Dokumente wie Bilder, Filme und Töne, PDF- und Textdokumente, Image-Dateien und andere Arten von Archiven.

Wenn Sie den Inhalt dieses Fensters löschen möchten, klicken Sie im Fenster in die Taste "Löschen". Sie können im Bereich "Allgemein" der Safari Einstellungen auch festlegen, wann Safari Objekte aus dem Fenster "Geladene Objekte" entfernen soll.

Safari lädt die Dateien an den Speicherort, der im Bereich "Allgemein" der Safari Einstellungen festgelegt wurde. Wenn Sie einen anderen Speicherort auswählen möchten, wählen Sie die Option "Andere" aus dem Einblendmenü zum Speichern geladener Dateien.
