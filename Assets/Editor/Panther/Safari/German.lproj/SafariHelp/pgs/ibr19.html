Überwachen der Browser-Aktivität

Während Safari eine Web-Seite lädt, können Sie überwachen, wie die einzelnen Elemente der Seite geladen werden. Dies kann sich als nützlich erweisen, wenn Sie die Struktur einer Web-Seite prüfen möchten.

Wählen Sie "Aktivität" aus dem Menü "Fenster" aus und öffnen Sie dann die Web-Seite. Safari zeigt jedes Element an, das von der Seite geladen wird.

Wenn Sie ein Objekt im Fenster "Aktivität" in einem eigenen Fenster öffnen möchten, wählen Sie es durch Doppelklicken aus.

Wenn Sie eine andere Web-Seite öffnen, ersetzt diese die Inhalte im Fenster "Aktivität".
