Öffnen von Web-Seiten

Wenn Sie Safari zum ersten Mal öffnen, wird die Startseite geöffnet, die in den Internet-Einstellungen festgelegt wurde. Sie haben dann verschiedene Möglichkeiten, Web-Seiten zu öffnen.

Wenn Sie eine Seite öffnen möchten, die mit der gerade angezeigten Seite durch einen Link verbunden ist, klicken Sie in den Link.

Wenn Sie eine Seite ohne Link öffnen möchten, geben Sie die entsprechende Adresse im Textfeld der Adressleiste ein und drücken Sie den Zeilenschalter.

Wenn Sie eine Seite öffnen möchten, die Sie mit einem Lesezeichen versehen haben, klicken Sie in der Lesezeichenleiste in ein Objekt, wählen Sie ein Objekt aus dem Menü "Lesezeichen" aus oder wählen Sie das entsprechende Lesezeichen durch Doppelklicken in der "Lesezeichen-Sammlung" aus.

Wird neben einem Objekt in der Lesezeichenleiste oder dem Menü "Lesezeichen" ein Dreiecksymbol angezeigt, handelt es sich um eine Sammlung von Lesezeichen. Wenn Sie dieses Objekt auswählen, werden alle Lesezeichen der Sammlung angezeigt. Sie können dann in dieser Liste die gewünschte Seite auswählen.

Wenn Sie eine Seite öffnen möchten, die Sie kürzlich angesehen haben, geben Sie einen Teil der Adresse ein. Safari vervollständigt die Adresse oder zeigt Ihnen eine Liste in Frage kommender Adressen an. Wenn Sie eine Liste angezeigt sehen, wählen Sie mithilfe der Pfeiltasten oder Ihres Zeigers eine Adresse aus und drücken Sie dann den Zeilenschalter, um die Seite zu öffnen.

Wenn Sie eine Seite in einem neuen Fenster vor dem aktuellen Fenster öffnen möchten, halten Sie die Befehlstaste gedrückt und klicken Sie in den Link oder in das Lesezeichen. Wenn Sie ein Fenster hinter dem aktuellen Fenster öffnen möchten, halten Sie die Befehlstaste und die Umschalttaste gedrückt. Diese Kurzbefehle ändern sich, wenn Sie im Bereich "Tabs" in den Safari Einstellungen die Option "Surfen mit Tabs aktivieren" auswählen.

Wenn Sie eine Seite auf Ihrer Festplatte oder einem File-Server öffnen möchten, wählen Sie "Öffnen" aus dem Menü "Ablage".

Wenn Safari Ihr Standard-Web-Browser ist, werden Web-Seiten in Safari geöffnet, wenn Sie in Dokumenten anderer Programme, etwa einer E-Mail-Nachricht, in Links klicken oder wenn Sie Symbole von Web-Internet-Adressdateien durch Doppelklicken auswählen. Sie können im Bereich "Allgemein" der Safari Einstellungen festlegen, ob Seiten in einem neuen Fenster oder im aktuellen Fenster geöffnet werden sollen. Wenn Sie das Surfen mit Tabs aktivieren und auswählen, dass Links im aktuellen Fenster geöffnet werden, werden diese in einem neuen Tab geöffnet.

Sie können eine Web-Seite von einem in einem anderen Programm geöffneten Dokument aus anzeigen, indem Sie die URL-Adresse auswählen und dann "Dienste" aus dem Programmmenü auswählen. Wählen Sie danach die Option "URL in Safari öffnen" aus.
