Übertragen von Formularen an eine sichere Web-Site

In einigen Fällen werden Formulare, die Sie in Safari ausfüllen, über eine nicht sichere Verbindung an eine sichere Web-Site übertragen. Safari ist so eingestellt, dass in diesem Fall eine Nachricht angezeigt wird, sodass Sie die Übertragung des Formulars unterbinden können, wenn Sie Bedenken wegen der Sicherheit Ihrer Informationen haben.

Wenn Sie diese Meldung nicht sehen möchten, wählen Sie "Einstellungen" aus dem Menü "Safari" und klicken Sie in "Sicherheit". Deaktivieren Sie das Markierungsfeld "Vor dem Senden unsicherer Formulare an sichere Web-Sites nachfragen".
