Festlegen von Proxy-Servern

Wenn Ihr Computer über eine durch eine Firewall geschützte Netzwerkverbindung auf das Internet zugreift, müssen Sie unter Umständen Proxy-Server festlegen, um auf Web-Seiten und andere Internet-Ressourcen zugreifen zu können. Ihr Browser sendet dann Anfragen für Web-Seiten an den Proxy-Server, der die Seite für Sie abruft.

Wenn Sie einen Proxy-Server festlegen müssen, sollte Ihnen Ihr Netzwerkadministrator alle erforderlichen Informationen zur Verfügung stellen können. Diese Informationen sollten die Art des Proxy-Servers umfassen, den Sie festlegen müssen (z.B. einen Web-Proxy-Server), die IP-Adresse oder den DNS-Namen für den Server sowie eine Port-Nummer.

Sie können Proxy-Server-Informationen mithilfe der Systemeinstellung "Netzwerk" festlegen. Sie können den entsprechenden Bereich der Systemeinstellung "Netzwerk" mithilfe der Safari Einstellungen öffnen.

Wählen Sie "Einstellungen" aus dem Menü "Safari" und klicken Sie in "Erweitert". Klicken Sie dann in "Einstellungen ändern".

Die Systemeinstellung "Netzwerk" wird geöffnet und zeigt die Einstellungen für die von Ihnen verwendete Verbindungsart an. Wählen Sie das Markierungsfeld für die gewünschte Art des Proxy-Servers aus (z.B. Web Proxy). Geben Sie die von Ihrem Netzwerkadministrator zur Verfügung gestellte IP-Adresse oder den DNS-Namen im ersten Textfeld und die Port-Nummer im zweiten Textfeld ein. Klicken Sie "Jetzt aktivieren", wenn Sie alle erforderlichen Angaben gemacht haben.
