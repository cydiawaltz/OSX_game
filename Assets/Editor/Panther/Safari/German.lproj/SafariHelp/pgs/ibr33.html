Web-Seiten funktionieren nicht

Wenn einige Funktionen auf Web-Seiten nicht funktionieren, haben Sie möglicherweise die Verwendung von Plug-Ins, Java oder JavaScript deaktiviert oder Sie haben in Safari das Blockieren von Pop-Up-Fenstern ausgewählt.

Wählen Sie "Einstellungen" aus dem Menü "Safari" und klicken Sie in "Sicherheit". Stellen Sie sicher, dass die Markierungsfelder für die Verwendung von Plug-Ins, Java und JavaScript ausgewählt sind und dass das Markierungsfeld "Pop-Ups unterdrücken" nicht markiert ist.

Sind all diese Objekte nicht ausgewählt und wird die Web-Seite dennoch nicht korrekt geladen, wählen Sie "Fehler an Apple melden" aus dem Menü "Safari", um Apple über das Problem zu informieren.

Wenn Sie Web-Seiten öffnen, denen Sie vertrauen, dann stellt die Verwendung von Plug-Ins, Java und JavaScript kein Sicherheitsrisiko für Ihren Computer dar.
