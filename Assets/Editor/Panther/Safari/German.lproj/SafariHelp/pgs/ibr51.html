Anzeigen der HTML-Quelle einer Web-Seite

Sie können den HTML-Quelltext einer Web-Seite in Safari anzeigen. Sie können eine Web-Seite auch sichern, sodass Sie diese später anzeigen oder als Quelle für HTML-Code verwenden können.

Wenn Sie den HTML-Quelltext einer Web-Seite anzeigen möchten, öffnen Sie die gewünschte Seite und wählen Sie "Quelltext anzeigen" aus dem Menü "Darstellung".

Wenn Sie den HTML-Quelltext einer Web-Seite sichern möchten, öffnen Sie die gewünschte Seite und wählen Sie "Sichern unter" aus dem Menü "Ablage". Geben Sie einen Namen für die Datei ein und wählen Sie den gewünschten Speicherort aus. Klicken Sie dann in "Sichern".

Durch das Sichern der Seite wird nur der HTML-Textinhalt der aktuellen Seite gesichert. Elemente der Seite wie Bilder, die sich auf den HTML-Code der Seite beziehen, werden nicht gesichert.
