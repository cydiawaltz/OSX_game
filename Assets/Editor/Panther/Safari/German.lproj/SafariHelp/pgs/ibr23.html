Festlegen, wie Seiten angezeigt werden

Sie können festlegen, wie Seiten beim Öffnen in Safari angezeigt werden. Beispielsweise können Sie festlegen, welche Zeichensätze verwendet werden, ob Bilder angezeigt werden sollen oder nicht und ob Sie eine eigene CSS-Datei (Cascading Style Sheet) verwenden möchten.

Auf vielen Web-Seiten sind eigene Zeichensätze festgelegt. Die von Ihnen vorgenommenen Einstellungen der Zeichensätze betreffen nur die Seiten, die keine festgelegten Zeichensätze besitzen. Web-Seiten können unter Umständen Style Sheets festlegen, mit der die Einstellungen Ihrer CSS-Datei aufgehoben werden.

Wählen Sie "Einstellungen" aus dem Menü "Safari" und klicken Sie dann in "Erscheinungsbild".

Wenn Sie den standardmäßig auf den Seiten verwendeten Zeichensatz oder den verwendeten nichtproportionalen Zeichensatz ändern möchten, klicken Sie in die entsprechende Taste "Auswählen". Wählen Sie dann im Fenster "Schriften" den Zeichensatz aus, den Sie verwenden möchten.

Wenn Sie verhindern möchten, dass beim Öffnen von Seiten Bilder angezeigt werden, deaktivieren Sie das Markierungsfeld "Bilder anzeigen, sobald die Seite sich öffnet". Durch das Deaktivieren dieser Option werden Seiten schneller geöffnet. Allerdings erhalten Sie dann möglicherweise wichtige Informationen nicht.

Wird der Text auf den Web-Seiten nicht korrekt angezeigt, müssen Sie unter Umständen aus dem Einblendmenü "Standard-Codierung" eine andere Codierung auswählen. Wählen Sie eine Codierung aus, die der Sprache entspricht, in der Sie Web-Seiten am häufigsten anzeigen.

Wenn Sie eine eigene CSS-Datei (Cascading Style Sheet) verwenden möchten, klicken Sie in "Erweitert" und wählen Sie "Auswählen" aus dem Einblendmenü "Style Sheet" aus. Suchen Sie die gewünschte Datei und wählen Sie diese aus.

Im Bereich "Sicherheit" der Safari Einstellungen können Sie festlegen, welche Inhalte auf einigen Seiten angezeigt werden.

Einige Web-Sites sind in verschiedenen Sprachen verfügbar. Safari kann die Seiten in Ihrer bevorzugten Sprache automatisch öffnen. Durch das Auswählen einer Text-Codierung wird Ihre bevorzugte Sprache nicht festgelegt. Verwenden Sie den Bereich "Sprache" in der Systemeinstellung "Landeseinstellungen", um Ihre Sprache festzulegen.
