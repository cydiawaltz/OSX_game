Surfen zu Web-Seiten mithilfe von Tabs

Wenn Sie das Surfen mithilfe von Tabs aktivieren, können Sie für Web-Seiten Tabs in der Tableiste anzeigen, anstatt den Inhalt des aktuellen Fensters zu ersetzen oder weitere Fenster zu öffnen.

Das Surfen zu Web-Seiten mithilfe von Tabs vereinfacht das gleichzeitige Öffnen mehrerer Seiten, da Sie dafür nicht mehrere Fenster öffnen müssen.

Wenn Sie für eine Seite einen Tab anzeigen, erscheint die Tableiste unter der Lesezeichenleiste. Der Name der Seite wird in einem Tab in der Tableiste angezeigt.

Sie können auch eine Sammlung von Lesezeichen in Tabs öffnen. Während Sie sich eine Seite ansehen, können die anderen geladen werden.

Wenn Sie das Surfen mithilfe von Tabs aktivieren möchten, wählen Sie "Einstellungen" aus dem Menü "Safari" und klicken Sie in "Tabs". Wählen Sie dann die Option "Surfen mit Tabs aktivieren" aus.

Wenn Sie einen Link oder ein Lesezeichen in der Lesezeichenleiste in einem neuen Tab öffnen möchten, halten Sie die Taste "Crtl" gedrückt und klicken Sie in das gewünschte Objekt. Wählen Sie anschließend "In Tabs öffnen" aus dem Kontextmenü aus.

Wenn Sie eine Lesezeichen-Sammlung in der Lesezeichenleiste oder einen Ordner mit Lesezeichen in der "Lesezeichen-Sammlung" mithilfe von Tabs öffnen möchten, halten Sie die Taste "ctrl" gedrückt und klicken Sie in die gewünschte Sammlung oder in den gewünschten Ordner. Wählen Sie anschließend aus dem Kontextmenü die Option "In Tabs öffnen" aus.

Wenn Sie für einen Ordner in der Lesezeichenleiste den Befehl "In Tabs öffnen" aus dem Menü "Lesezeichen" auswählen, werden für alle Lesezeichen in diesem Ordner Tabs in der Tableiste angezeigt.

Wenn Sie für eine Web-Seite einen neuen Tab öffnen möchten, wählen Sie "Neuer Tab" aus dem Menü "Ablage" und geben Sie dann die Adresse der gewünschten Seite ein.

Klicken Sie in das Schließfeld eines Tabs, um den Tab auszublenden.

Wenn Sie eine Web-Seite anzeigen möchten, für die ein Tab angezeigt wird, und alle anderen Tabs ausblenden möchten, halten Sie die Wahltaste gedrückt und klicken Sie in das Schließfeld des Tabs, den Sie weiterhin anzeigen möchten.

Wenn Sie in einer Seite, für die Sie einen Tab anzeigen, in einen Link klicken, wird die Seite im aktuellen Tab geöffnet. Klicken Sie in der Adresszeile in die Tasten "Zurück" und "Vorwärts", um Seiten zu durchsuchen, die Sie in Tabs geöffnet haben.

Wenn Sie eine Seite aus dem Menü "Verlauf" oder "Lesezeichen" auswählen, wird die Seite im aktuellen Tab geöffnet.

Wenn Sie das Surfen mit Tabs aktiviert haben, ändern sich die Kurzbefehle zum Öffnen von Fenstern. Wenn Sie beispielsweise eine Seite in einem neuen Fenster öffnen möchten, halten Sie die Befehlstaste und die Wahltaste gedrückt und klicken Sie in einen Link. Die Liste im unteren Teil des Bereichs "Tabs" zeigt die Kurzbefehle, die für die jeweils gewählte Option für das Surfen mit Tabs verfügbar sind.

Wenn Sie festlegen, dass Links aus anderen Programmen im aktuellen Fenster geöffnet werden und das Surfen mit Tabs aktivieren, wird die neue Seite in einem neuen Tab im aktuellen Fenster geöffnet.
