Öffnen von Startseiten aus Ihrem Adressbuch

In Safari können Sie mühelos Web-Sites öffnen, die auf den Visitenkarten in Ihrem Adressbuch verzeichnet sind.

Wählen Sie im Adressbuch eine Visitenkarte aus und geben Sie die Adresse für eine Seite im Feld für die Startseite ein.

Wenn Sie diese Seiten in Safari anzeigen möchten, wählen Sie "Alle Lesezeichen einblenden" aus dem Menü "Lesezeichen". Wählen Sie dann das Adressbuch aus. Wählen Sie eine Seite durch Doppelklicken aus, um sie zu öffnen.

Sie können Startseiten aus dem Adressbuch zur Lesezeichenleiste und dem Menü "Lesezeichen" hinzufügen, indem Sie den Bereich "Lesezeichen" der Safari Einstellungen verwenden. Sie können auch festlegen, dass Startseiten aus dem Adressbuch in der Lesezeichen-Sammlung angezeigt werden.
