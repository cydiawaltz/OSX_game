Drucken von Web-Seiten

Sie können den Standardbefehl zum Drucken im Menü "Ablage" verwenden, um eine Web-Seite zu drucken. Wenn die Web-Seite aus mehreren Frames besteht, können Sie gezielt nur den Frame drucken, den Sie benötigen.

Öffnen Sie die Seite in Safari und wählen Sie "Drucken" aus dem Menü "Ablage", um eine Web-Seite zu drucken.

Wenn Sie einen Frame einer Web-Seite drucken wollen, drücken Sie Taste "ctrl". Halten Sie die Maustaste gedrückt und wählen Sie den gewünschten Frame aus. Wählen Sie dann "Frame drucken" aus dem Kontextmenü.

Mit den Optionen im Dialogfenster "Drucken" können Sie auch ein PDF-Dokument der Web-Seite erstellen oder die Seite als Fax versenden.
