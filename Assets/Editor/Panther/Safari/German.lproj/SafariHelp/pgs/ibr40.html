Web-Seiten mit einem Lesezeichen versehen

Wenn Sie Web-Seiten öffnen, empfiehlt es sich, diese mit einem Lesezeichen zu versehen, damit Sie schnell wieder darauf zugreifen können.

Wenn Sie eine Web-Seite mit einem Lesezeichen versehen möchten, öffnen Sie zunächst die gewünschte Seite. Dann wählen Sie "Lesezeichen hinzufügen" aus dem Menü "Lesezeichen". Alternativ können Sie auch in die Taste "Lesezeichen hinzufügen" (+) in der Adressleiste klicken, sofern diese angezeigt wird.

Geben Sie einen Namen für das Lesezeichen ein und wählen Sie aus dem Einblendmenü aus, wo es angezeigt werden soll. Sie können das Lesezeichen zur Lesezeichenleiste, dem Menü "Lesezeichen" oder einer Sammlung von Lesezeichen hinzufügen.

Sie können ein Lesezeichen auch zur Lesezeichenleiste hinzufügen, indem Sie das Symbol im Adressfeld in die Lesezeichenleiste bewegen.

Wenn Sie ein Lesezeichen anzeigen möchten, das Sie zu einer Sammlung hinzugefügt haben, wählen Sie "Alle Lesezeichen einblenden" aus dem Menü "Lesezeichen".
