Steuern des durch eine Web-Seite geladenen Inhalts

Sie können steuern, welche Inhalte beim Öffnen einer Web-Seite geladen werden. Sie möchten möglicherweise das Laden bestimmter Inhalte unterbinden - entweder aus Sicherheitsgründen oder weil Sie diese Inhalte störend finden.

Wenn Sie verhindern möchten, dass Inhalte geladen werden, wählen Sie "Einstellungen" aus dem Menü "Safari" und klicken Sie in "Sicherheit". Wählen Sie dann die Inhalte aus, die Sie nicht laden möchten.

Wenn Sie das Einblenden von Pop-Up-Fenstern blockieren möchten, wählen Sie das entsprechende Markierungsfeld aus. Alternativ können Sie auch den Befehl "Pop-Ups unterdrücken" aus dem Menü "Safari" auswählen.

Sie können auch auswählen, ob Sie Cookies akzeptieren möchten und welche Cookies akzeptiert werden sollen.

Web-Seiten verwenden zum Anzeigen von Informationen Plug-Ins, Java und JavaScript. Wenn Sie diese Funktionen deaktivieren, können Sie möglicherweise einige Inhalte der Seite nicht sehen.
