Laden und Installieren von Software

Wenn Sie eine Image-Datei geladen haben, dekomprimiert Safari diese Datei automatisch. Enthält die Datei ein Installationsprogramm, öffnet Safari das Installationsprogramm für Sie. Befolgen Sie einfach die Anweisungen auf dem Bildschirm, um die Installation korrekt zu auszuführen.

Wenn Sie eine Image-Datei aus dem Internet geladen haben, die Software installiert, dekomprimiert Safari die Datei und öffnet das Installationsprogramm für Sie. Wenn die Installation abgeschlossen ist, bewegt Safari die Image-Datei in den Papierkorb. Wenn Sie die Image-Datei aufbewahren wollen, um die Software später erneut zu installieren, bewegen Sie die Datei aus dem Papierkorb heraus.
