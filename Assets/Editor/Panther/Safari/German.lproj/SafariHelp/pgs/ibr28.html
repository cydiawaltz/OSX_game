Unterdrücken von Pop-Up-Fenstern

Einige Web-Seiten zeigen beim Öffnen und Schließen manchmal Pop-Up-Fenster an. Eine Web-Seite kann z.B. ein Pop-Up-Fenster verwenden, um Anmeldeinformationen von Ihnen abzufragen oder um Werbung anzuzeigen. Sie können die Anzeige dieser Pop-Up-Fenster unterdrücken.

Dadurch wird nur die Anzeige von Pop-Up-Fenstern unterdrückt, die beim Öffnen oder Schließen einer Seite angezeigt werden. Pop-Up-Fenster, die durch das Klicken in einen Link geöffnet werden, werden dadurch nicht unterdrückt.

Wenn Sie die Anzeige von Pop-Up-Fenstern unterdrücken möchten, wählen Sie den zugehörigen Befehl aus dem Menü "Safari", sodass neben dieser Option ein Häkchen angezeigt wird.

Alternativ können Sie auch "Einstellungen" aus dem Menü "Safari" wählen und dann in "Sicherheit" klicken. Klicken Sie dann in das Markierungsfeld "Pop-Ups unterdrücken".

Wenn Sie Pop-Up-Fenster unterdrücken, werden unter Umständen wichtige Informationen einer Web-Seite nicht angezeigt.
