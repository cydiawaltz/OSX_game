Entfernen von Daten, die aus Web-Formularen gesichert wurden

Wenn Sie die Option zum automatischen Vervollständigen von Web-Formularen mit Informationen von anderen Web-Seiten auswählen, sichert Safari die von Ihnen eingegebenen Informationen. Sie können diese Informationen entfernen, wenn Sie dies wünschen.

Wählen Sie "Einstellungen" aus dem Menü "Safari" und klicken Sie in "Automatisch ausfüllen". Klicken Sie neben dem Markierungsfeld "Andere Formulare" in "Bearbeiten". Wählen Sie das Objekt aus, das Sie löschen möchten, und klicken Sie in "Entfernen". Wenn Sie alle Objekte löschen möchten, klicken Sie in "Alle entfernen".

Wenn Sie keine Daten von anderen Web-Formularen verwenden möchten, deaktivieren Sie das Markierungsfeld "Andere Formulare" im Bereich "Tabs" der Safari Einstellungen.
