Festlegen, wie das Surfen mit Tabs funktioniert

Sie können mithilfe des Bereichs "Tabs" in den Safari Einstellungen festlegen, wie das Surfen mit Tabs erfolgen soll.

Wählen Sie "Einstellungen" aus dem Menü "Safari" und klicken Sie in "Tabs".

Wenn Sie beim Surfen zu Web-Seiten Tabs in der Tableiste verwenden möchten, markieren Sie die Option "Surfen mit Tabs aktivieren".

Wenn Sie neue Tabs im Vordergrund vor dem aktuellen Tab öffnen möchten, markieren Sie das Feld "Neuen Tab nach dem Anlegen auswählen".

Markieren Sie das Feld "Tableiste immer zeigen", um einen Tab anzuzeigen, auch wenn Sie nur eine Web-Seite geöffnet haben.

Wenn Sie das Surfen mit Tabs aktivieren oder festlegen, dass neue Tabs im Vordergrund vor dem aktuellen Tab angezeigt werden sollen, ändern sich die Kurzbefehle, mit denen Sie Seiten in neuen Tabs und neuen Fenstern öffnen können. Die Liste im unteren Teil des Bereichs "Tabs" zeigt, welche Kurzbefehle abhängig von der für das Surfen mit Tabs gewählten Option zur Verfügung stehen.
