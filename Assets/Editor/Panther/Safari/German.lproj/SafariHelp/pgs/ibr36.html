Eine Web-Seite lässt sich nicht öffnen

Es gibt verschiedene Gründe, warum sich eine Web-Seite in Safari nicht öffnen lässt. Im Folgenden finden Sie einige Hinweise, die Sie überprüfen sollten, wenn eine Seite sich nicht öffnen lässt.

Überprüfen Sie die Meldung, die angezeigt wird, wenn eine Seite nicht geöffnet werden kann. Sie finden darin unter Umständen wichtige Informationen zur Problemlösung.

Stellen Sie sicher, dass Sie die richtige Adresse für die Web-Seite verwenden und dass Sie diese Adresse korrekt eingegeben haben.

Die Web-Site ist möglicherweise vorübergehend nicht verfügbar.

Falls sich die Seite im Netzwerk oder im Internet befindet, stellen Sie sicher, dass eine Verbindung hergestellt ist.

Wenn Sie versuchen, eine Seite mithilfe einer Rendezvous Adresse zu öffnen, vergewissern Sie sich, dass sich die Site-Adresse im selben Teilnetzwerk wie Ihr Computer befindet.

Einige Web-Sites unterbinden die Verwendung von Browsern, die sie nicht erkennen. Wenden Sie sich an den Administrator der Web-Site, um herauszufinden, ob dies der Fall ist.

Wenn eine Web-Seite nicht geöffnet wird, können Sie den Fehler melden, indem Sie "Safari" > "Fehler an Apple melden" auswählen.
