Auffinden von geladenen Dateien

Dateien, die Sie geladen haben, werden an den Speicherort kopiert, den Sie im Bereich "Allgemein" der Safari Einstellungen festgelegt haben.

Standardmäßig lädt Safari Dateien in Ihren Schreibtischordner, Sie können jedoch auch einen anderen Speicherort festlegen. Öffnen Sie den Bereich "Allgemein" der Safari Einstellungen, um zu sehen, an welchen Speicherort die Dateien geladen werden.

Wenn Sie eine geladene Datei im Finder sehen möchten, klicken Sie in das Lupensymbol neben dem Dateinamen im Fenster "Geladene Objekte", das beim Laden einer Datei angezeigt wird.

Wenn Sie das Fenster "Geladene Objekte" nicht sehen, wählen Sie den entsprechenden Befehl aus dem Menü "Fenster".

Wenn Sie eine Image-Datei geladen haben, zeigt Safari den Namen der Image-Datei im Fenster "Geladene Objekte" an. Wenn Sie in diesem Fenster in das Lupensymbol neben dem geladenen Objekt klicken, zeigt Safari die Image-Datei im Finder an.

Wenn Sie eine Image-Datei aus dem Internet laden, dekomprimiert Safari die Datei automatisch und kopiert die Inhalte an den Speicherort für geladene Dateien. Anschließend bewegt Safari die Image-Datei in den Papierkorb. Wenn Sie in das Lupensymbol klicken, sehen Sie den Inhalt des Speicherorts für geladene Dateien. Wenn Sie die Image-Datei sichern möchten, müssen Sie sie aus dem Papierkorb bewegen.
